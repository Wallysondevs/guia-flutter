Flutter Stack e Positioned

A Row põe os widgets lado a lado; a Column, um embaixo do outro. Falta uma direção: um em cima do outro, como camadas. O nome do prato escrito sobre a foto, o selinho vermelho com o número sobre o ícone do carrinho, o botão de favorito no canto da imagem. Para isso existe o Stack ("pilha"), e, dentro dele, o Positioned ("posicionado"), que coloca uma camada num lugar exato.

Você vai aprender
  • Como o Stack empilha os filhos em camadas: o primeiro embaixo, o último em cima.
  • Como o alignment do Stack decide onde ficam as camadas menores.
  • Como o Positioned prende uma camada às bordas com top, left, right e bottom.
  • Como fazer o selinho com o número em cima de um ícone.
  • O que acontece com o que passa da borda (clipBehavior) e os erros reais.

Todos os apps desta aula são um lib/main.dart completo, compilados pelo Flutter 3.47 do laboratório para a web e fotografados no navegador, em tamanho de celular (390 × 844).

A ideia: folhas de papel na mesa

A Ana põe na mesa uma foto do bolo. Por cima, cola um bilhetinho com o nome da receita. Por cima do bilhete, um adesivo de estrela. Cada coisa nova fica por cima das anteriores e pode tapar um pedaço delas. O Stack funciona assim: os filhos são desenhados na ordem da lista, então o primeiro fica no fundo e o último fica na frente.

Stack(children: [ foto, bilhete, estrela ])

      ┌─ estrela   (último: na frente)
    ┌─┴ bilhete
  ┌─┴── foto       (primeiro: no fundo)

1. O primeiro Stack

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: Stack(
          children: [
            Container(width: 300, height: 200, color: Colors.orange),
            Container(width: 200, height: 120, color: Colors.yellow),
            const Text('Bolo de cenoura', style: TextStyle(fontSize: 24)),
          ],
        ),
      ),
    );
  }
}
Stack(children: [ … ])
A pilha. Como a Row e a Column, recebe uma lista de filhos.
Container laranja (300 × 200)
O primeiro filho: a camada do fundo (no app de verdade, seria a foto do bolo).
Container amarelo (200 × 120)
A segunda camada, por cima da laranja.
Text('Bolo de cenoura')
O último filho: a camada da frente, por cima de tudo.

Duas regras aparecem nessa foto:

  • As camadas ficam encostadas no canto de cima, à esquerda. É o alignment padrão do Stack (AlignmentDirectional.topStart, "começo do topo").
  • O Stack fica com o tamanho da maior camada (aqui, a laranja, 300 × 200).

2. Para onde vão as camadas: alignment

O alignment do Stack diz onde ficam as camadas menores dentro da maior. Os valores são os do Alignment: topLeft, topCenter, topRight, centerLeft, center, centerRight, bottomLeft, bottomCenter e bottomRight (aula Center e Align). Este app mostra três Stacks iguais, mudando só o alignment:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class Camadas extends StatelessWidget {
  const Camadas(this.alinhamento, this.nome, {super.key});

  final Alignment alinhamento;
  final String nome;

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(8),
      child: Stack(
        alignment: alinhamento,
        children: [
          Container(width: 300, height: 160, color: Colors.orange),
          Container(width: 140, height: 60, color: Colors.yellow),
          Text(nome, style: const TextStyle(fontSize: 18)),
        ],
      ),
    );
  }
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('alignment')),
        body: const Column(
          children: [
            Camadas(Alignment.topLeft, 'topLeft'),
            Camadas(Alignment.center, 'center'),
            Camadas(Alignment.bottomRight, 'bottomRight'),
          ],
        ),
      ),
    );
  }
}

Com topLeft, o amarelo e o texto encostam no canto de cima à esquerda do laranja; com center, ficam os dois no meio; com bottomRight, no canto de baixo à direita. Repare que o texto também se moveu: o alignment vale para todas as camadas que não têm Positioned, cada uma alinhada pelo seu próprio tamanho dentro do Stack.

3. Positioned: um lugar exato

O alignment vale para todas as camadas ao mesmo tempo. Quando cada camada precisa de um lugar diferente, embrulhe-a num Positioned e diga a distância até as bordas do Stack:

        body: Stack(
          children: [
            Container(width: 390, height: 240, color: Colors.orange),
            const Positioned(
              left: 16,
              bottom: 16,
              child: Text('Bolo de cenoura', style: TextStyle(fontSize: 28, color: Colors.white)),
            ),
            const Positioned(
              top: 8,
              right: 8,
              child: Icon(Icons.favorite, color: Colors.red, size: 40),
            ),
          ],
        ),
Positioned(left: 16, bottom: 16, …)
"16 de distância da borda esquerda e 16 da borda de baixo do Stack." O texto fica no canto de baixo, à esquerda.
Positioned(top: 8, right: 8, …)
O coração, a 8 do topo e 8 da direita: o canto de cima, à direita.
const Positioned
O Positioned tem construtor const; como o texto e o ícone também são constantes, ele inteiro pode ser.
Você dizO que acontece
top ou bottom (um dos dois)A distância até aquela borda; a altura é a do filho
top e bottomO filho é esticado entre as duas bordas
left ou right (um dos dois)A distância até aquela borda; a largura é a do filho
left e rightO filho é esticado entre as duas bordas
width / heightUm tamanho fixo (só combina com um dos lados daquela direção)
Positioned.fill(child: …)top, left, right e bottom = 0: o filho cobre o Stack inteiro

4. O selinho com o número

O exemplo mais famoso de Stack: o ícone do carrinho com uma bolinha vermelha mostrando quantos itens há nele.

        body: Center(
          child: Stack(
            clipBehavior: Clip.none,
            children: [
              const Icon(Icons.shopping_cart, size: 64),
              Positioned(
                right: -6,
                top: -6,
                child: Container(
                  padding: const EdgeInsets.all(6),
                  decoration: const BoxDecoration(color: Colors.red, shape: BoxShape.circle),
                  child: const Text('3', style: TextStyle(color: Colors.white, fontSize: 16)),
                ),
              ),
            ],
          ),
        ),
Center
Só para pôr o carrinho no meio da tela (aula Center e Align).
Icon(Icons.shopping_cart, size: 64)
A camada de baixo. Como é a única sem Positioned, é ela que dá o tamanho do Stack: 64 × 64.
right: -6, top: -6
Números negativos: a bolinha passa um pouco para fora do Stack, no canto de cima à direita, como nos apps de verdade.
clipBehavior: Clip.none
"Não corte nada." Por padrão, o Stack corta o que passa da borda dele (Clip.hardEdge). Sem esta linha, a bolinha apareceria cortada.
BoxDecoration(… shape: BoxShape.circle)
Pinta o Container de vermelho, em forma de círculo (aula BoxDecoration).

E sem o clipBehavior: Clip.none, o mesmo código fica assim:

O Material 3 já tem um selinho pronto: Badge

Para esse caso específico, o Flutter tem o widget Badge ("crachá"): Badge(label: Text('3'), child: Icon(Icons.shopping_cart)). Ele faz o Stack por você, com as cores do tema. Mesmo assim, vale entender o Stack: é com ele que você monta tudo o que não vem pronto.

Quando dá errado

Positioned fora de um Stack 
        body: const Column(
          children: [
            Positioned(top: 10, left: 10, child: Text('Bolo de cenoura')),
          ],
        ),

Usually, this means that the Positioned widget has the wrong ancestor RenderObjectWidget. Typically,

"Uso errado de ParentDataWidget." Como o Expanded (aula Expanded e Flexible), o Positioned não desenha nada: ele deixa um recado (as distâncias) para o pai, e só o Stack sabe ler esse recado. A última linha diz onde ele está: inside a Column widget, "dentro de uma Column". Como consertar: o Positioned tem de ser filho direto de um Stack. Para só afastar um widget das bordas, sem camadas, use um Padding.

"Uma asserção falhou: left == null || right == null || width == null não é verdade." Traduzindo a condição: "pelo menos um dos três (left, right, width) tem de ficar vazio". Faz sentido: com a distância da esquerda e da direita, a largura já está decidida; um width a mais seria uma terceira opinião, possivelmente diferente. O endereço basic.dart:4917 é o lugar, no código do Flutter, onde o Positioned faz essa conferência. Com o app rodando no modo de depuração, a tela inteira fica vermelha com essa mesma mensagem em amarelo. Como consertar: use só dois dos três na horizontal (left e right, ou left e width…); a mesma regra vale para top, bottom e height.

Quando todas as camadas têm Positioned, nenhuma delas dá tamanho ao Stack; aí ele tenta ficar do maior tamanho que o pai deixar. Dentro de uma Column, a altura permitida vai até Infinity (veja a linha constraints), e nada pode ter altura infinita: a conferência size.isFinite ("o tamanho é finito") falha. A mensagem entre aspas traduz: "Um Stack precisa de restrições com limite. Isso costuma acontecer quando ele está dentro de uma Column, de um ListView… Para consertar, embrulhe o Stack num widget que dê largura e altura finitas, como um SizedBox." Como consertar: SizedBox(height: 60, child: Stack(…)), ou deixe pelo menos uma camada sem Positioned para dar o tamanho. O porquê do "infinito" está em Como o Flutter Calcula Tamanhos.

Referência rápida

EscritaO que faz
Stack(children: [a, b, c])a no fundo, c na frente
Stack(alignment: Alignment.center, …)Onde ficam as camadas sem Positioned (padrão: em cima, no começo)
Stack(clipBehavior: Clip.none, …)Não corta o que passa da borda (padrão: Clip.hardEdge, corta)
Stack(fit: StackFit.expand, …)As camadas sem Positioned esticam até o tamanho máximo
Positioned(top:, right:, bottom:, left:, width:, height:, child:)Prende o filho às bordas do Stack
Positioned.fill(child: w)w cobre o Stack inteiro

Resumo

  • Stack empilha os filhos em camadas: o primeiro da lista fica no fundo, o último na frente.
  • O Stack tem o tamanho da maior camada sem Positioned; o alignment (padrão: em cima, no começo) posiciona essas camadas.
  • Positioned prende uma camada às bordas com top, right, bottom, left (e width/height); Positioned.fill cobre tudo.
  • O que passa da borda é cortado, a não ser com clipBehavior: Clip.none.
  • Positioned só funciona como filho direto de um Stack.
