Flutter Alinhamento (mainAxis e crossAxis)

Na aula Row e Column, os filhos sempre ficaram encostados no começo: no alto da coluna, à esquerda da fileira. Mas e se você quiser os botões no meio da tela? Ou o primeiro ícone na esquerda e o último na direita, com o espaço repartido entre eles? Para isso, a Row e a Column têm dois parâmetros: mainAxisAlignment e crossAxisAlignment. Os nomes assustam, mas a ideia é uma só: em que direção você está alinhando.

Você vai aprender
  • O que é o eixo principal (main axis) e o eixo cruzado (cross axis), e por que eles trocam de lugar entre a Row e a Column.
  • Os seis valores de mainAxisAlignment, cada um com a foto: start, end, center, spaceBetween, spaceAround e spaceEvenly.
  • Os valores de crossAxisAlignment: start, end, center, stretch e baseline.
  • Por que, às vezes, mudar o alinhamento não muda nada na tela, e como resolver.

Todos os apps desta aula são um lib/main.dart completo, compilados pelo Flutter Flutter 3.47 do laboratório para a web e fotografados no navegador, em tamanho de celular (390 × 844).

A ideia: a fila do caixa

Pense numa fila de pessoas no caixa do mercado. A fila tem uma direção: é nela que as pessoas andam, uma atrás da outra. Essa é a direção principal. A outra direção, de lado, é a cruzada: dá para alguém ficar mais à esquerda ou mais à direita na fila, sem sair do lugar dela.

  • Na Row, a fila anda para a direita: o eixo principal é o horizontal e o cruzado é o vertical.
  • Na Column, a fila anda para baixo: o eixo principal é o vertical e o cruzado é o horizontal.
Row                                   Column
eixo principal ──────────────▶        eixo principal
┌────┐ ┌────┐ ┌────┐  ▲ eixo           │  ┌──────┐
│ A  │ │ B  │ │ C  │  │ cruzado        │  │  A   │
└────┘ └────┘ └────┘  ▼                │  ├──────┤
                                       │  │  B   │
                                       ▼  ├──────┤
                                          │  C   │
                                          └──────┘
                                       ◀── eixo cruzado ──▶

Então:

  • mainAxisAlignment ("alinhamento no eixo principal") diz onde os filhos ficam ao longo da fila: no começo, no fim, no meio, ou espalhados.
  • crossAxisAlignment ("alinhamento no eixo cruzado") diz onde cada filho fica de lado: encostado de um lado, do outro, no meio, ou esticado.

1. mainAxisAlignment: os seis valores

Este app desenha seis faixas cinzas. Cada uma é uma Row com os mesmos três quadrados (vermelho, verde e azul); a única diferença entre elas é o mainAxisAlignment, escrito em cima de cada faixa:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class Quadrado extends StatelessWidget {
  const Quadrado(this.cor, {super.key});

  final Color cor;

  @override
  Widget build(BuildContext context) {
    return Container(width: 48, height: 48, color: cor);
  }
}

class Faixa extends StatelessWidget {
  const Faixa(this.nome, this.alinhamento, {super.key});

  final String nome;
  final MainAxisAlignment alinhamento;

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(nome, style: const TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
        ColoredBox(
          color: Colors.grey.shade300,
          child: Row(
            mainAxisAlignment: alinhamento,
            children: const [
              Quadrado(Colors.red),
              Quadrado(Colors.green),
              Quadrado(Colors.blue),
            ],
          ),
        ),
        const SizedBox(height: 12),
      ],
    );
  }
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('mainAxisAlignment')),
        body: const Padding(
          padding: EdgeInsets.all(12),
          child: Column(
            children: [
              Faixa('start', MainAxisAlignment.start),
              Faixa('end', MainAxisAlignment.end),
              Faixa('center', MainAxisAlignment.center),
              Faixa('spaceBetween', MainAxisAlignment.spaceBetween),
              Faixa('spaceAround', MainAxisAlignment.spaceAround),
              Faixa('spaceEvenly', MainAxisAlignment.spaceEvenly),
            ],
          ),
        ),
      ),
    );
  }
}
Quadrado
Um widget nosso, bem pequeno: um Container de 48 × 48 com uma cor. Fazer um widget só para isso evita repetir a mesma linha nove vezes (aula StatelessWidget).
Faixa
Outro widget nosso: o nome em negrito e, embaixo, a faixa cinza (ColoredBox) com a Row dos três quadrados. Ele recebe o MainAxisAlignment como parâmetro.
mainAxisAlignment: alinhamento
O único parâmetro que muda de uma faixa para outra. O tipo é MainAxisAlignment, um enum do Flutter; os valores se escrevem MainAxisAlignment.center, MainAxisAlignment.spaceBetween etc.

Valor por valor (a faixa cinza tem a largura da tela, menos o padding; os quadrados são sempre os mesmos):

ValorOnde ficam os quadradosDesenho
start (o padrão)Encostados no começo (na Row, à esquerda), sem espaço entre eles[RGB ]
endEncostados no fim (na Row, à direita)[ RGB]
centerJuntos, no meio[ RGB ]
spaceBetweenO primeiro no começo, o último no fim, e o espaço que sobra repartido entre eles[R G B]
spaceAroundCada quadrado ganha o mesmo espaço em volta de si; nas pontas fica a metade do espaço do meio[ R G B ]
spaceEvenlyTodos os espaços iguais, inclusive os das pontas[ R G B ] (pontas um pouco maiores que no spaceAround)

Fazendo a conta do espaço

Os três "space…" repartem a sobra: a largura da faixa menos a largura dos filhos. Na foto, a faixa cinza tem 366 de largura (os 390 da tela menos 12 de padding de cada lado) e os três quadrados somam 3 × 48 = 144. A sobra é 366 − 144 = 222:

  • spaceBetween: 2 vãos entre os quadrados, 222 ÷ 2 = 111 cada; nas pontas, 0.
  • spaceAround: cada quadrado ganha 222 ÷ 3 = 74, metade de cada lado (37 + 37). Entre dois quadrados ficam 37 + 37 = 74; nas pontas, só 37.
  • spaceEvenly: 4 vãos iguais (antes, entre, entre, depois), 222 ÷ 4 = 55,5 cada.

É por isso que, na foto, o quadrado vermelho do spaceEvenly começa um pouco mais longe da borda que o do spaceAround.

2. mainAxisAlignment na Column: no meio da tela

Na Column, o eixo principal é o vertical. Então os mesmos valores agora movem os filhos para cima e para baixo. O uso mais comum: centralizar o conteúdo na altura da tela, como numa tela de boas-vindas.

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Icon(Icons.restaurant_menu, size: 80, color: Colors.deepOrange),
            Text('Bem-vinda, Ana!', style: TextStyle(fontSize: 28)),
            Text('32 receitas salvas', style: TextStyle(fontSize: 18)),
          ],
        ),
      ),
    );
  }
}

O ícone e os dois textos foram para o meio da altura do body: a Column ocupa toda a altura, e o center divide o espaço que sobra igualmente em cima e embaixo. Mas repare: o grupo ficou encostado à esquerda, e não no meio da largura. O ícone e o "32 receitas salvas" estão centralizados em relação ao "Bem-vinda, Ana!", não à tela. Isso não é defeito; é uma regra importante, explicada na seção 4.

3. crossAxisAlignment: de lado

Agora o outro eixo. Para ver o crossAxisAlignment numa Row, os filhos precisam ter alturas diferentes (se todos tivessem a mesma altura, não haveria o que alinhar). Este app usa faixas de 90 de altura com três caixas de 30, 60 e 45:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class Faixa extends StatelessWidget {
  const Faixa(this.nome, this.alinhamento, {super.key});

  final String nome;
  final CrossAxisAlignment alinhamento;

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(nome, style: const TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
        Container(
          height: 90,
          color: Colors.grey.shade300,
          child: Row(
            crossAxisAlignment: alinhamento,
            children: [
              Container(width: 60, height: 30, color: Colors.red),
              Container(width: 60, height: 60, color: Colors.green),
              Container(width: 60, height: 45, color: Colors.blue),
            ],
          ),
        ),
        const SizedBox(height: 12),
      ],
    );
  }
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('crossAxisAlignment')),
        body: const Padding(
          padding: EdgeInsets.all(12),
          child: Column(
            children: [
              Faixa('start', CrossAxisAlignment.start),
              Faixa('center', CrossAxisAlignment.center),
              Faixa('end', CrossAxisAlignment.end),
              Faixa('stretch', CrossAxisAlignment.stretch),
            ],
          ),
        ),
      ),
    );
  }
}
ValorNa Row (eixo cruzado = vertical)Na Column (eixo cruzado = horizontal)
center (o padrão)Cada filho no meio da alturaCada filho no meio da largura
startEncostados em cimaEncostados à esquerda
endEncostados embaixoEncostados à direita
stretchEsticados até a altura toda (a altura que você deu é ignorada)Esticados até a largura toda

Na foto, cada faixa cinza tem 90 de altura. Com start, as três caixas encostam no alto da faixa; com center, ficam no meio da altura; com end, encostam embaixo. Com stretch, as três ficaram com os 90 de altura da faixa: o height de 30, 60 e 45 que demos a cada Container foi ignorado, porque o stretch obriga cada filho a ter a altura toda. As larguras (60) não mudaram em nenhuma faixa: o eixo cruzado da Row é só o vertical.

baseline: textos de tamanhos diferentes na mesma linha

Quando uma Row junta textos de tamanhos diferentes (um preço grande e o "R$" pequeno, por exemplo), centralizar fica estranho: as letras não "pisam" no mesmo chão. O baseline alinha pela linha de base, a linha invisível onde as letras se apoiam, como as linhas de um caderno:

        body: const Row(
          crossAxisAlignment: CrossAxisAlignment.baseline,
          textBaseline: TextBaseline.alphabetic,
          children: [
            Text('R\$ ', style: TextStyle(fontSize: 18)),
            Text('12', style: TextStyle(fontSize: 64)),
            Text(',90', style: TextStyle(fontSize: 28)),
          ],
        ),

O R\$ tem uma barra porque, no Dart, o $ dentro de um texto serve para mostrar variáveis ('Olá, $nome'); a barra diz "é um cifrão de verdade". O textBaseline: TextBaseline.alphabetic é obrigatório com baseline: ele diz qual linha de base usar (a do nosso alfabeto).

4. "Mudei o alinhamento e nada aconteceu!"

Esta é a dúvida mais comum de quem começa. O alinhamento só move os filhos dentro do espaço que a Row ou a Column tem. Se não sobra espaço, não há para onde mover. Veja esta coluna, que deveria encostar os textos à direita:

        body: const Column(
          crossAxisAlignment: CrossAxisAlignment.end,
          children: [
            Text('Arroz', style: TextStyle(fontSize: 24)),
            Text('Feijão preto', style: TextStyle(fontSize: 24)),
            Text('Café', style: TextStyle(fontSize: 24)),
          ],
        ),

O end funcionou, só que dentro de um espaço pequeno. Na direção cruzada, a Column fica só com a largura do filho mais largo (o "Feijão preto"). Os outros dois foram encostados à direita desse espaço, e a coluna inteira ficou no canto esquerdo da tela, onde o Scaffold a pôs. O mesmo aconteceu na tela de boas-vindas da seção 2: o grupo foi para o meio da altura, mas ficou à esquerda. A regra:

  • no eixo principal, a Row/Column ocupa todo o espaço (por causa do MainAxisSize.max), então o mainAxisAlignment tem espaço para trabalhar;
  • no eixo cruzado, ela fica do tamanho do maior filho, então o crossAxisAlignment só alinha os filhos entre si.

Para o crossAxisAlignment valer para a tela toda, dê largura à coluna. Um jeito é um SizedBox com width: double.infinity ("a largura máxima que o pai deixar"; aula SizedBox e Spacer):

        body: const SizedBox(
          width: double.infinity,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.end,
            children: [
              Text('Arroz', style: TextStyle(fontSize: 24)),
              Text('Feijão preto', style: TextStyle(fontSize: 24)),
              Text('Café', style: TextStyle(fontSize: 24)),
            ],
          ),
        ),

E para a tela de boas-vindas ficar no meio de verdade (na altura e na largura), embrulhe a Column num Center (aula Center e Align):

        body: const Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Icon(Icons.restaurant_menu, size: 80, color: Colors.deepOrange),
              Text('Bem-vinda, Ana!', style: TextStyle(fontSize: 28)),
              Text('32 receitas salvas', style: TextStyle(fontSize: 18)),
            ],
          ),
        ),

Por que o tamanho da coluna funciona assim é o assunto da aula Como o Flutter Calcula Tamanhos.

Quando dá errado

Trocou os tipos: CrossAxisAlignment no mainAxisAlignment

          mainAxisAlignment: CrossAxisAlignment.center,
          children: [Text('A'), Text('B')],

Escreveu o valor sem o nome do tipo

          mainAxisAlignment: center,
          children: [Text('A'), Text('B')],

"Não é uma expressão constante." A mensagem confunde, porque o problema não é o const: é que center, sozinho, não existe. Como a Row é const, o Dart reclama primeiro que o valor não é constante.

Sem o const (com Row(mainAxisAlignment: center, children: const [ … ])), a mensagem fica mais clara:

lib/main.dart:15:30: Error: The getter 'center' isn't defined for the type 'MeuApp'.
 - 'MeuApp' is from 'package:app/main.dart' ('lib/main.dart').
Try correcting the name to the name of an existing getter, or defining a getter or field named 'center'.

                             ^^^^^^

"O getter center não está definido para o tipo MeuApp." Sem o nome do tipo na frente, o Dart procura um center dentro da sua própria classe (MeuApp) e não acha. Como consertar: os valores de um enum sempre levam o nome do tipo na frente: MainAxisAlignment.center.

Resumo

  • Toda Row e Column tem um eixo principal (a direção da fila) e um eixo cruzado (o de lado). Na Row, o principal é horizontal; na Column, vertical.
  • mainAxisAlignment posiciona os filhos ao longo da fila: start (padrão), end, center, spaceBetween, spaceAround, spaceEvenly.
  • crossAxisAlignment posiciona cada filho de lado: center (padrão), start, end, stretch, baseline (com textBaseline).
  • O alinhamento só funciona se sobrar espaço. Se nada mudou, a Row ou a Column está do tamanho exato dos filhos.
