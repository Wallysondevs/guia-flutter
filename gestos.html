Flutter GestureDetector

Botões já respondem ao toque (aula Botões). Mas e se você quiser que uma foto, um cartão ou um texto respondam? E se quiser reagir a dois toques rápidos (o "curtir" do Instagram), a um toque longo (o menu de opções) ou a um arrasto? Para isso existe o GestureDetector ("detector de gestos"): um embrulho invisível que transforma qualquer widget em algo tocável.

Você vai aprender
  • Como embrulhar um widget num GestureDetector e reagir a onTap, onDoubleTap e onLongPress.
  • Como arrastar um widget pela tela com onPanUpdate e o delta.
  • O que é a área de toque e por que às vezes o toque "não pega" (behavior).
  • A diferença entre GestureDetector e InkWell (a onda do Material).
  • Os erros reais: No Material widget found e o pan junto com o scale.

A ideia: o sensor de presença

Sabe a porta de shopping que abre sozinha? Ela não é uma porta especial: é uma porta comum com um sensor em cima. O sensor não muda a aparência da porta; só percebe quem chega e avisa o motor.

O GestureDetector é esse sensor. Ele não desenha nada: o que aparece é o child. Ele só fica "olhando" os toques que caem em cima do filho e chama a função certa para cada tipo de gesto:

O dedo faz…O nome do gestoParâmetro
Toca e soltatoque (tap)onTap
Toca duas vezes, rápidotoque duplo (double tap)onDoubleTap
Toca e seguratoque longo (long press)onLongPress
Encosta e arrastaarrastar (pan, drag)onPanStart, onPanUpdate, onPanEnd
Dois dedos abrindo ou fechandopinça (scale)onScaleStart, onScaleUpdate, onScaleEnd

1. Toque, toque duplo e toque longo

Um cartão de receita: um toque abre, dois toques curtem, toque longo mostra mais opções.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Receita()));

class Receita extends StatefulWidget {
  const Receita({super.key});

  @override
  State<Receita> createState() => _ReceitaState();
}

class _ReceitaState extends State<Receita> {
  bool curtida = false;
  String aviso = 'Toque no cartão';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Receitas da Ana')),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            GestureDetector(
              onTap: () {
                setState(() {
                  aviso = 'Um toque: abrir a receita';
                });
              },
              onDoubleTap: () {
                setState(() {
                  curtida = !curtida;
                  aviso = 'Dois toques: curtir';
                });
              },
              onLongPress: () {
                setState(() {
                  aviso = 'Toque longo: mais opções';
                });
              },
              child: Container(
                width: 260,
                height: 160,
                decoration: BoxDecoration(
                  color: Colors.orange.shade100,
                  borderRadius: BorderRadius.circular(16),
                ),
                child: Column(
                  mainAxisAlignment: MainAxisAlignment.center,
                  children: [
                    const Text('Bolo de cenoura', style: TextStyle(fontSize: 22)),
                    Icon(
                      curtida ? Icons.favorite : Icons.favorite_border,
                      color: Colors.red,
                      size: 40,
                    ),
                  ],
                ),
              ),
            ),
            const SizedBox(height: 24),
            Text(aviso, style: const TextStyle(fontSize: 18)),
          ],
        ),
      ),
    );
  }
}
GestureDetector(…, child: Container(…))
O sensor em volta do cartão. O toque vale em qualquer ponto do Container (260 × 160).
onTap: () { … }
Um toque simples. Uma função sem parâmetros, como o onPressed dos botões.
onDoubleTap: () { … }
Dois toques seguidos e rápidos. Troca o coração cheio/vazio.
onLongPress: () { … }
Encostar e segurar por um instante (cerca de meio segundo).
Icon(curtida ? Icons.favorite : Icons.favorite_border, …)
O coração cheio quando curtida é true, vazio quando é false.

Ao abrir, o cartão mostra o coração vazio. A Ana deu um toque no cartão, e o onTap trocou o aviso de baixo (o coração continua vazio: quem curte é o toque duplo):

O toque duplo e o toque longo não cabem numa foto parada: rode o app e experimente (com o mouse, são dois cliques rápidos e "clicar e segurar"). A caixa logo abaixo tem um toque longo para você testar.

Por que o toque simples demora um pouquinho?

Quando o GestureDetector tem onTap e onDoubleTap, ele não sabe, no primeiro toque, se vem um segundo. Então ele espera um instante: se o segundo toque não vier, aí sim chama o onTap. Por isso o toque simples fica com um pequeno atraso. Se o seu widget só precisa do toque simples, não ponha onDoubleTap.

2. Arrastar: onPanUpdate

Agora uma bolinha que segue o dedo. A ideia: guardar a posição da bolinha no estado e, a cada pedacinho de arrasto, somar o quanto o dedo andou.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Arrastar()));

class Arrastar extends StatefulWidget {
  const Arrastar({super.key});

  @override
  State<Arrastar> createState() => _ArrastarState();
}

class _ArrastarState extends State<Arrastar> {
  Offset posicao = const Offset(100, 100);

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Arraste a bolinha')),
      body: Stack(
        children: [
          Positioned(
            left: posicao.dx,
            top: posicao.dy,
            child: GestureDetector(
              onPanUpdate: (detalhes) {
                setState(() {
                  posicao += detalhes.delta;
                });
              },
              child: const CircleAvatar(radius: 40, child: Text('Ana')),
            ),
          ),
        ],
      ),
    );
  }
}
Offset posicao = const Offset(100, 100);
Um Offset é um par de números, dx (horizontal) e dy (vertical): aqui, onde fica o canto da bolinha. Começa 100 pixels da esquerda e 100 do topo.
Stack + Positioned(left: …, top: …)
O Positioned põe o filho numa posição exata dentro do Stack (veja Stack e Positioned).
onPanUpdate: (detalhes) { … }
Chamado muitas vezes por segundo enquanto o dedo arrasta. Diferente do onTap, ele recebe um parâmetro com os detalhes do movimento (um DragUpdateDetails).
detalhes.delta
Quanto o dedo andou desde a última chamada, também um Offset. Por exemplo, Offset(3, -1): 3 pixels para a direita e 1 para cima.
posicao += detalhes.delta
Soma o pedacinho à posição: a bolinha anda junto com o dedo.

Experimente na caixa abaixo: arraste a bolinha com o mouse (ou o dedo, no celular).

Experimente: arraste a bolinha. Depois, troque posicao += detalhes.delta; por posicao += Offset(detalhes.delta.dx, 0); e veja: agora ela só anda na horizontal.

}

      body: Stack(

            left: posicao.dx,
            top: posicao.dy,
            child: GestureDetector(
              onPanUpdate: (detalhes) {
                setState(() {
                  posicao += detalhes.delta;
                });
              },
              child: const CircleAvatar(radius: 40, child: Text('Ana')),
            ),
          ),
        ],
      ),
    );
  }
}

Existem também versões só horizontais ou só verticais: onHorizontalDragUpdate e onVerticalDragUpdate. Elas são úteis dentro de uma lista que rola, para não brigar com a rolagem (a lista usa o arrasto vertical; você fica com o horizontal). E para a pinça de dois dedos (zoom numa foto), use onScaleUpdate, que traz detalhes.scale (1.0 = tamanho original, 2.0 = o dobro).

3. A área de toque: behavior

Um susto comum: você põe um GestureDetector em volta de um Padding ou de uma Row com espaço vazio, e o toque só funciona em cima do texto; no espaço vazio entre as coisas, nada. Por quê? Por padrão, o GestureDetector só recebe os toques que caem em cima de algo desenhado pelo filho. Espaço vazio é "transparente" para o toque.

GestureDetector(
  behavior: HitTestBehavior.opaque,
  onTap: () { … },
  child: const Padding(
    padding: EdgeInsets.all(24),
    child: Text('Toque em qualquer lugar desta área'),
  ),
)
HitTestBehavior.O que recebe o toque
deferToChild (padrão quando há child)Só os pontos em que o filho desenhou algo
opaqueA área inteira do GestureDetector, inclusive o vazio; o que está atrás não recebe
translucentA área inteira, e deixa o toque passar também para o que está atrás

Um Container com cor já é "desenhado" em toda a área (por isso o cartão da seção 1 funciona em qualquer ponto). O problema aparece com Padding, SizedBox, Row e Container sem cor.

4. InkWell: o toque com a onda do Material

O GestureDetector é invisível: a pessoa toca e não vê resposta nenhuma até algo mudar. Nos apps Material, o toque costuma mostrar uma onda que se espalha a partir do dedo (em inglês, ink splash, "respingo de tinta"). Para ter essa onda, use o InkWell no lugar do GestureDetector. Ele tem onTap, onDoubleTap e onLongPress, mas não tem arrasto.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Tarefas()));

class Tarefas extends StatelessWidget {
  const Tarefas({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tarefas')),
      body: Column(
        children: [
          InkWell(
            onTap: () {
              ScaffoldMessenger.of(context).showSnackBar(
                const SnackBar(content: Text('Abrindo: Regar as plantas')),
              );
            },
            child: const Padding(
              padding: EdgeInsets.all(16),
              child: Row(
                children: [
                  Icon(Icons.local_florist),
                  SizedBox(width: 16),
                  Text('Regar as plantas'),
                ],
              ),
            ),
          ),
        ],
      ),
    );
  }
}

Repare: com o InkWell, a linha inteira responde, inclusive o espaço vazio à direita do texto (ele não tem o problema do behavior). A onda é desenhada no Material mais próximo acima dele, que aqui é o do Scaffold.

A Ana tocou na linha. A onda é rápida demais para a foto, mas o onTap rodou e mostrou o aviso:

Qual usar

SituaçãoO que usar
Uma ação com texto, que parece botãoUm botão de verdade: FilledButton, TextButton, IconButton (aula Botões)
Uma linha de lista tocávelListTile(onTap: …), que já tem a onda
Um cartão ou área tocável, com a onda do MaterialInkWell
Toque duplo, toque longo sem onda, arrastar, pinçaGestureDetector
Arrastar um item para fora da listaDismissible (aula Arrastar para Apagar)

Quando dá errado

InkWell sem um Material acima

A solução já vem na mensagem: ponha o InkWell dentro de um desses, ou embrulhe-o num Material.

Como consertar: normalmente o InkWell já está dentro de um Scaffold. Se ele estiver em cima de um Container colorido, a onda fica escondida atrás da cor; nesse caso, use Material(color: …, child: InkWell(…)) no lugar do Container com cor, ou um Card.

"Argumentos incorretos no GestureDetector. Ter um reconhecedor de arrasto e um de pinça é redundante: a pinça inclui o arrasto. Use só o de pinça." Com um dedo só, o onScaleUpdate também é chamado, e detalhes.focalPointDelta diz quanto o dedo andou. Como consertar: fique só com o onScale… e use o focalPointDelta para mover e o scale para o zoom.

O toque não pega no espaço vazio

Sem mensagem de erro: o toque funciona em cima do texto e não funciona ao lado dele. É o behavior da seção 3. Como consertar: behavior: HitTestBehavior.opaque, ou troque por um InkWell.

Missão final: o contador de toques

Missão: o quadrado azul soma 1 a cada toque. Faça o toque duplo somar 10 e o toque longo zerar o contador.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Contador()));

class Contador extends StatefulWidget {
  const Contador({super.key});

  @override
  State<Contador> createState() => _ContadorState();
}

class _ContadorState extends State<Contador> {
  int pontos = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Toques')),
      body: Center(
        child: GestureDetector(
          onTap: () => setState(() => pontos++),
          child: Container(
            width: 200,
            height: 200,
            color: Colors.blue,
            alignment: Alignment.center,
            child: Text(
              '$pontos',
              style: const TextStyle(fontSize: 48, color: Colors.white),
            ),
          ),
        ),
      ),
    );
  }
}

}

Resumo

  • O GestureDetector é um sensor invisível: torna qualquer widget tocável, sem mudar a aparência.
  • onTap, onDoubleTap e onLongPress para toques; onPanUpdate (com detalhes.delta) para arrastar; onScaleUpdate para pinça. Pan e scale juntos dão erro.
  • Com onDoubleTap, o onTap espera um instante para ter certeza de que não vem o segundo toque.
  • Toque que não pega no vazio: behavior: HitTestBehavior.opaque.
  • Para a onda do Material, use InkWell, que precisa de um Material acima (o Scaffold, um Card).
