Flutter Widgets Mais Usados

Esta página é para consulta: quando você lembrar que "existe um widget que faz isso", mas não lembrar o nome nem o jeito de escrever. Os widgets estão separados por assunto. Cada linha traz o que ele faz, o exemplo mínimo e o link para a aula que ensina com calma. Os widgets de arrumar a tela (Row, Column, Padding…) têm uma página própria: Widgets de Layout.

Como ler as tabelas
  • Os exemplos são o mínimo para o widget funcionar. Os parâmetros obrigatórios estão todos lá.
  • … quer dizer "outro widget qualquer aqui".
  • Um onPressed: () {} é um toque que não faz nada; com onPressed: null, o botão fica desativado (cinza).
  • A versão do lab é o Flutter 3.47 (Dart 3.13), com o Material 3, que já é o padrão.

Uma vitrine com vários deles

Antes das tabelas, um app só com widgets desta página numa tela: Card, ListTile, CircleAvatar, SwitchListTile, Slider, LinearProgressIndicator, os cinco tipos de botão e o FloatingActionButton.

import 'package:flutter/material.dart';

void main() => runApp(const VitrineApp());

class VitrineApp extends StatelessWidget {
  const VitrineApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.green),
      home: const VitrinePage(),
    );
  }
}

class VitrinePage extends StatefulWidget {
  const VitrinePage({super.key});

  @override
  State<VitrinePage> createState() => _VitrinePageState();
}

class _VitrinePageState extends State<VitrinePage> {
  bool _aberta = true;
  double _fornadas = 3;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Vitrine de widgets')),
      floatingActionButton: FloatingActionButton(
        onPressed: () {},
        child: const Icon(Icons.add),
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          const Card(
            child: ListTile(
              leading: CircleAvatar(child: Text('A')),
              title: Text('Padaria da Ana'),
              subtitle: Text('Card + ListTile + CircleAvatar'),
            ),
          ),
          SwitchListTile(
            title: const Text('Loja aberta'),
            value: _aberta,
            onChanged: (v) => setState(() => _aberta = v),
          ),
          Text('Fornadas hoje: ${_fornadas.round()}'),
          Slider(
            value: _fornadas,
            min: 0,
            max: 10,
            divisions: 10,
            onChanged: (v) => setState(() => _fornadas = v),
          ),
          LinearProgressIndicator(value: _fornadas / 10),
          const SizedBox(height: 16),
          Wrap(
            spacing: 8,
            runSpacing: 8,
            children: [
              ElevatedButton(onPressed: () {}, child: const Text('Elevated')),
              FilledButton(onPressed: () {}, child: const Text('Filled')),
              OutlinedButton(onPressed: () {}, child: const Text('Outlined')),
              TextButton(onPressed: () {}, child: const Text('Text')),
              IconButton(
                onPressed: () {},
                icon: const Icon(Icons.favorite),
                tooltip: 'Favoritar',
              ),
            ],
          ),
        ],
      ),
    );
  }
}

Repare em como os botões se diferenciam só pelo "peso" visual: o FilledButton é o mais forte (fundo verde-escuro), o ElevatedButton tem fundo claro, o OutlinedButton só contorno e o TextButton só o texto. O Wrap quebrou a fila de botões em duas linhas porque os cinco não cabiam numa só. A barra de progresso acompanha o Slider: 3 de 10 fornadas, 30% da barra.

Missão: acrescente à vitrine um campo de texto, logo depois da barra de progresso: um TextField com labelText: 'Seu nome' e borda (OutlineInputBorder). Mexa também no Slider e no Switch para ver o estado mudar.

Como achar o widget certo

  1. Pense no que você quer em português ("uma linha com ícone e texto", "um aviso que some") e procure nesta página com Ctrl+F.
  2. Se não achar, o catálogo oficial de widgets fica em docs.flutter.dev/ui/widgets, separado por categoria, e cada widget tem a sua página na documentação da API (api.flutter.dev), com exemplos.
  3. No VS Code, digite o nome do widget e aperte Ctrl+Espaço: o editor mostra os parâmetros (veja VS Code e Android Studio).
