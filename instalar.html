Instalar o Flutter

Antes do primeiro app, o Flutter precisa morar no seu computador. Instalar o Flutter é, no fundo, três coisas: baixar uma pasta (o SDK), guardar essa pasta num lugar fixo e avisar ao sistema onde ela está, para que o comando flutter funcione em qualquer terminal. Esta aula mostra os dois caminhos oficiais: o rápido, pelo VS Code, e o manual, que funciona em qualquer lugar.

Você vai aprender
  • O que você precisa ter antes de começar (Git, espaço em disco, um editor).
  • O jeito rápido: instalar pelo VS Code, com a extensão do Flutter.
  • O jeito manual: baixar o pacote, extrair na pasta develop e pôr a pasta bin no PATH, no Windows, no macOS e no Linux.
  • Como conferir a instalação com flutter --version e dart --version.
  • O que fazer quando o terminal diz que o flutter não existe.
O que é ilustrativo nesta aula

A instalação depende do seu sistema. Os passos de Windows e macOS e as telas do VS Code foram conferidos na documentação oficial (docs.flutter.dev/install, versão 3.47) e são ilustrativos: não foram fotografados. As saídas de terminal marcadas como "máquina da Ana" saíram de um Linux de verdade, com o Flutter 3.47.7.

Não quer instalar nada agora? Dá para seguir as primeiras aulas só com as caixas "Experimente" do guia: o app é compilado pelo DartPad, do Google, e aparece na própria página (precisa de internet; aula O Editor do Guia). Mas, para ter o app no seu celular, a instalação é o caminho.

A ideia: a caixa de ferramentas e o mapa

Pense numa caixa de ferramentas nova. Não adianta comprar e deixar no porta-malas de um carro qualquer: você guarda num lugar fixo da garagem e conta para todo mundo da casa onde ela fica. Aí, quando alguém pede "me passa a chave de fenda", qualquer um sabe onde buscar.

Na garagemNo computador
A caixa de ferramentasA pasta flutter (o SDK), com as ferramentas dentro de flutter/bin
O lugar fixo da garagemA pasta develop na sua pasta pessoal
O recado "a caixa fica na prateleira 3"O PATH: a lista de pastas onde o terminal procura os comandos
"Me passa a chave de fenda"Digitar flutter no terminal

O PATH (em inglês, "caminho") é uma variável do sistema com uma lista de pastas. Quando você digita um comando, o terminal procura um programa com aquele nome em cada pasta da lista, na ordem. Se a pasta flutter/bin não estiver na lista, o terminal responde que o comando não existe, mesmo com o Flutter inteiro no seu disco.

Não precisa instalar o Dart separado: o Dart vem dentro do Flutter. Se você já tem um Dart instalado por causa do Guia Dart, tudo bem; mais adiante você vê como saber qual deles o terminal está usando.

2. O jeito rápido: pelo VS Code

É o caminho que a documentação oficial chama de quick start, e o mais fácil no Windows e no macOS. O VS Code baixa o Flutter e mexe no PATH para você.

  1. Instale o Git e o VS Code (code.visualstudio.com).
  2. No VS Code, instale a extensão Flutter (da Dart Code): abra a aba de extensões (Ctrl+Shift+X), procure "Flutter" e clique em Install. Ela instala junto a extensão do Dart.
  3. Abra a paleta de comandos: menu View › Command Palette, ou Ctrl+Shift+P (Cmd+Shift+P no Mac).
  4. Digite flutter e escolha Flutter: New Project.
  5. O VS Code avisa que não achou o SDK. Clique em Download SDK.
  6. Na janela Select Folder for Flutter SDK, escolha onde guardar (por exemplo, a pasta develop na sua pasta pessoal) e clique em Clone Flutter. Aparece o aviso "Downloading the Flutter SDK. This may take a few minutes." ("baixando o SDK do Flutter; pode levar alguns minutos").
  7. No fim, clique em Add SDK to PATH. A mensagem "The Flutter SDK was added to your PATH" confirma.
  8. Se aparecer o aviso do Google Analytics, leia e responda.
  9. Feche e abra de novo todos os terminais e o próprio VS Code. Só os terminais abertos depois enxergam o PATH novo.

Pronto. Pule para a seção 4, "Conferindo".

3. O jeito manual

O caminho manual é o mesmo nos três sistemas: baixar, extrair, pôr no PATH. Use quando não quiser depender do VS Code, ou quando o jeito rápido der problema.

3.1 Baixar

Na página docs.flutter.dev/install/archive ficam os pacotes do canal stable (estável). O nome do arquivo diz o sistema e a versão:

SistemaArquivo (exemplo)
Windowsflutter_windows_3.47.7-stable.zip
macOSflutter_macos_arm64_3.47.7-stable.zip (Apple Silicon) ou flutter_macos_3.47.7-stable.zip (Intel)
Linuxflutter_linux_3.47.7-stable.tar.xz

Pegue sempre o stable mais recente. Os outros canais (beta, main) são para quem quer testar novidades antes da hora.

3.2 Extrair na pasta develop

A recomendação oficial é uma pasta develop dentro da sua pasta pessoal. Duas regras importantes para a pasta: sem espaços nem acentos no caminho, e sem precisar de administrador para escrever nela (nada de C:\Program Files).

Windows (no PowerShell, depois de criar a pasta develop):

PS> Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\flutter_windows_3.47.7-stable.zip" `
  -DestinationPath "$env:USERPROFILE\develop"

macOS:

$ mkdir -p ~/develop
$ unzip ~/Downloads/flutter_macos_arm64_3.47.7-stable.zip -d ~/develop/

Linux (antes, os pacotes que o Flutter usa, nos sistemas da família Debian/Ubuntu):

$ sudo apt-get install -y curl git unzip xz-utils zip libglu1-mesa
$ mkdir -p ~/develop
$ tar -xf ~/Downloads/flutter_linux_3.47.7-stable.tar.xz -C ~/develop/

Nos três casos, o resultado é uma pasta develop/flutter. Dentro dela, a que interessa é a bin, onde moram os comandos flutter e dart.

3.3 Pôr a pasta bin no PATH

Windows:

  1. Aperte Windows+Pause (ou procure "variáveis de ambiente" no menu Iniciar) e vá em Configurações avançadas do sistema › Variáveis de Ambiente.
  2. Em Variáveis de usuário, selecione Path e clique em Editar.
  3. Clique em Novo e escreva %USERPROFILE%\develop\flutter\bin.
  4. Use Mover para Cima até a linha ficar no topo.
  5. Clique em OK nas três janelas e feche e abra de novo os terminais e o editor.

macOS (o terminal padrão é o zsh): acrescente uma linha no fim do arquivo ~/.zprofile:

export PATH="$HOME/develop/flutter/bin:$PATH"

Linux (com o bash, o padrão do Ubuntu): acrescente a mesma linha no fim do ~/.bashrc, com um comando só:

$ echo 'export PATH="$HOME/develop/flutter/bin:$PATH"' >> ~/.bashrc
export PATH=
Muda a variável PATH e a "exporta" para os programas abertos a partir daquele terminal.
"$HOME/develop/flutter/bin
A pasta nova, com o caminho completo ($HOME é a sua pasta pessoal; na máquina da Ana, /home/ana).
:$PATH"
Os dois-pontos separam as pastas da lista, e $PATH é a lista antiga. Ou seja: "a pasta do Flutter primeiro, e depois tudo o que já estava lá". Esquecer o :$PATH apaga a lista antiga, e aí nem o ls funciona.
>> ~/.bashrc
Acrescenta a linha no fim do arquivo que o bash lê toda vez que abre. Com > (um só), o arquivo inteiro seria substituído: cuidado.

Depois, abra um terminal novo (ou rode source ~/.bashrc no atual).

Quando dá errado

"Comando 'flutter' não encontrado"

Numa máquina da Ana sem o Flutter no PATH, o terminal do Ubuntu responde assim (as mensagens do próprio Ubuntu saem em português):

$ flutter --version
Comando 'flutter' não encontrado, você quis dizer:
  comando 'fluster' do deb fluster (1.0.1+really0.6.0-2)
Experimente: sudo apt install <deb name>

O terminal procurou um programa chamado flutter em todas as pastas do PATH e não achou. O Ubuntu ainda tenta ajudar: sugere um programa de nome parecido, o fluster, que não tem nada a ver com o Flutter. Não instale o fluster. No Windows, a mesma situação aparece como "'flutter' não é reconhecido como um comando interno ou externo" (ilustrativo).

Como consertar: (1) confira se a pasta existe mesmo (no Linux, ls ~/develop/flutter/bin); (2) confira se a linha do PATH está certa e aponta para a pasta bin, não para a pasta flutter; (3) abra um terminal novo.

Esqueceu o :$PATH 
$ export PATH="$HOME/develop/flutter/bin"
$ ls
Comando 'ls' está disponível nos seguintes locais
 * /bin/ls
 * /usr/bin/ls
O comando não foi localizado porque '/usr/bin:/bin' não está incluído na variável de ambiente PATH.
ls: comando não encontrado

A Ana escreveu a linha do PATH sem o :$PATH do fim. A lista antiga sumiu, e agora o terminal só procura comandos na pasta do Flutter: até o ls deixou de existir. A mensagem do Ubuntu explica direitinho: o ls está em /bin/ls, mas /usr/bin:/bin não está no PATH. Como consertar: feche esse terminal (a mudança feita com export vale só para ele) e, se a linha errada foi parar no ~/.bashrc, corrija-a lá, com :$PATH no fim.

A pasta tem espaço ou acento

Instalar em C:\Users\Ana Maria\Meus Programas\flutter ou em C:\Program Files costuma dar erros estranhos depois, na hora de compilar o app de Android (ferramentas que se perdem no espaço do caminho, ou que não têm permissão para escrever ali). Como consertar: mova a pasta flutter para um caminho simples, como C:\develop\flutter, e corrija o PATH.

Windows: sumiu o flutter.bat

Depois de extrair, a pasta flutter\bin está sem o arquivo flutter.bat. A documentação oficial explica: o antivírus pode ter colocado o arquivo em quarentena. Como consertar: marque a pasta do Flutter como confiável no antivírus e extraia de novo.

Resumo

  • Instalar o Flutter é baixar o SDK, guardar numa pasta fixa (develop, sem espaços nem acentos) e pôr a pasta flutter/bin no PATH.
  • O jeito mais fácil é pelo VS Code: extensão Flutter, Flutter: New Project, Download SDK, Add SDK to PATH.
  • O jeito manual: pacote do canal stable, extrair, e o PATH pelas Variáveis de Ambiente (Windows), no ~/.zprofile (macOS) ou no ~/.bashrc (Linux).
  • O Dart vem junto com o Flutter.
  • Confira com flutter --version e dart --version, sempre num terminal aberto depois de mexer no PATH.
  • "Comando não encontrado" quase sempre é PATH: confira a pasta, o :$PATH e abra um terminal novo.
  • O próximo passo é o flutter doctor, que confere o resto da máquina.
