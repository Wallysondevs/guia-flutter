Flutter Widgets de Layout

Widgets de layout não aparecem na tela: eles arrumam os outros. Põem um embaixo do outro, dão espaço, centralizam, empilham. Esta página reúne todos os que o guia usa, com o que cada um faz, o jeito mínimo de escrever e o link para a aula. Para os widgets que aparecem (texto, botões, campos), veja Widgets Mais Usados.

A regra de ouro do layout

"As restrições descem, os tamanhos sobem, e o pai decide a posição." Cada widget recebe do pai os limites de tamanho (mínimo e máximo), escolhe o próprio tamanho dentro deles e avisa o pai, que então decide onde colocá-lo. Quase todo susto de layout (o overflow, a lista que não aparece) se explica por essa regra. A aula Como o Flutter Calcula Tamanhos mostra em detalhe.

Um laboratório de layout

Um app com três dos arranjos mais comuns: uma Row com Expanded (as caixas dividem a largura em partes), uma Row com spaceBetween (o espaço sobra entre as caixas) e um Stack (uma coisa por cima da outra).

import 'package:flutter/material.dart';

void main() => runApp(const LayoutApp());

class LayoutApp extends StatelessWidget {
  const LayoutApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.blue),
      home: Scaffold(
        appBar: AppBar(title: const Text('Laboratório de layout')),
        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              const Text('Row com Expanded (flex 1, 2 e 1):'),
              const SizedBox(height: 8),
              Row(
                children: [
                  Expanded(flex: 1, child: Container(height: 60, color: Colors.red)),
                  Expanded(flex: 2, child: Container(height: 60, color: Colors.green)),
                  Expanded(flex: 1, child: Container(height: 60, color: Colors.blue)),
                ],
              ),
              const SizedBox(height: 24),
              const Text('Row com spaceBetween:'),
              const SizedBox(height: 8),
              Row(
                mainAxisAlignment: MainAxisAlignment.spaceBetween,
                children: [
                  Container(width: 60, height: 60, color: Colors.orange),
                  Container(width: 60, height: 60, color: Colors.purple),
                  Container(width: 60, height: 60, color: Colors.teal),
                ],
              ),
              const SizedBox(height: 24),
              const Text('Stack com Positioned:'),
              const SizedBox(height: 8),
              SizedBox(
                height: 120,
                child: Stack(
                  children: [
                    Container(color: Colors.amber.shade100),
                    const Positioned(
                      right: 8,
                      bottom: 8,
                      child: Icon(Icons.star, size: 48, color: Colors.amber),
                    ),
                    const Center(child: Text('Centro do Stack')),
                  ],
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Na primeira linha, a verde ocupa metade da largura (2 de 4 partes) e a vermelha e a azul, um quarto cada. Na segunda, os quadrados têm 60 pixels fixos, e o spaceBetween mandou o primeiro para a esquerda, o último para a direita e dividiu a sobra entre eles. No Stack, os três filhos ficaram na ordem da lista: o fundo amarelo embaixo, a estrela por cima no canto (o Positioned) e o texto centralizado por cima de tudo.

Missão: na primeira linha, troque o flex: 2 da caixa verde por flex: 4. Com 1 + 4 + 1 = 6 partes, que fração da largura a verde passa a ocupar? Depois, experimente trocar o spaceBetween da segunda linha por spaceEvenly e por center.

Alinhamento em Row e Column

O eixo principal (main axis) é a direção em que os filhos se enfileiram: horizontal na Row, vertical na Column. O eixo cruzado (cross axis) é o outro. Os detalhes, com fotos de cada valor, estão em Alinhamento.

mainAxisAlignment:O que faz no eixo principal
MainAxisAlignment.startTudo no começo (o padrão)
MainAxisAlignment.centerTudo no meio
MainAxisAlignment.endTudo no fim
MainAxisAlignment.spaceBetweenO primeiro no começo, o último no fim, o espaço dividido entre eles
MainAxisAlignment.spaceAroundEspaço igual em volta de cada filho (meio espaço nas pontas)
MainAxisAlignment.spaceEvenlyEspaços todos iguais, inclusive nas pontas
crossAxisAlignment:O que faz no eixo cruzado
CrossAxisAlignment.centerCada filho no meio (o padrão)
CrossAxisAlignment.startCada filho encostado no começo (à esquerda numa Column, em cima numa Row)
CrossAxisAlignment.endCada filho encostado no fim
CrossAxisAlignment.stretchEstica cada filho para ocupar o eixo cruzado inteiro
CrossAxisAlignment.baselineAlinha textos de tamanhos diferentes pela linha de base (pede também textBaseline)
mainAxisSize:O que faz
MainAxisSize.maxOcupa todo o eixo principal disponível (o padrão)
MainAxisSize.minOcupa só o tamanho dos filhos (bom dentro de Center, de botões, de cartões)

empurrar um item para o fim da linhaSpacer() antes dele
um selo por cima de uma fotoStack + Positioned
etiquetas que quebram de linhaWrap
uma tela comprida que rolaSingleChildScrollView (poucos itens) ou ListView (muitos)
