Flutter Botões

"Salvar receita", "Adicionar ao carrinho", "Cancelar": um app sem botões só serve para olhar. O Material 3 tem uma família de botões, cada um com um "peso" visual diferente, do mais chamativo ao mais discreto. Nesta aula a Ana conhece a família toda, aprende a dizer o que cada botão faz quando é tocado e a desligar um botão.

Você vai aprender
  • Os cinco botões do dia a dia: FilledButton, ElevatedButton, OutlinedButton, TextButton e IconButton.
  • O onPressed: a função que roda no toque.
  • A desligar um botão com onPressed: null.
  • Botões com ícone e texto (.icon).
  • A mudar as cores de um botão com styleFrom.
  • Qual botão usar em cada situação.
  • Os erros reais: esquecer o onPressed e chamar a função em vez de passá-la.

Todos os apps desta aula foram compilados com o Flutter 3.47.7 do laboratório e fotografados numa tela do tamanho de um celular. Os toques também são de verdade: a ferramenta de fotos do lab clicou nos botões.

A ideia: o volume da voz

Numa conversa, você não fala tudo no mesmo volume. O importante você fala mais alto; o detalhe, baixinho. Uma tela também: a ação principal ("Salvar") precisa gritar, e as secundárias ("Cancelar", "Ver detalhes") só sussurram.

Os botões do Material 3 são esses volumes, do mais alto para o mais baixo: FilledButton (preenchido), ElevatedButton (com sombra), OutlinedButton (só o contorno) e TextButton (só o texto).

1. A família inteira

}

  @override
  Widget build(BuildContext context) {
    return MaterialApp(

        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              FilledButton(
                onPressed: () {},
                child: const Text('FilledButton'),
              ),
              ElevatedButton(
                onPressed: () {},
                child: const Text('ElevatedButton'),
              ),
              OutlinedButton(
                onPressed: () {},
                child: const Text('OutlinedButton'),
              ),
              TextButton(
                onPressed: () {},
                child: const Text('TextButton'),
              ),
              IconButton(
                onPressed: () {},
                icon: const Icon(Icons.favorite),
              ),
            ],
          ),
        ),
      ),

}
FilledButton( ... )
O botão preenchido com a cor principal do tema. O mais chamativo: para a ação mais importante da tela.
onPressed: () {}
"Ao ser pressionado": a função que roda quando o botão é tocado. Aqui, () {} é uma função vazia, sem nome (uma função anônima, como você viu no Dart): o botão funciona, mas não faz nada ainda.
child: const Text('...')
O que aparece dentro do botão. Quase sempre um Text, mas pode ser qualquer widget.
ElevatedButton
Fundo claro e uma sombra leve, como se flutuasse.
OutlinedButton
Só o contorno, sem fundo.
TextButton
Só o texto, na cor do tema. O mais discreto.
IconButton(onPressed: ..., icon: ...)
Um botão que é só um ícone. Repare: em vez de child, ele usa icon.
Column(...)
Põe os botões um embaixo do outro (aula Row e Column).

2. Fazendo alguma coisa no toque

O onPressed recebe uma função. Tudo o que estiver dentro das chaves roda a cada toque. Para ver isso acontecer sem saber ainda mudar a tela (isso é o setState, aula setState), a Ana usa o debugPrint, que escreve no console:

        body: Center(
          child: FilledButton(
            onPressed: () {
              debugPrint('Receita salva!');
            },
            child: const Text('Salvar receita'),
          ),
        ),
onPressed: () { ... }
A função com uma linha dentro. Ela não roda quando o app abre: o botão a guarda e só a chama no toque.
debugPrint('Receita salva!');
Escreve no console (o terminal do flutter run, ou o console do navegador). É o print recomendado no Flutter.

3. Botão desligado: onPressed: null

Às vezes o botão não pode ser usado ainda: "Finalizar compra" com o carrinho vazio. No Flutter não existe um parâmetro "desligado": o botão fica desligado quando o onPressed é null.

            children: [
              FilledButton(
                onPressed: () {},
                child: const Text('Ligado'),
              ),
              const FilledButton(
                onPressed: null,
                child: Text('Desligado'),
              ),
            ],
onPressed: null
Sem função para chamar, o botão fica desligado: cinza, e o toque não faz nada. O Flutter faz isso sozinho, em todos os tipos de botão.
const FilledButton(...)
Com null no lugar da função, o botão inteiro pode ser const.

Na prática, o onPressed vem de uma condição: onPressed: carrinhoVazio ? null : finalizar. Você vai fazer isso quando aprender estado, em setState.

O mesmo botão, num construtor com nome que aceita um ícone. Todos os quatro botões com texto têm o seu .icon.

O ícone, à esquerda (aula Ícones).
label:

O estilo do botão.
FilledButton.styleFrom( ... )
"Estilo a partir de": monta o estilo só com o que você disser. Cada botão tem o seu: ElevatedButton.styleFrom, TextButton.styleFrom...

Qual botão usar?

BotãoPesoQuando usarExemplo
FilledButtonMáximoA ação principal da tela. Uma por tela, de preferência."Salvar receita", "Finalizar compra"
FilledButton.tonalAltoImportante, mas não a principal (fundo num tom mais suave)."Adicionar ingrediente"
ElevatedButtonMédioQuando o botão precisa se destacar de um fundo com imagem ou cor.Botão sobre uma foto
OutlinedButtonMédioAções importantes que não são a principal; o par do FilledButton."Cancelar", "Voltar"
TextButtonBaixoAções secundárias, links, botões de diálogos."Ver detalhes", "Esqueci a senha"
IconButtonVariávelAções conhecidas pelo ícone, em barras e cartões.Favoritar, buscar, apagar
FloatingActionButtonMáximoA ação principal da tela inteira, flutuando (aula Scaffold)."Nova receita"

Quando dá errado

Os dois erros abaixo são de compilação, os mais comuns com botões. O compilador do flutter run recusa o código e o app não abre. (O arquivo é o da seção 2; o botão começa na linha 16.)

Esqueceu o onPressed 
        body: const Center(
          child: FilledButton(
            child: Text('Salvar receita'),
          ),
        ),

lib/main.dart:16:30: Error: Required named parameter 'onPressed' must be provided.
          child: FilledButton(
                             ^
/home/ana/flutter/packages/flutter/lib/src/material/filled_button.dart:81:9: Context: Found this candidate, but the arguments don't match.
  const FilledButton({                     « o código do próprio Flutter, na pasta onde ele está instalado
        ^^^^^^^^^^^^
Required named parameter 'onPressed' must be provided.
"O parâmetro com nome obrigatório onPressed precisa ser informado". Todo botão exige o onPressed, nem que seja null: o Flutter quer que você diga, de propósito, se o botão está ligado ou não.
Context: Found this candidate, but the arguments don't match.
"Achei este construtor, mas os argumentos não batem": aponta para o construtor do FilledButton, dentro do próprio Flutter, onde o onPressed é declarado como required.

Como consertar: onPressed: () {} (ou onPressed: null, se ele deve ficar desligado).

Chamou a função em vez de passá-la 
        body: Center(
          child: FilledButton(
            onPressed: debugPrint('Receita salva!'),
            child: const Text('Salvar receita'),
          ),
        ),

lib/main.dart:17:34: Error: This expression has type 'void' and can't be used.
            onPressed: debugPrint('Receita salva!'),
                                 ^

"Esta expressão tem o tipo void e não pode ser usada". Com os parênteses, debugPrint('...') roda na hora e o que vai para o onPressed é o resultado, que é void (nada). O botão queria uma função para guardar e chamar depois, no toque. É a diferença entre entregar a receita do bolo e entregar o bolo já comido.

Como consertar: embrulhe numa função: onPressed: () { debugPrint('Receita salva!'); }, ou com a seta, onPressed: () => debugPrint('Receita salva!'). Se você já tem uma função sem parâmetros, como void salvar() {...}, passe só o nome, sem parênteses: onPressed: salvar.

Referência rápida

EscritaO que faz
FilledButton(onPressed: () {}, child: Text('...'))Botão preenchido
ElevatedButton / OutlinedButton / TextButtonOs outros botões de texto, mesmos parâmetros
IconButton(onPressed: ..., icon: Icon(...))Botão de ícone (usa icon, não child)
onPressed: nullBotão desligado

Resumo

  • Os botões do Material 3, do mais forte ao mais discreto: FilledButton, ElevatedButton, OutlinedButton, TextButton; e o IconButton para ícones.
  • onPressed recebe a função que roda no toque: () { ... }. Passe a função, não o resultado dela.
  • onPressed: null desliga o botão.
  • .icon(icon: ..., label: ...) põe ícone e texto.
  • style: XButton.styleFrom(backgroundColor: ..., foregroundColor: ...) muda as cores de um botão; para o app inteiro, use o tema.
