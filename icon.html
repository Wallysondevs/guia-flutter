Flutter Icon: ícones

Uma lupa para buscar, um coração para favoritar, um carrinho para a lojinha: os ícones dizem o que um botão faz sem precisar de palavras. O Flutter já vem com milhares de ícones do Material prontos, sem baixar nada. Basta o widget Icon e o nome do ícone.

Você vai aprender
  • A mostrar um ícone com Icon(Icons.nome).
  • A mudar o tamanho (size) e a cor (color).
  • As variantes de cada ícone: preenchido, _outlined, _rounded, _sharp.
  • A pôr um ícone ao lado de um texto.
  • O semanticLabel, para quem usa leitor de tela.
  • Os erros reais: um ícone com nome que não existe e um nome entre aspas.

Todos os apps desta aula foram compilados com o Flutter 3.47.7 do laboratório e fotografados numa tela do tamanho de um celular.

A ideia: as placas de trânsito

Uma placa com um garfo e uma faca diz "restaurante" para qualquer pessoa, em qualquer língua, mesmo de longe. Os ícones são as placas do seu app. E, como as placas, eles funcionam melhor quando são os conhecidos: todo mundo sabe o que uma lixeira faz.

No Flutter, o "catálogo de placas" é a classe Icons, e o widget que pendura a placa na tela é o Icon.

1. O primeiro ícone

import 'package:flutter/material.dart';

void main() {
  runApp(const MeuApp());
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Center(
          child: Icon(Icons.cake),
        ),
      ),
    );
  }
}
Icon( ... )
O widget que desenha um ícone.
Icons.cake
Qual ícone: o bolo. Icons é uma classe com uma constante para cada ícone do Material (Icons.home, Icons.search, Icons.favorite...). Os nomes são em inglês, em minúsculas, com _ separando as palavras: Icons.shopping_cart.
Como achar o nome de um ícone

O catálogo completo, com busca, está em fonts.google.com/icons (os "Material Symbols"; a maioria tem o mesmo nome na classe Icons) e na documentação da classe Icons, que mostra o desenho de cada um. No VS Code, digite Icons. e comece a escrever em inglês: o editor sugere os nomes e mostra o desenho ao lado.

2. Tamanho e cor

        body: const Center(
          child: Icon(
            Icons.cake,
            size: 96,
            color: Colors.pink,
          ),
        ),
size: 96
O tamanho do ícone, em pontos lógicos (a mesma medida do fontSize). O padrão é 24. O ícone é desenhado como uma letra de uma fonte, por isso fica nítido em qualquer tamanho.
color: Colors.pink
A cor. Sem ela, o ícone usa a cor do tema (a mesma do texto, um cinza bem escuro).

3. As variantes: preenchido, contorno, arredondado

A maioria dos ícones vem em quatro "estilos de traço". O nome é o mesmo, com um final diferente:

        body: const Center(
          child: Row(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Icon(Icons.favorite, size: 48),
              Icon(Icons.favorite_outlined, size: 48),
              Icon(Icons.favorite_border, size: 48),
              Icon(Icons.home, size: 48),
              Icon(Icons.home_outlined, size: 48),
              Icon(Icons.home_rounded, size: 48),
              Icon(Icons.home_sharp, size: 48),
            ],
          ),
        ),
Row(children: [...])
Põe os ícones lado a lado (aula Row e Column).
Icons.home
O padrão: preenchido.
Icons.home_outlined
Só o contorno, por dentro vazio.
Icons.home_rounded / Icons.home_sharp
Cantos arredondados / cantos retos e pontudos.
Icons.favorite_border
O coração "vazio". Alguns ícones antigos têm o contorno com outro nome, como este; e alguns, como o favorite_outlined, existem mas saem iguais ao preenchido (veja a foto abaixo). Confira no catálogo antes de usar.

A foto mostra as pegadinhas: o favorite_outlined saiu cheio, igual ao favorite; o coração vazio é o favorite_border. Já nas casinhas o _outlined funciona como esperado. E o _rounded e o _sharp só mudam os cantos, uma diferença que mal se vê neste tamanho.

Um estilo só

Escolha uma variante e use-a no app inteiro: misturar contornos e preenchidos na mesma tela parece desleixo. Um costume comum é o contorno para o normal e o preenchido para o selecionado (o coração vazio que fica cheio ao favoritar, aula setState).

4. Ícone ao lado do texto

Ícone sozinho é placa; ícone com texto é placa com legenda. Para pôr os dois lado a lado, use uma Row:

        body: const Column(
          children: [
            Row(
              children: [
                Icon(Icons.timer, color: Colors.deepOrange),
                Text(' 50 minutos'),
              ],
            ),
            Row(
              children: [
                Icon(Icons.people, color: Colors.deepOrange),
                Text(' 8 porções'),
              ],
            ),
            Row(
              children: [
                Icon(
                  Icons.star,
                  color: Colors.amber,
                  semanticLabel: 'Receita favorita',
                ),
                Text(' Favorita'),
              ],
            ),
          ],
        ),
Text(' 50 minutos')
O espaço no começo do texto afasta a palavra do ícone. É o jeito mais rápido; o jeito "certo" é um SizedBox(width: 8) entre os dois (aula SizedBox e Spacer).
semanticLabel: 'Receita favorita'
O que o leitor de tela (o app que lê a tela em voz alta para quem não enxerga) fala quando passa pelo ícone. Sem ele, o ícone é mudo. Use em ícones que significam algo sem texto do lado.

Formas diferentes: Icons, CupertinoIcons e imagens

FormaQuando usar
Icon(Icons.home)Quase sempre. Os ícones do Material vêm com o Flutter e combinam com o MaterialApp.
Icon(CupertinoIcons.home)Para o visual de iPhone. Precisa do import 'package:flutter/cupertino.dart'; e do pacote cupertino_icons, que o flutter create já põe no pubspec.yaml.
Image.asset('assets/logo.png', width: 24)Para um desenho que não existe em nenhum catálogo, como o logotipo da lojinha (aula Imagens).
IconButton(icon: Icon(...), onPressed: ...)Quando o ícone é um botão (aula Botões).

Quando dá errado

Os dois erros abaixo são de compilação: o compilador do flutter run recusa o código e o app não abre. (Nos dois, o Icon está na linha 16 do arquivo da seção 1.)

Um ícone que não existe 
        body: const Center(
          child: Icon(Icons.bolo),
        ),

lib/main.dart:16:29: Error: Member not found: 'bolo'.
          child: Icon(Icons.bolo),
                            ^^^^

"Membro não encontrado: bolo". A classe Icons não tem nada com esse nome: os nomes são em inglês. A vantagem é que o erro aparece antes de o app rodar, nunca como um ícone em branco na tela. Como consertar: procure o nome certo no catálogo (Icons.cake) ou deixe o VS Code sugerir.

O nome do ícone entre aspas 
        body: const Center(
          child: Icon('cake'),
        ),

lib/main.dart:16:23: Error: The argument type 'String' can't be assigned to the parameter type 'IconData?'.
 - 'IconData' is from 'package:flutter/src/widgets/icon_data.dart'.   « caminho do arquivo cortado
          child: Icon('cake'),
                      ^

"Uma String não pode ir num parâmetro do tipo IconData?". O Icon não procura o ícone pelo nome escrito: ele quer um IconData, o "desenho" do ícone, que é o que as constantes da classe Icons guardam. Como consertar: Icon(Icons.cake), sem aspas.

Resumo

  • Icon(Icons.nome) mostra um dos ícones do Material, que já vêm com o Flutter.
  • size (padrão 24) e color mudam tamanho e cor.
  • Variantes: _outlined, _rounded, _sharp; use um estilo só no app.
  • Ícone com texto: uma Row com os dois.
  • semanticLabel dá voz ao ícone para o leitor de tela.
  • Nome errado de ícone é erro de compilação; o nome vai sem aspas.
