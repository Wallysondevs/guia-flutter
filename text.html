Flutter Text

Nome da receita, preço do produto, quantidade de itens no carrinho: quase tudo o que um app mostra é texto. No Flutter, todo texto na tela é um widget Text. Nesta aula a Ana usa o Text para montar o cartão de uma receita e descobre o que fazer quando o texto é grande demais para o espaço que tem.

Você vai aprender
  • A anatomia do Text: a string e os parâmetros com nome.
  • A mostrar valores de variáveis com a interpolação do Dart ('$nome').
  • Como o texto quebra de linha sozinho, e a quebrar onde você quer com \n.
  • A alinhar com textAlign.
  • A limitar o número de linhas com maxLines e cortar com reticências (overflow).
  • Alternativas: SelectableText (texto que dá para copiar) e Text.rich (vários estilos numa frase).
  • Os erros reais: um número no lugar da string e uma string que não fecha.

Todos os apps desta aula foram compilados com o Flutter estável do laboratório e fotografados numa tela do tamanho de um celular. As cores, tamanhos e negrito ficam para a próxima aula, Estilos de Texto.

A ideia: uma etiqueta

Pense numa etiquetadora de mercado: você digita o texto, ela imprime uma etiqueta e você cola onde quiser. A etiqueta não decide onde fica; ela só carrega o texto. O tamanho dela depende do texto e do espaço onde ela é colada.

O Text é essa etiqueta. Ele recebe uma string e a desenha, e quem decide onde ele fica é o widget de fora (o Center, o Scaffold, uma coluna).

1. O Text mais simples

import 'package:flutter/material.dart';

void main() {
  runApp(const MeuApp());
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Text('Bolo de cenoura com cobertura de chocolate'),
      ),
    );
  }
}
Text( ... )
O widget de texto. Ele desenha uma string na tela com o estilo padrão do tema.
'Bolo de cenoura com cobertura de chocolate'
A string. É o primeiro parâmetro, sem nome (um parâmetro posicional, como você viu no Dart) e obrigatório. Todos os outros parâmetros do Text têm nome e são opcionais.
const
Como o texto nunca muda, o widget pode ser const. Isso deixa o Flutter reaproveitar o widget em vez de criar de novo.

2. Texto com variáveis: interpolação

Quase sempre o texto vem de uma variável: o nome da receita, o número de porções. Use a interpolação do Dart: $variavel ou ${expressão} dentro da string.

import 'package:flutter/material.dart';

void main() {
  runApp(const MeuApp());
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    const receita = 'Bolo de cenoura';
    const porcoes = 8;
    const minutos = 40;

    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Center(
          child: Text('$receita: $porcoes porções, ${minutos + 10} minutos'),
        ),
      ),
    );
  }
}
$receita
Põe o valor da variável receita dentro do texto.
$porcoes
Um int dentro do texto: a interpolação transforma o número em texto sozinha.
${minutos + 10}
Uma conta dentro do texto precisa de chaves: ${...}. Saem 50 minutos (40 de forno + 10 de preparo).
const receita = ...
As variáveis são const, então o Text que as usa também pode ser const. Se elas fossem final ou viessem de fora, o const do Text teria de sair.

3. Quebra de linha: sozinha e com \n

Quando o texto não cabe na largura, o Text quebra a linha sozinho, entre as palavras. E, quando você quer quebrar num ponto exato, usa o \n ("nova linha") dentro da string:

        body: const Text(
          'Modo de preparo:\n'
          'Bata no liquidificador as cenouras, os ovos e o óleo. '
          'Misture com o açúcar e a farinha, junte o fermento e '
          'leve ao forno médio por 40 minutos.',
        ),
\n
Uma quebra de linha forçada: o texto continua na linha de baixo, mesmo que ainda houvesse espaço.
'...' '...' '...'
Strings escritas uma ao lado da outra, sem nada entre elas, viram uma string só (é uma regra do Dart). É o jeito de escrever um texto comprido em várias linhas do código sem mudar o texto na tela. Repare no espaço no fim de cada pedaço: sem ele, as palavras grudariam.

4. Alinhamento: textAlign

        body: const Text(
          'Bata no liquidificador as cenouras, os ovos e o óleo. '
          'Misture com o açúcar e a farinha.',
          textAlign: TextAlign.center,
        ),
textAlign: TextAlign.center
Centraliza cada linha dentro do espaço do texto. Os outros valores: TextAlign.left, .right, .justify (justificado, como jornal), .start e .end (começo e fim na direção do texto).
textAlign não é o mesmo que Center

O textAlign alinha as linhas dentro do espaço que o texto ocupa. Se o texto é curto e ocupa só uma linha, esse espaço tem o tamanho do próprio texto, e não há para onde alinhar: Text('Oi', textAlign: TextAlign.center) continua no canto. Para pôr o texto no meio da tela, use o Center em volta (aula Center e Align). Foi o que o lab fotografou com o Oi sozinho no body:

5. Texto grande demais: maxLines e overflow

Numa lista de receitas, cada item tem espaço para uma ou duas linhas. Se o nome é comprido, você quer cortá-lo com reticências (...), e não empurrar o resto da tela para baixo:

        body: const Column(
          children: [
            Text(
              'Bolo de cenoura com cobertura de chocolate meio amargo e raspas de laranja',
            ),
            Divider(),
            Text(
              'Bolo de cenoura com cobertura de chocolate meio amargo e raspas de laranja',
              maxLines: 1,
              overflow: TextOverflow.ellipsis,
            ),
            Divider(),
            Text(
              'Bolo de cenoura com cobertura de chocolate meio amargo e raspas de laranja',
              maxLines: 1,
              overflow: TextOverflow.fade,
            ),
          ],
        ),
Column(children: [...])
Põe os widgets um embaixo do outro (aula Row e Column). O Divider é a linha fina entre eles.
maxLines: 1
No máximo uma linha. O que passar disso não aparece.
overflow: TextOverflow.ellipsis
"Transbordamento: reticências". O que não cabe é trocado por … no fim.
overflow: TextOverflow.fade
O fim do texto vai sumindo, num degradê, em vez das reticências.

WidgetQuando usar
TextQuase sempre. Títulos, rótulos, nomes, preços.
SelectableTextQuando o usuário vai querer copiar o texto: um código de rastreio, uma chave Pix, um endereço.
Text.rich(TextSpan(...))Quando uma frase só tem pedaços com estilos diferentes (uma palavra em negrito, um preço em vermelho). Os estilos são o assunto de Estilos de Texto.

Quando dá errado

Os dois erros abaixo são de compilação: o app nem abre, e o compilador do flutter run mostra o arquivo, a linha e a coluna, com ^ embaixo do ponto exato.

Um número no lugar da string

A Ana quer mostrar as porções e escreveu a variável direto no Text (o arquivo é o da seção 2, com const porcoes = 8;; o Text está na linha 18):

        body: const Center(
          child: Text(porcoes),
        ),

lib/main.dart:18:23: Error: The argument type 'int' can't be assigned to the parameter type 'String'.
          child: Text(porcoes),
                      ^
lib/main.dart:18:23:
Linha 18, coluna 23: bem em cima do porcoes.
The argument type 'int' can't be assigned to the parameter type 'String'.
"O argumento do tipo int não pode ser passado para o parâmetro do tipo String". O Text só aceita texto; o Dart não transforma o número em texto sozinho.

Como consertar: transforme em texto, com interpolação (Text('$porcoes'), ou melhor, Text('$porcoes porções')) ou com Text(porcoes.toString()).

A aspa que não fecha 
        body: const Text('Bolo de cenoura),

lib/main.dart:15:26: Error: String starting with ' must end with '.
        body: const Text('Bolo de cenoura),
                         ^^^^^^^^^^^^^^^^^^
lib/main.dart:12:23: Error: Can't find ')' to match '('.
    return MaterialApp(
                      ^
String starting with ' must end with '.
"Uma string que começa com ' tem de terminar com '". Os ^ sublinham do começo da string até o fim da linha: o Dart engoliu o ), como parte do texto.
Can't find ')' to match '('.
"Não acho o ) que fecha este (". É consequência do primeiro erro: como o ) virou texto, o MaterialApp( da linha 12 ficou sem par. Quando aparecem vários erros, conserte o primeiro e compile de novo; muitas vezes os outros somem junto.

Como consertar: feche a aspa: Text('Bolo de cenoura').

O texto que "não aparece": está no canto

Não é erro, mas confunde todo iniciante: um Text direto no body fica colado no canto de cima, à esquerda (fotos das seções 1 e 4), e o textAlign não o tira de lá. Para centralizar na tela, embrulhe num Center; para afastar das bordas, num Padding (aula Padding e Margem).

Resumo

  • Text('...') mostra uma string na tela. A string é o primeiro parâmetro, sem nome, e precisa ser String.
  • Para mostrar variáveis, use a interpolação: '$nome', '${conta}'.
  • O texto quebra a linha sozinho quando não cabe; \n força a quebra.
  • textAlign alinha as linhas dentro do espaço do texto; para centralizar na tela, use Center.
  • maxLines + overflow: TextOverflow.ellipsis cortam o texto com reticências.
  • SelectableText deixa copiar; Text.rich mistura estilos numa frase.
