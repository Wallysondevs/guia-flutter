Flutter SizedBox e Spacer

Duas peças pequenas que você vai usar em quase toda tela. O SizedBox ("caixa com tamanho") é uma caixa invisível de tamanho fixo: serve para dar um tamanho a um widget ("este botão tem 56 de altura") ou, vazio, para pôr espaço entre dois widgets ("16 de distância entre o título e o texto"). O Spacer ("espaçador") é um espaço vazio que estica: ele empurra os vizinhos para as pontas de uma Row ou Column.

Você vai aprender
  • Como pôr um espaço fixo entre os itens com um SizedBox vazio (height na Column, width na Row).
  • Como dar largura e altura fixas a um widget, e como esticar até o máximo com double.infinity.
  • Como o Spacer empurra os vizinhos, e o flex dele.
  • O parâmetro spacing: da Row e da Column, que põe o mesmo espaço entre todos os filhos.
  • Os erros comuns: o espaço "na direção errada" e o SizedBox(16).

Todos os apps desta aula são um lib/main.dart completo, compilados pelo Flutter Flutter 3.47 do laboratório para a web e fotografados no navegador, em tamanho de celular (390 × 844).

A ideia: o calço e a mola

Na estante da Ana, para separar os livros de receitas dos cadernos, ela põe um calço de madeira de 3 cm: o espaço é sempre o mesmo, não importa o tamanho da estante. Esse é o SizedBox. Já para encostar os livros numa ponta e o porta-retrato na outra, imagine uma mola entre eles, que estica até ocupar o vão todo. Esse é o Spacer.

1. SizedBox vazio: espaço entre os itens

Numa Column, os filhos ficam colados um no outro. Um SizedBox com só a height ("altura"), e sem filho, vira um espaço vazio daquela altura:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Padding(
          padding: EdgeInsets.all(16),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('Bolo de cenoura', style: TextStyle(fontSize: 28)),
              SizedBox(height: 8),
              Text('Rende 8 porções', style: TextStyle(fontSize: 16)),
              SizedBox(height: 32),
              Row(
                children: [
                  Icon(Icons.timer),
                  SizedBox(width: 8),
                  Text('40 minutos', style: TextStyle(fontSize: 18)),
                ],
              ),
            ],
          ),
        ),
      ),
    );
  }
}
SizedBox(height: 8)
Numa Column, um espaço de 8 entre o título e a linha de baixo. Só a altura importa aqui (a coluna empilha na vertical).
SizedBox(height: 32)
Um espaço maior, para separar "blocos" diferentes da tela. Espaços diferentes ajudam o olho a perceber o que está junto e o que está separado.
SizedBox(width: 8)
Numa Row, o espaço é na largura: 8 entre o ícone e o texto. É o jeito certo de fazer o que, na aula Row e Column, foi feito com um espaço dentro do texto (' 40 minutos').
const
O SizedBox tem construtor const, então a coluna inteira continua constante.

2. SizedBox com filho: tamanho fixo

Com um child, o SizedBox obriga o filho a ter aquele tamanho. O uso mais comum é em botões: o botão, sozinho, tem o tamanho do texto dele; dentro de um SizedBox, ele fica do tamanho que você escolher:

        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            children: [
              FilledButton(onPressed: () {}, child: const Text('Sem SizedBox')),
              const SizedBox(height: 16),
              SizedBox(
                width: 200,
                height: 56,
                child: FilledButton(onPressed: () {}, child: const Text('200 × 56')),
              ),
              const SizedBox(height: 16),
              SizedBox(
                width: double.infinity,
                height: 56,
                child: FilledButton(onPressed: () {}, child: const Text('Largura toda')),
              ),
            ],
          ),
        ),
FilledButton(onPressed: () {}, …)
Um botão do Material 3 (aula Botões). O () {} é uma função vazia: o botão funciona, mas não faz nada ao ser tocado.
width: 200, height: 56
O botão fica com exatamente 200 de largura e 56 de altura.
width: double.infinity
"Largura infinita". Na prática quer dizer "o máximo que o pai deixar": aqui, a largura da tela menos o padding. É o jeito clássico de fazer um botão que ocupa a linha toda.
sem const no Padding
Os botões não são constantes (o onPressed recebe uma função criada na hora), então o const foi para as peças que podem ser.
AtalhoÉ o mesmo quePara quê
SizedBox.expand(child: w)SizedBox(width: double.infinity, height: double.infinity, child: w)Ocupar todo o espaço que o pai der
SizedBox.square(dimension: 48)SizedBox(width: 48, height: 48)Um quadrado
SizedBox.shrink()SizedBox(width: 0, height: 0)"Nada": um widget vazio, de tamanho zero
O "nada" do Flutter

Às vezes você precisa devolver um widget mas não quer mostrar nada (por exemplo, um aviso que só aparece se houver erro). const SizedBox.shrink() (ou const SizedBox(), sem nada) é o jeito mais leve de dizer "aqui não tem nada".

3. Spacer: a mola

O Spacer é um espaço vazio que ocupa toda a sobra de uma Row ou Column, empurrando os vizinhos. Para pôr o nome da receita à esquerda e a estrela à direita:

        body: const Padding(
          padding: EdgeInsets.all(16),
          child: Column(
            children: [
              Row(
                children: [
                  Text('Bolo de cenoura', style: TextStyle(fontSize: 22)),
                  Spacer(),
                  Icon(Icons.star, color: Colors.amber),
                ],
              ),
              SizedBox(height: 32),
              Row(
                children: [
                  Icon(Icons.home, size: 40),
                  Spacer(),
                  Icon(Icons.search, size: 40),
                  Spacer(flex: 2),
                  Icon(Icons.person, size: 40),
                ],
              ),
            ],
          ),
        ),

Na segunda linha há duas molas. Como no Expanded, elas dividem a sobra pelo flex: a primeira (flex 1, o padrão) fica com 1 parte e a segunda (flex: 2) com 2 partes. Por isso o espaço entre a lupa e a pessoa é o dobro do espaço entre a casa e a lupa. (Por dentro, o Spacer é exatamente isto: um Expanded com um SizedBox.shrink() dentro.)

4. spacing: o mesmo espaço entre todos

Pôr um SizedBox entre cada par de itens fica repetitivo numa lista de dez. Desde o Flutter 3.27, a Row e a Column têm um parâmetro spacing:, que põe o mesmo espaço entre todos os filhos:

        body: const Padding(
          padding: EdgeInsets.all(16),
          child: Column(
            spacing: 16,
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('Arroz', style: TextStyle(fontSize: 24)),
              Text('Feijão', style: TextStyle(fontSize: 24)),
              Text('Café', style: TextStyle(fontSize: 24)),
              Row(
                spacing: 8,
                children: [
                  Icon(Icons.add_shopping_cart),
                  Text('Adicionar item', style: TextStyle(fontSize: 18)),
                ],
              ),
            ],
          ),
        ),

O spacing só vai entre os filhos: não há espaço antes do primeiro nem depois do último.

Formas diferentes de fazer

Quero…Use
O mesmo espaço entre todos os filhosspacing: na Row/Column
Espaços diferentes em pontos diferentesSizedBox(height: …) / SizedBox(width: …) entre os filhos
Empurrar um filho para a pontaSpacer(), ou mainAxisAlignment: MainAxisAlignment.spaceBetween (aula Alinhamento)
Espaço em volta de um widget (não entre dois)Padding (aula Padding e Margem)
Tamanho fixo, sem corSizedBox(width:, height:, child:)
Tamanho fixo com cor, borda…Container(width:, height:, …) (aula Container)
SizedBox ou Container para dar tamanho?

Os dois aceitam width e height. Se você só quer o tamanho (ou só um espaço), prefira o SizedBox: ele é mais simples, tem construtor const e deixa claro o que você quis. O Container é para quando também há cor, borda, margem ou alinhamento.

Quando dá errado

O espaço na direção errada

Na Row, um SizedBox(height: …) não afasta nada na horizontal: ele tem largura zero. O erro não aparece no console; o espaço é que não aparece na tela:

        body: const Row(
          children: [
            Icon(Icons.timer, size: 40),
            SizedBox(height: 40),
            Text('40 minutos', style: TextStyle(fontSize: 24)),
          ],
        ),

Como consertar: na Row, use width; na Column, height. Regra: o espaço vai na direção da fila (o eixo principal).

"Argumentos posicionais demais: 0 permitidos, mas 1 encontrado." Um argumento posicional é o que vai sem nome, só pela posição (o 16). O SizedBox não aceita nenhum: todos os parâmetros dele são nomeados, como mostra o construtor que o compilador achou, com as chaves { }: width, height e child. O Dart não tem como adivinhar se o 16 é largura ou altura. Como consertar: diga qual medida: SizedBox(height: 16).

Missão final: o botão de salvar

Missão: o botão "Salvar receita" deve ocupar a largura toda, com 56 de altura. Embrulhe o FilledButton num SizedBox com width: double.infinity e height: 56.

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {

  @override

              const Spacer(),
              FilledButton(onPressed: () {}, child: const Text('Salvar receita')),
            ],
          ),
        ),
      ),
    );
  }
}

Resumo

  • SizedBox vazio é um espaço fixo: height na Column, width na Row.
  • SizedBox com child dá um tamanho fixo ao filho; double.infinity quer dizer "o máximo que o pai deixar".
  • Spacer é uma mola: ocupa a sobra e empurra os vizinhos; vários Spacer dividem a sobra pelo flex.
  • spacing: na Row/Column põe o mesmo espaço entre todos os filhos.
  • Para só dar tamanho ou espaço, prefira SizedBox (é const) a Container.
