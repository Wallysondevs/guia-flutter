Flutter Animações Explícitas

Nas Animações Implícitas, você mudava um valor e o widget animava sozinho, uma vez, de A até B. Isso cobre muita coisa, mas não tudo: um ícone que gira sem parar enquanto carrega, um coração que pulsa, uma animação que você quer pausar, voltar ou repetir. Para isso, você pega o "controle remoto" da animação: o AnimationController. A animação deixa de ser subentendida e passa a ser explícita: você diz quando ela anda, para onde e quantas vezes.

Você vai aprender
  • A criar um AnimationController com vsync e duration, e por que ele pede o SingleTickerProviderStateMixin.
  • Os comandos do controle: forward, reverse, repeat, stop e o value que vai de 0 a 1.
  • A transformar o 0…1 em tamanhos e cores com Tween, ColorTween e CurvedAnimation.
  • A redesenhar a cada quadro com AnimatedBuilder.
  • As transições prontas: RotationTransition, ScaleTransition, FadeTransition.
  • Por que todo controle precisa de dispose(), e os erros reais do mixin.

A ideia: o controle remoto do vídeo

Pense num vídeo de receita no celular. A barrinha embaixo vai de 0% (o começo) a 100% (o fim). O controle remoto tem botões: play (vai para o fim), voltar (vai para o começo), repetir e pausar.

  1. O AnimationController é esse controle. A "barrinha" dele é o value, um número que vai de 0.0 a 1.0 durante a duration.
  2. Sozinho, esse número não desenha nada. Um Tween traduz o 0…1 para o que interessa: de 60 a 160 pixels, de bege a marrom.
  3. O AnimatedBuilder redesenha um pedaço da tela a cada quadro (cerca de 60 vezes por segundo), com o valor do momento.
AnimationController   0.0 ─────────────▶ 1.0       (em 800 ms)
        │
   Tween(60, 160)     60  ─────────────▶ 160       (tamanho do ícone)
   ColorTween         bege ────────────▶ marrom    (cor)
        │
   AnimatedBuilder → Icon(size: …, color: …)       (redesenha a cada quadro)

1. O bolo que cresce: o exemplo completo

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: TelaBolo(),
    ));

class TelaBolo extends StatefulWidget {
  const TelaBolo({super.key});

  @override
  State<TelaBolo> createState() => _TelaBoloState();
}

class _TelaBoloState extends State<TelaBolo>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controle;
  late final Animation<double> _tamanho;
  late final Animation<Color?> _cor;

  @override
  void initState() {
    super.initState();
    _controle = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 800),
    );
    _tamanho = Tween<double>(begin: 60, end: 160).animate(
      CurvedAnimation(parent: _controle, curve: Curves.easeOut),
    );
    _cor = ColorTween(begin: Colors.brown.shade200, end: Colors.brown.shade700)
        .animate(_controle);
  }

  @override
  void dispose() {
    _controle.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('O bolo crescendo')),
      body: Center(
        child: AnimatedBuilder(
          animation: _controle,
          builder: (context, child) {
            return Icon(Icons.cake, size: _tamanho.value, color: _cor.value);
          },
        ),
      ),
      persistentFooterButtons: [
        TextButton(
          onPressed: () => _controle.reverse(),
          child: const Text('Murchar'),
        ),
        FilledButton(
          onPressed: () => _controle.forward(),
          child: const Text('Assar'),
        ),
      ],
    );
  }
}
with SingleTickerProviderStateMixin
Um mixin (um pacote de métodos que a classe "veste"; veja Mixins no Guia Dart) que dá ao State um ticker: um relógio que bate uma vez por quadro da tela. O controle precisa desse relógio para andar. "Single" = um ticker, para um controle.
late final AnimationController _controle
O controle. É late porque só pode ser criado no initState (ele precisa do this).
vsync: this
"Use o meu relógio." O this é o próprio State, que ganhou o ticker pelo mixin. O nome vem de vertical sync (sincronia com a tela): o ticker também para quando a tela não está visível, para não gastar bateria.
duration: const Duration(milliseconds: 800)
Quanto tempo o value leva de 0 a 1.
Tween<double>(begin: 60, end: 160).animate(…)
Liga a faixa 60…160 ao controle e devolve uma Animation<double>: quando o controle está em 0.5, ela vale 110.
CurvedAnimation(parent: _controle, curve: Curves.easeOut)
Aplica uma curva (o ritmo, como nas implícitas) entre o controle e o tween.
ColorTween(begin: …, end: …)
O mesmo, para cores: mistura as duas conforme o valor. Devolve Color? (pode ser nula), por isso Animation<Color?>.
dispose() → _controle.dispose()
Obrigatório. Desliga o relógio quando a tela é fechada. Sem isso, o ticker continua vivo, gastando memória (veja Ciclo de Vida do Widget).
AnimatedBuilder(animation: _controle, builder: …)
Escuta o controle e chama o builder a cada quadro. Só o que o builder devolve é redesenhado.
_tamanho.value / _cor.value
O valor do momento de cada animação.
_controle.forward() / reverse()
"Play" (do valor atual até 1) e "voltar" (do valor atual até 0).
Começo (valor 0.0)Fim, depois de tocar em "Assar" (valor 1.0)

Missão: rode e toque em Assar e em Murchar. Depois, faça o botão Assar deixar o bolo pulsando sem parar (crescendo e encolhendo): troque o _controle.forward() por _controle.repeat(reverse: true). Para parar no meio, o Murchar continua funcionando: o reverse() interrompe a repetição e volta ao começo.

2. Os comandos do controle

ComandoO que faz
_controle.forward()Anda até 1.0
_controle.reverse()Volta até 0.0
_controle.repeat()De 0 a 1, de novo e de novo, sem parar
_controle.repeat(reverse: true)Vai e volta sem parar (0→1→0→1…): o "pulsar"
_controle.stop()Pausa onde estiver
_controle.reset()Volta para 0 na hora, sem animar
_controle.value = 0.5Pula para a metade (útil para arrastar com o dedo)
_controle.isAnimating / .statusEstá andando? Em que fase está (forward, completed…)?

3. As transições prontas

Para os casos mais comuns, nem precisa de AnimatedBuilder: o Flutter tem widgets "…Transition" que recebem a animação direto. Um ícone de carregando que gira sem parar:

// no initState:
_giro = AnimationController(vsync: this, duration: const Duration(seconds: 2))
  ..repeat();

// no build:
RotationTransition(
  turns: _giro,
  child: const Icon(Icons.autorenew, size: 64),
)
..repeat()
O .. (cascata do Dart) chama repeat() no controle recém-criado e devolve o próprio controle para a variável.
turns: _giro
"Voltas": 0.0 = parado, 1.0 = uma volta inteira. Como o controle vai de 0 a 1 em 2 segundos e repete, o ícone dá uma volta a cada 2 segundos.
TransiçãoRecebeAnima
RotationTransitionturnsgiro (em voltas)
ScaleTransitionscaletamanho (1.0 = normal)
FadeTransitionopacitytransparência
SlideTransitionposition (Animation<Offset>)deslocamento
SizeTransitionsizeFactorabre/fecha como uma gaveta

Um coração que pulsa, com ScaleTransition e um tween de 1.0 a 1.3, indo e voltando:

_pulso = AnimationController(vsync: this, duration: const Duration(milliseconds: 600))
  ..repeat(reverse: true);
_escala = Tween<double>(begin: 1.0, end: 1.3).animate(_pulso);

// no build:
ScaleTransition(
  scale: _escala,
  child: const Icon(Icons.favorite, color: Colors.red, size: 48),
)

4. Dois controles na mesma tela

O SingleTickerProviderStateMixin dá um ticker só. Se o mesmo State tem dois controles (o giro e o pulso, por exemplo), troque por TickerProviderStateMixin (sem o "Single"), que dá quantos tickers forem precisos. A seção Quando dá errado mostra o que acontece se esquecer.

Explícita ou implícita?

Você quer…Use
Suavizar uma mudança de valor (tamanho, cor, posição), uma vezWidget Animated… (implícitas)
Animar um valor qualquer uma vez, sem controleTweenAnimationBuilder
Repetir sem parar, ir e voltar, pausarAnimationController + uma …Transition
Várias coisas mudando juntas no mesmo ritmo, ou um desenho próprioAnimationController + AnimatedBuilder
Um elemento "voando" de uma tela para outraHero

Comece sempre pela implícita. Se ela não der conta, aí sim pegue o controle remoto.

Como consertar: with TickerProviderStateMixin.

Esqueceu o dispose()

Com o controle parado, nada aparece na tela e o app continua funcionando, por isso é fácil esquecer. Mas cada vez que a tela abre e fecha, um controle fica para trás, ocupando memória. Se ele ainda estiver andando quando a tela fecha (um repeat(), por exemplo), o modo debug acusa um erro dizendo que o State foi descartado com um ticker ativo. Como consertar: todo controle criado no initState tem o seu .dispose() no dispose, antes do super.dispose().

Missão final: o ícone de carregando

Missão: o controle _giro já está pronto e repetindo (..repeat()), mas o ícone está parado, porque ninguém usa o controle. Embrulhe o Icon num RotationTransition com turns: _giro para ele girar uma volta a cada 2 segundos. Atenção: o Center deixa de ser const.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: TelaCarregando(),
    ));

class TelaCarregando extends StatefulWidget {

  @override
  State<TelaCarregando> createState() => _TelaCarregandoState();
}

class _TelaCarregandoState extends State<TelaCarregando>
    with SingleTickerProviderStateMixin {
  late final AnimationController _giro;

  @override

    super.initState();
    _giro = AnimationController(
      vsync: this,
      duration: const Duration(seconds: 2),
    )..repeat();
  }

  @override
  void dispose() {
    _giro.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Buscando receitas')),
      body: const Center(
        child: Icon(Icons.autorenew, size: 96, color: Colors.teal),
      ),
    );
  }
}

Resumo

  • O AnimationController é o controle remoto: um value de 0 a 1 que anda com forward, reverse, repeat e para com stop.
  • Ele precisa de um ticker: with SingleTickerProviderStateMixin (um controle) ou TickerProviderStateMixin (vários), e vsync: this.
  • Crie no initState, destrua no dispose.
  • Tween/ColorTween + .animate(controle) traduzem o 0…1; CurvedAnimation dá o ritmo.
  • AnimatedBuilder redesenha a cada quadro; as …Transition prontas resolvem giro, escala, opacidade e deslize.
