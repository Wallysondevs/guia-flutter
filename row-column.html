Flutter Row e Column

Até agora, cada tela teve um widget no body: um texto, uma imagem, um Container. Uma tela de verdade tem vários: um título, uma foto, uma lista de ingredientes, dois botões lado a lado. Para colocar vários widgets juntos, o Flutter tem duas peças básicas: a Column ("coluna"), que empilha os filhos um embaixo do outro, e a Row ("linha", no sentido de fileira), que os enfileira um do lado do outro. Quase toda tela que você vai montar é feita de Rows e Columns, uma dentro da outra.

Você vai aprender
  • O que é o children (a lista de filhos) e a diferença para o child.
  • Como empilhar widgets com Column e enfileirar com Row.
  • Como colocar uma Row dentro de uma Column (e o contrário), e ler a árvore de widgets.
  • Quanto espaço cada uma ocupa: o mainAxisSize.
  • Os erros reais: o overflow (as listras amarelas e pretas) e o children sem colchetes.

Todos os apps desta aula são um lib/main.dart completo, compilados pelo Flutter Flutter 3.47 do laboratório para a web e fotografados no navegador, em tamanho de celular (390 × 844).

A ideia: a pilha de pratos e a prateleira

Na cozinha da Ana, os pratos ficam empilhados: um em cima do outro, de cima para baixo. As latas de tempero ficam na prateleira: uma do lado da outra, da esquerda para a direita.

  • Column é a pilha: os filhos vão de cima para baixo, na ordem em que você os escreveu.
  • Row é a prateleira: os filhos vão da esquerda para a direita, na ordem em que você os escreveu.

As duas recebem os filhos do mesmo jeito: uma lista, no parâmetro children ("filhos", no plural). Compare com o Padding e o Container da aula anterior, que têm child (no singular): um filho só.

1. Column: um embaixo do outro

A lista de compras da Ana, com três itens:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Lista de compras')),
        body: const Column(
          children: [
            Text('Arroz', style: TextStyle(fontSize: 24)),
            Text('Feijão', style: TextStyle(fontSize: 24)),
            Text('Café', style: TextStyle(fontSize: 24)),
          ],
        ),
      ),
    );
  }
}
Column(…)
A coluna: empilha os filhos de cima para baixo.
children: [ … ]
A lista de filhos, entre colchetes, como qualquer List do Dart (o tipo é List<Widget>). Cada item é um widget, separado por vírgula.
Text('Arroz', …)
O primeiro filho: fica em cima. A ordem na lista é a ordem na tela.
a vírgula no fim
A vírgula depois do último filho (…'Café', …),) é opcional, mas é um costume do Flutter: com ela, o formatador do Dart (dart format) põe um filho por linha, e acrescentar um item novo mexe numa linha só.
const Column
Todos os filhos são constantes, então a coluna inteira pode ser const.

Repare em duas coisas na foto. Primeiro, os itens ficaram no alto da tela: a coluna começa em cima. Segundo, olhe de perto: Arroz e Café estão um pouquinho para a direita do Feijão. É que a Column ficou só com a largura do filho mais largo (o Feijão), encostada à esquerda, e os outros dois foram centralizados dentro dessa largura. Os dois comportamentos têm nome e dá para mudar: é o assunto da próxima aula, Alinhamento (mainAxis e crossAxis).

2. Row: um do lado do outro

Troque Column por Row e os mesmos filhos passam a ficar lado a lado. Aqui, as três latas de tempero da prateleira, cada uma com um ícone:

        body: const Row(
          children: [
            Icon(Icons.local_florist, size: 48, color: Colors.green),
            Icon(Icons.local_fire_department, size: 48, color: Colors.red),
            Icon(Icons.grain, size: 48, color: Colors.brown),
          ],
        ),

A Row é exatamente a Column "deitada": tem o mesmo children, os mesmos parâmetros, e o mesmo comportamento, só que na horizontal. Por isso as duas são ensinadas juntas: aprendeu uma, aprendeu a outra.

3. Uma dentro da outra

O poder de verdade aparece quando você combina as duas. A ficha de uma receita: o título em cima e, embaixo, duas linhas com um ícone e um texto cada. Ou seja: uma Column cujos filhos são um Text e duas Rows.

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Padding(
          padding: EdgeInsets.all(16),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('Bolo de cenoura', style: TextStyle(fontSize: 28)),
              Row(
                children: [
                  Icon(Icons.timer),
                  Text(' 40 minutos', style: TextStyle(fontSize: 18)),
                ],
              ),
              Row(
                children: [
                  Icon(Icons.people),
                  Text(' 8 porções', style: TextStyle(fontSize: 18)),
                ],
              ),
            ],
          ),
        ),
      ),
    );
  }
}

A árvore de widgets desse body, quem está dentro de quem:

Padding
└── Column
    ├── Text('Bolo de cenoura')
    ├── Row
    │   ├── Icon(timer)
    │   └── Text(' 40 minutos')
    └── Row
        ├── Icon(people)
        └── Text(' 8 porções')
Padding → Column
O respiro de 16 em volta de tudo (aula Padding e Margem).
crossAxisAlignment: CrossAxisAlignment.start
Encosta os filhos da coluna à esquerda, em vez de centralizar. Por enquanto, aceite essa linha; a próxima aula explica o nome.
Row(children: [Icon, Text])
Uma fileira dentro da coluna: o ícone e, à direita dele, o texto. O espaço no começo de ' 40 minutos' afasta o texto do ícone (um jeito simples; na aula SizedBox e Spacer você aprende o jeito certo).
Dica: desenhe a árvore antes do código

Olhe uma tela (de um app que você usa, ou um desenho no papel) e pergunte: "isto está empilhado ou lado a lado?". O que está empilhado vira Column; o que está lado a lado vira Row; repita para cada pedaço. Em pouco tempo você "enxerga" as Rows e Columns em qualquer app.

4. Quanto espaço elas ocupam: mainAxisSize

Uma Column ocupa, por padrão, toda a altura que puder, mesmo que os filhos sejam pequenos. Uma Row ocupa toda a largura. Para ver isso, este app pinta o fundo de cada uma (com um ColoredBox), uma com o padrão e outra com mainAxisSize: MainAxisSize.min ("tamanho mínimo"):

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('mainAxisSize')),
        body: const Column(
          children: [
            ColoredBox(
              color: Colors.amber,
              child: Row(
                children: [Text('max ', style: TextStyle(fontSize: 22)), Icon(Icons.star)],
              ),
            ),
            SizedBox(height: 16),
            ColoredBox(
              color: Colors.lightGreen,
              child: Row(
                mainAxisSize: MainAxisSize.min,
                children: [Text('min ', style: TextStyle(fontSize: 22)), Icon(Icons.star)],
              ),
            ),
          ],
        ),
      ),
    );
  }
}
ValorNa ColumnNa Row
MainAxisSize.max (o padrão)Ocupa toda a altura disponívelOcupa toda a largura disponível
MainAxisSize.minSó a altura somada dos filhosSó a largura somada dos filhos

(O SizedBox(height: 16) do meio é só um espaço vazio entre as duas; ele tem aula própria.) Na prática, você vai usar min quando a Row ou a Column estiver dentro de algo que deve "abraçar" o conteúdo, como um botão ou um cartão.

Formas diferentes de fazer

A Row e a Column não são as únicas formas de juntar vários widgets. Cada uma resolve um problema diferente:

SituaçãoQual usar
Poucos itens, empilhados, que cabem na telaColumn
Poucos itens lado a lado, que cabem na larguraRow
Muitos itens, ou itens que podem não caber (a lista de compras do mês)ListView, que rola (aula ListView)
Itens lado a lado que devem "quebrar a linha" quando acabar o espaço (etiquetas, filtros)Wrap
Um widget em cima do outro (texto sobre a foto)Stack (aula Stack e Positioned)

Quando dá errado

Não coube: o overflow (as listras amarelas e pretas)

A Row não quebra linha e não rola. Se os filhos forem mais largos que a tela, ela mostra o que cabe e pinta uma faixa de aviso no lado que estourou:

        body: const Row(
          children: [
            Icon(Icons.shopping_cart, size: 40),
            Text('Arroz, feijão, café, leite, açúcar e farinha de trigo', style: TextStyle(fontSize: 24)),
          ],
        ),

Resumo

  • Column empilha os filhos de cima para baixo; Row os enfileira da esquerda para a direita.
  • As duas recebem uma lista no children (com colchetes); a ordem da lista é a ordem na tela.
  • Telas de verdade são Rows dentro de Columns dentro de Rows: desenhe a árvore antes de escrever.
  • Por padrão elas ocupam todo o espaço do eixo principal; mainAxisSize: MainAxisSize.min faz ocupar só o tamanho dos filhos.
  • Elas não rolam nem quebram linha: o que não cabe vira o overflow com listras amarelas e pretas.
