Flutter Cores, Bordas e Sombras (BoxDecoration)

O color: do Container pinta uma caixa retangular, de cantos retos. Para deixar a caixa com cara de app moderno, com cantos arredondados, uma borda, uma sombra embaixo ou um degradê de cores, o Container tem o parâmetro decoration: ("decoração"), que recebe um BoxDecoration ("decoração de caixa"). Tudo o que é visual na caixa vai dentro dele.

Você vai aprender
  • Como trocar o color: do Container por um decoration: BoxDecoration(…).
  • Cantos arredondados com borderRadius, e bordas com Border.all e Border(bottom: …).
  • Sombras com boxShadow, e degradês com LinearGradient e RadialGradient.
  • Caixas redondas com shape: BoxShape.circle.
  • Os erros reais: color e decoration juntos, e o círculo com borderRadius.

Todos os apps desta aula são um lib/main.dart completo, compilados pelo Flutter Flutter 3.47 do laboratório para a web e fotografados no navegador, em tamanho de celular (390 × 844).

A ideia: embrulhar um presente

O Container é a caixa do presente. O BoxDecoration é tudo o que você faz com o papel de embrulho: a cor do papel, a fita em volta (a borda), as pontas dobradas para ficarem redondinhas (os cantos), a sombra que a caixa faz na mesa. O conteúdo de dentro (o child) não muda; muda só o embrulho.

1. Cor e cantos arredondados

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: Center(
          child: Container(
            width: 300,
            padding: const EdgeInsets.all(24),
            decoration: BoxDecoration(
              color: Colors.orange.shade200,
              borderRadius: BorderRadius.circular(20),
            ),
            child: const Text('Bolo de cenoura', style: TextStyle(fontSize: 24)),
          ),
        ),
      ),
    );
  }
}
decoration: BoxDecoration(…)
O "embrulho" da caixa. Quando você usa decoration, a cor vai dentro dele, e não no color: do Container (veja Quando dá errado).
color: Colors.orange.shade200
A cor de fundo, agora dentro do BoxDecoration.
borderRadius: BorderRadius.circular(20)
Arredonda os quatro cantos com raio 20: quanto maior o número, mais redondo o canto.
EscritaCantos arredondados
BorderRadius.circular(20)Os quatro, com raio 20
BorderRadius.only(topLeft: Radius.circular(20), topRight: Radius.circular(20))Só os dois de cima
BorderRadius.vertical(top: Radius.circular(20))Os dois de cima (atalho)
BorderRadius.horizontal(left: Radius.circular(20))Os dois da esquerda

2. Bordas

A border ("borda") é a fita em volta da caixa. Border.all põe a mesma borda nos quatro lados; Border(…) deixa escolher lado por lado:

        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            spacing: 16,
            children: [
              Container(
                padding: const EdgeInsets.all(16),
                decoration: BoxDecoration(
                  border: Border.all(color: Colors.deepPurple, width: 3),
                  borderRadius: BorderRadius.circular(12),
                ),
                child: const Text('Border.all', style: TextStyle(fontSize: 20)),
              ),
              Container(
                padding: const EdgeInsets.all(16),
                decoration: const BoxDecoration(
                  border: Border(bottom: BorderSide(color: Colors.teal, width: 4)),
                ),
                child: const Text('Só embaixo', style: TextStyle(fontSize: 20)),
              ),
              Container(
                padding: const EdgeInsets.all(16),
                decoration: const BoxDecoration(
                  color: Color(0xFFFFF3E0),
                  border: Border(left: BorderSide(color: Colors.deepOrange, width: 8)),
                ),
                child: const Text('Aviso com faixa à esquerda', style: TextStyle(fontSize: 20)),
              ),
            ],
          ),
        ),
Border.all(color: …, width: 3)
Uma borda de 3 de grossura nos quatro lados. Junto com o borderRadius, a borda acompanha os cantos redondos.
Border(bottom: BorderSide(…))
Só a borda de baixo, como um sublinhado. Cada lado (top, bottom, left, right) é um BorderSide ("lado da borda") com cor e grossura.
Color(0xFFFFF3E0)
Uma cor escrita em número: 0xFF (totalmente opaca) seguido do código da cor em hexadecimal, o mesmo dos sites (#FFF3E0, um creme). Útil quando a cor exata vem de um desenho.

3. Sombras

A boxShadow é uma lista de sombras (dá para empilhar várias). Cada sombra é um BoxShadow:

        body: Center(
          child: Container(
            width: 280,
            height: 160,
            alignment: Alignment.center,
            decoration: BoxDecoration(
              color: Colors.white,
              borderRadius: BorderRadius.circular(16),
              boxShadow: const [
                BoxShadow(
                  color: Colors.black26,
                  blurRadius: 16,
                  offset: Offset(0, 8),
                ),
              ],
            ),
            child: const Text('Pudim de leite', style: TextStyle(fontSize: 24)),
          ),
        ),
color: Colors.black26
A cor da sombra: um preto bem transparente (26% de opacidade). Sombras de verdade nunca são pretas sólidas.
blurRadius: 16
O quanto a sombra é "borrada": 0 é uma sombra de contorno duro; números maiores espalham e suavizam.
offset: Offset(0, 8)
O deslocamento da sombra: 0 para o lado e 8 para baixo, como se a luz viesse de cima.
spreadRadius
(não usado aqui) Aumenta ou diminui o tamanho da sombra antes de borrar.

Missão: o cartão parece "colado" na tela. Faça ele "flutuar" mais: aumente o blurRadius para 20 ou mais e o deslocamento para baixo (Offset(0, …)) para 12 ou mais.

4. Degradês

No lugar de uma cor só, o fundo pode ser um degradê (em inglês, gradient): uma cor que vai virando outra.

        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            spacing: 16,
            children: [
              Container(
                height: 140,
                decoration: BoxDecoration(
                  borderRadius: BorderRadius.circular(16),
                  gradient: const LinearGradient(
                    colors: [Colors.orange, Colors.pink],
                  ),
                ),
              ),
              Container(
                height: 140,
                decoration: BoxDecoration(
                  borderRadius: BorderRadius.circular(16),
                  gradient: const LinearGradient(
                    begin: Alignment.topCenter,
                    end: Alignment.bottomCenter,
                    colors: [Colors.lightBlue, Colors.indigo],
                  ),
                ),
              ),
              Container(
                height: 140,
                decoration: BoxDecoration(
                  borderRadius: BorderRadius.circular(16),
                  gradient: const RadialGradient(
                    colors: [Colors.yellow, Colors.deepOrange],
                  ),
                ),
              ),
            ],
          ),
        ),
LinearGradient(colors: [a, b])
Degradê em linha reta. Sem begin/end, vai da esquerda (centerLeft) para a direita (centerRight).
begin: Alignment.topCenter, end: Alignment.bottomCenter
De cima para baixo. Os pontos são os mesmos Alignment da aula Center e Align; topLeft → bottomRight faz um degradê na diagonal.
RadialGradient(colors: [a, b])
Degradê em círculo: a primeira cor no centro, a segunda nas bordas.
colors: [ … ]
Uma lista: dá para usar três, quatro cores ou mais.

5. Caixas redondas: BoxShape.circle

        body: Center(
          child: Container(
            width: 120,
            height: 120,
            alignment: Alignment.center,
            decoration: BoxDecoration(
              shape: BoxShape.circle,
              color: Colors.deepPurple.shade100,
              border: Border.all(color: Colors.deepPurple, width: 4),
            ),
            child: const Text('A', style: TextStyle(fontSize: 56)),
          ),
        ),
shape: BoxShape.circle
Em vez de retângulo, um círculo que cabe dentro da caixa. Com largura e altura iguais, um círculo perfeito; a borda acompanha a forma.

Referência rápida

color:Cor de fundo
borderRadius: BorderRadius.circular(r)Cantos arredondados
border: Border.all(color:, width:)Borda nos quatro lados

boxShadow: [BoxShadow(color:, blurRadius:, offset:)]Sombra (uma lista)
gradient: LinearGradient(colors: […]) / RadialGradientDegradê em linha / em círculo

image: DecorationImage(image: …, fit: BoxFit.cover)Imagem de fundo (aula Imagens)

Resumo

  • Container(decoration: BoxDecoration(…)) é o "embrulho" da caixa: cor, cantos, borda, sombra, degradê, forma.
  • Com decoration, a cor vai dentro do BoxDecoration; os dois color juntos dão erro.
  • borderRadius arredonda os cantos; border põe a fita; boxShadow é uma lista de sombras (cor transparente, blurRadius, offset).
  • LinearGradient e RadialGradient fazem degradês; begin/end usam os pontos do Alignment.
  • shape: BoxShape.circle deixa a caixa redonda, e não combina com borderRadius.
