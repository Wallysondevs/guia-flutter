Flutter ListView.builder

Na aula ListView, você escreveu cada item da lista à mão. Isso funciona para 14 itens de compras, mas não para os mil produtos do estoque, nem para uma lista que vem de um banco de dados e muda de tamanho. Para isso existe a ListView.builder ("construtora"): você diz quantos itens são e dá uma receita para montar um item qualquer. O Flutter monta só os que aparecem na tela, na hora em que aparecem.

Você vai aprender
  • Os dois parâmetros da ListView.builder: itemCount e itemBuilder.
  • Como ela monta os itens sob demanda (visto no console, com mil produtos).
  • Como montar a lista a partir de uma lista de objetos (uma classe Receita).
  • A ListView.separated, com uma linha entre os itens.
  • A tela vermelha real RangeError (index) de quem esquece o itemCount.

As telas e o console desta aula vieram de um Flutter de verdade, no laboratório da Ana, em tamanho de celular.

A ideia: a fôrma de biscoito

Para fazer 1000 biscoitos, ninguém desenha cada um à mão: a Ana usa uma fôrma e corta quantos precisar. E ela não precisa assar os mil de uma vez: assa só a fornada que vai para a vitrine agora. A ListView.builder faz igual:

  • o itemBuilder é a fôrma: uma função que recebe a posição (index) e devolve o widget daquele item;
  • o itemCount diz quantos biscoitos existem;
  • e o Flutter só chama a fôrma para os itens que vão aparecer (mais uma pequena reserva logo abaixo da tela).

1. Mil produtos

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    final produtos = List.generate(1000, (i) => 'Produto ${i + 1}');
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Estoque da lojinha')),
        body: ListView.builder(
          itemCount: produtos.length,
          itemBuilder: (context, index) {
            debugPrint('montando o item $index');
            return ListTile(
              leading: CircleAvatar(child: Text('${index + 1}')),
              title: Text(produtos[index]),
            );
          },
        ),
      ),
    );
  }
}
List.generate(1000, (i) => 'Produto ${i + 1}')
Cria a lista de dados: 'Produto 1', 'Produto 2'… até 'Produto 1000' (o i começa em 0).
ListView.builder(…)
Uma ListView que monta os itens com uma função, em vez de receber a lista de children pronta.
itemCount: produtos.length
Quantos itens a lista tem: 1000. Com ele, a lista sabe onde termina.
itemBuilder: (context, index) { … }
A fôrma. O Flutter a chama com o index do item que precisa mostrar (de 0 a 999) e usa o widget que ela devolve. O context é o mesmo BuildContext do build.
debugPrint('montando o item $index')
Só para espiar: escreve no console cada vez que a fôrma é usada.
CircleAvatar(child: Text('${index + 1}'))
Um círculo com o número do item (o index + 1, para começar do 1).

E o console, do momento em que o app abriu até depois da rolagem (aqui, encurtado no meio):

A lista tem 1000 produtos, mas a fôrma foi usada 35 vezes (do item 0 ao 34): os 17 que apareceram ao abrir, os que apareceram durante a rolagem e uma pequena reserva abaixo da tela, montada com antecedência para a rolagem não engasgar. 2. Uma lista de objetos: as receitas

Na vida real, cada item tem várias informações. A Ana criou uma classe Receita com o nome e o tempo de preparo, e uma lista de receitas. A fôrma pega a receita da posição index e monta a linha com os dados dela:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class Receita {
  const Receita(this.nome, this.minutos);

  final String nome;
  final int minutos;
}

const receitas = [
  Receita('Bolo de cenoura', 50),
  Receita('Pão de queijo', 30),
  Receita('Brigadeiro', 20),
  Receita('Lasanha', 90),
  Receita('Salada de frutas', 15),
];

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: ListView.separated(
          itemCount: receitas.length,
          separatorBuilder: (context, index) => const Divider(),
          itemBuilder: (context, index) {
            final receita = receitas[index];
            return ListTile(
              leading: const Icon(Icons.restaurant_menu),
              title: Text(receita.nome),
              trailing: Text('${receita.minutos} min'),
            );
          },
        ),
      ),
    );
  }
}
class Receita { … }
Uma classe de modelo simples, com construtor const e campos final (mais em JSON e Classes de Modelo).
const receitas = [ Receita(…), … ];
A lista de dados, fora dos widgets. Numa versão de verdade, ela viria de um banco de dados ou da internet.
ListView.separated(…)
Uma prima da builder: monta um separador entre um item e o próximo.
separatorBuilder: (context, index) => const Divider()
A fôrma do separador: aqui, uma linha fina (Divider). Ela é usada entre os itens, e não depois do último.
final receita = receitas[index];
Pega a receita da posição atual. Daí em diante, receita.nome e receita.minutos.
trailing: Text('${receita.minutos} min')
O tempo de preparo na ponta direita da linha.

Repare que há 4 linhas separadoras para 5 receitas: nenhuma depois da Salada de frutas.

3. Formas diferentes de fazer uma lista: qual usar

FormaUse quando
ListView(children: [...])Poucos itens, escritos à mão (um menu de configurações)
ListView.builder(itemCount:, itemBuilder:)Muitos itens, ou itens que vêm de uma lista de dados
ListView.separated(…, separatorBuilder:)O mesmo, com algo entre os itens (linha, espaço)
ListView(children: [for (final r in receitas) ListTile(…)])Lista curta vinda de dados: funciona, mas monta todos os itens de uma vez

Para apagar itens com o dedo, veja Arrastar para Apagar. E se os itens têm estado e a lista muda de ordem, lembre das Keys.

Resumo

  • ListView.builder recebe itemCount (quantos) e itemBuilder (a fôrma que monta o item da posição index).
  • Ela só monta os itens que aparecem (e uma pequena reserva): com mil produtos, o lab montou 35.
  • Dentro do itemBuilder, pegue o dado com lista[index] e monte a linha com ele.
  • ListView.separated põe um separador entre os itens (um a menos que os itens).
  • Sem itemCount, a lista é infinita e dá RangeError (index) quando os dados acabam.
