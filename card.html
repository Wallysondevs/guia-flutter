Flutter Card e ListTile

Até aqui você montou tudo à mão: Container com cor, Padding, Row com ícone e texto. O Material Design já traz duas peças prontas que aparecem em quase todo app: o Card ("cartão"), uma caixa com cantos arredondados que parece um papel sobre a tela, e o ListTile ("ladrilho de lista"), uma linha pronta com ícone, título, subtítulo e alguma coisa na ponta. Juntos, eles fazem em poucas linhas uma lista bonita, como a de contatos do seu celular.

Você vai aprender
  • Como o Card embrulha um conteúdo num cartão, e os três estilos do Material 3: Card, Card.filled e Card.outlined.
  • Como mudar a sombra (elevation), a cor, os cantos e a margem do cartão.
  • As quatro partes do ListTile: leading, title, subtitle e trailing, e o toque com onTap.
  • Como juntar os dois numa lista de receitas.
  • O erro real de pôr um ListTile dentro de uma Row.

Todos os apps desta aula são um lib/main.dart completo, compilados pelo Flutter Flutter 3.47 do laboratório para a web e fotografados no navegador, em tamanho de celular (390 × 844).

A ideia: as fichas de receita

A Ana guarda as receitas da avó em fichas de papel, uma para cada prato. Cada ficha é um cartão: separa uma receita da outra e parece "flutuar" sobre a mesa. Dentro de cada ficha, a primeira linha segue sempre o mesmo formato: um desenho do prato à esquerda, o nome em destaque, uma linha menor com o tempo de preparo, e uma estrelinha na ponta direita se for favorita. O Card é a ficha; o ListTile é essa linha de formato fixo.

1. O Card

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Card(
          child: Padding(
            padding: EdgeInsets.all(16),
            child: Text('Bolo de cenoura com cobertura de chocolate', style: TextStyle(fontSize: 20)),
          ),
        ),
      ),
    );
  }
}
Card(child: …)
O cartão. Ele desenha o fundo, os cantos arredondados e a sombra, e põe uma pequena margem em volta de si (4 de cada lado). Tem um filho.
Padding(padding: EdgeInsets.all(16), …)
O Card não tem padding: sem este Padding, o texto encostaria nas bordas do cartão. Quase sempre um Card tem um Padding logo dentro.

O cartão ocupou a largura toda (menos a margem de 4 de cada lado), porque o texto comprido precisou dela e quebrou em duas linhas. Ele tem os cantos arredondados (raio 12, o padrão do Material 3), uma sombra bem leve embaixo e um fundo um tom diferente do fundo da tela. Essa cor vem do tema do app, o ColorScheme do Material 3 (aula Material 3 e ColorScheme): por isso você não escolheu cor nenhuma e o cartão já combina com o resto.

Os três estilos do Material 3

O Material 3 define três tipos de cartão, e o Flutter tem um construtor para cada:

        body: const Padding(

          child: Column(

            children: [
              Card(child: Padding(padding: EdgeInsets.all(24), child: Text('Card() — elevado'))),
              Card.filled(child: Padding(padding: EdgeInsets.all(24), child: Text('Card.filled() — preenchido'))),
              Card.outlined(child: Padding(padding: EdgeInsets.all(24), child: Text('Card.outlined() — com contorno'))),

color: Colors.orange.shade50

2. O ListTile

O ListTile é uma linha pronta, com a altura, os espaços e os tamanhos de letra que o Material Design recomenda. Você só diz o que vai em cada lugar:

        body: Column(
          children: [
            const ListTile(title: Text('Só o title')),
            const ListTile(
              leading: Icon(Icons.cake),
              title: Text('Bolo de cenoura'),
              subtitle: Text('40 minutos · 8 porções'),
              trailing: Icon(Icons.star, color: Colors.amber),
            ),
            ListTile(
              leading: const Icon(Icons.icecream),
              title: const Text('Sorvete de manga'),
              subtitle: const Text('Toque para abrir'),
              trailing: const Icon(Icons.chevron_right),
              onTap: () {},
            ),
          ],
        ),

ListTile
┌──────────┬───────────────────────────────┬──────────┐
│ leading  │ title                         │ trailing │
│ (começo) │ subtitle                      │ (ponta)  │
└──────────┴───────────────────────────────┴──────────┘
leading
"O que vem na frente": um widget à esquerda, normalmente um Icon ou uma foto redonda (CircleAvatar).
title
O título, em letra maior. É o único que você quase sempre põe.
subtitle
A linha menor, embaixo do título, em cor mais apagada.
trailing
"O que vem atrás": um widget na ponta direita (uma estrela, uma seta, um Switch, um preço).
onTap: () {}
O que fazer ao tocar na linha. Com onTap, a linha inteira vira um botão: mostra o "respingo" de tinta ao toque. Aqui a função é vazia (não faz nada); em Navegação ela vai abrir outra tela.
const em cada peça
A terceira linha não pode ser const por causa do onTap (uma função criada na hora), então o const foi para as peças de dentro.

Repare como o ListTile cuidou de tudo sozinho: o título em letra maior e o subtítulo menor e mais apagado, o ícone do leading alinhado com o texto, a estrela e a seta encostadas na ponta direita, e o mesmo espaço nas laterais de todas as linhas. A primeira linha, só com title, é mais baixa que as outras: a altura muda conforme as partes que você usa.

3. Os dois juntos: a lista de receitas

O par mais comum do Flutter: um ListTile dentro de cada Card. Para não repetir o mesmo código três vezes, fazemos um widget nosso, o CartaoReceita:

import 'package:flutter/material.dart';

void main() => runApp(const MeuApp());

class CartaoReceita extends StatelessWidget {
  const CartaoReceita({
    super.key,
    required this.icone,
    required this.nome,
    required this.detalhe,
    this.favorita = false,
  });

  final IconData icone;
  final String nome;
  final String detalhe;
  final bool favorita;

  @override
  Widget build(BuildContext context) {
    return Card(
      child: ListTile(
        leading: Icon(icone, size: 36),
        title: Text(nome),
        subtitle: Text(detalhe),
        trailing: Icon(
          favorita ? Icons.star : Icons.star_border,
          color: Colors.amber,
        ),
      ),
    );
  }
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Padding(
          padding: EdgeInsets.all(8),
          child: Column(
            children: [
              CartaoReceita(icone: Icons.cake, nome: 'Bolo de cenoura', detalhe: '40 minutos · 8 porções', favorita: true),
              CartaoReceita(icone: Icons.icecream, nome: 'Sorvete de manga', detalhe: '6 horas · 10 porções'),
              CartaoReceita(icone: Icons.local_pizza, nome: 'Pizza de liquidificador', detalhe: '50 minutos · 6 porções', favorita: true),
            ],
          ),
        ),
      ),
    );
  }
}
CartaoReceita
Um StatelessWidget nosso (aula StatelessWidget) com quatro campos final. O favorita tem valor padrão false, então só precisa ser escrito quando for true.
IconData icone
IconData é o tipo de Icons.cake, Icons.icecream etc.: o desenho do ícone, sem tamanho nem cor.
favorita ? Icons.star : Icons.star_border
O operador ternário do Dart: estrela cheia se for favorita, só o contorno se não for.

E se forem 200 receitas?

Uma Column não rola: com muitos cartões, os de baixo estouram a tela (o overflow). Para listas compridas, troque a Column por um ListView, que rola e cria só os cartões que aparecem na tela. É o assunto das aulas ListView e ListView.builder.

Quando dá errado

ListTile dentro de uma Row

          children: [
            ListTile(title: Text('Bolo')),
            ListTile(title: Text('Pudim')),
          ],
        ),

"As restrições obrigam uma largura infinita." O ListTile sempre tenta ocupar toda a largura que recebe (é assim que ele empurra o trailing para a ponta). Só que a Row não dá um limite de largura aos filhos: "pode ter quanto quiser". "Toda a largura" de "sem limite" é infinito, e nada pode ter largura infinita.

Como consertar: diga a cada ListTile quanto espaço ele tem, embrulhando-o num Expanded (aula Expanded e Flexible): Row(children: [Expanded(child: ListTile(…)), Expanded(child: ListTile(…))]). Por que a Row dá largura "sem limite" é explicado em Como o Flutter Calcula Tamanhos.

Cartão sem Padding: o texto colado na borda 
        body: const Card(
          child: Text('Bolo de cenoura com cobertura de chocolate', style: TextStyle(fontSize: 20)),
        ),

Não é um erro do Flutter (o console fica quieto), mas fica feio. Como consertar: ponha um Padding entre o Card e o conteúdo. Com ListTile dentro, não precisa: o ListTile já tem o espaço dele (no Material 3, 16 à esquerda e 24 à direita, que dá para mudar com contentPadding:).

Resumo

  • Card é um cartão do Material: fundo, cantos arredondados, sombra e uma margem de 4. Ele não tem padding: ponha um Padding dentro.
  • O Material 3 tem três estilos: Card() (elevado), Card.filled() e Card.outlined(); elevation, color, margin e shape mudam a aparência.
  • ListTile é uma linha pronta: leading, title, subtitle, trailing; com onTap, vira um botão.
  • Um ListTile dentro de cada Card é o jeito mais rápido de fazer uma lista bonita; para listas compridas, use ListView.
  • O ListTile quer saber a largura: numa Row, embrulhe-o num Expanded.
