Flutter Fontes Personalizadas

O nome do app de receitas ficou com cara de documento: a mesma letra de todos os apps Android. A Ana quer o título numa letra cursiva, de caderno de receitas da avó, e o texto corrido numa letra redonda e fácil de ler. No Flutter, há dois caminhos para usar outra fonte: colocar o arquivo da fonte no projeto (um .ttf) e declará-lo no pubspec.yaml, ou usar o pacote google_fonts, que traz as mais de mil fontes do Google Fonts com uma linha de código.

Você vai aprender
  • Qual é a fonte que o Flutter usa quando você não diz nada.
  • A pôr um arquivo de fonte no projeto e declará-lo no pubspec.yaml (família, pesos e itálico).
  • A usar a fonte num texto (fontFamily) e no app inteiro (pelo tema).
  • A usar o pacote google_fonts: uma fonte num texto, a fonte do app inteiro e a busca pelo nome.
  • A diferença entre baixar a fonte com o app rodando e embutir o arquivo no app.
  • Os erros comuns: o nome da família errado (que não avisa), o pubspec.yaml mal indentado, o nome que não existe no Google Fonts.

Esta aula usa o Flutter 3.47 e o google_fonts 9.0.0. As caixas "Experimente" rodam no DartPad (aula O Editor do Guia), que já traz o google_fonts. O laboratório de fotos do guia compila um arquivo só, sem pacotes e sem arquivos de fonte; por isso esta aula não tem fotos: rode as caixas para ver cada fonte.

A ideia: o jogo de carimbos de letras

Imagine que o app escreve com carimbos de letras. O Flutter já vem com um jogo de carimbos (a fonte padrão). Para escrever com outra letra, você precisa trazer outro jogo de carimbos para a cozinha e etiquetar a caixa com um nome ("Caderno"), para poder pedir: "escreva o título com os carimbos da caixa Caderno".

1. A fonte padrão

Sem você dizer nada, o Flutter com Material usa a Roboto no Android e na web, e a fonte do sistema da Apple (San Francisco) no iPhone. No laboratório do guia, que roda o Flutter na web, todos os textos das fotos das outras aulas estão em Roboto. Trocar a fonte é sempre somar uma fonte nova ao app; as do sistema continuam lá.

2. Uma fonte em arquivo: o pubspec.yaml

A Ana baixou a fonte Pacifico (cursiva) no site do Google Fonts: veio o arquivo Pacifico-Regular.ttf. São três passos.

  1. Copie o arquivo para uma pasta do projeto. O costume é assets/fonts/, na raiz do projeto (ao lado da lib/): 
    receitas_da_ana/
 ├─ lib/
 │   └─ main.dart
 ├─ assets/
 │   └─ fonts/
 │       └─ Pacifico-Regular.ttf
 └─ pubspec.yaml
  2. Declare a fonte no pubspec.yaml, dentro da seção flutter:: 
    flutter:
  uses-material-design: true

  fonts:
    - family: Caderno
      fonts:
        - asset: assets/fonts/Pacifico-Regular.ttf
  3. Pare o app e rode de novo (flutter run). Mudanças no pubspec.yaml não entram com a recarga a quente: o arquivo da fonte precisa ser empacotado no app.
fonts:
A lista de famílias de fonte do app. Fica dentro de flutter:, com dois espaços de recuo.
- family: Caderno
O nome da família: a "etiqueta da caixa". É este nome, e não o nome do arquivo, que você usa no código. Pode ser o nome original da fonte (Pacifico) ou um apelido seu.
fonts: / - asset: …
Os arquivos dessa família, com o caminho a partir da raiz do projeto.
O YAML é exigente com os espaços

No pubspec.yaml, o recuo (a quantidade de espaços no começo da linha) diz quem está dentro de quem, como as chaves { } do Dart. Use sempre espaços (nunca TAB) e alinhe os itens de mesmo nível. Um espaço a mais ou a menos e o flutter pub get reclama, ou, pior, a fonte é ignorada.

Pesos e itálico

Muitas fontes vêm em vários arquivos: o normal, o negrito, o itálico. Todos entram na mesma família, cada um dizendo o que é:

flutter:
  fonts:
    - family: Lato
      fonts:
        - asset: assets/fonts/Lato-Regular.ttf
        - asset: assets/fonts/Lato-Bold.ttf
          weight: 700
        - asset: assets/fonts/Lato-Italic.ttf
          style: italic
weight: 700
O "peso" desse arquivo: 400 é o normal, 700 é o negrito (FontWeight.bold é o mesmo que FontWeight.w700). Quando um texto pede fontWeight: FontWeight.bold, o Flutter escolhe este arquivo.
style: italic
Este arquivo é o itálico, usado com fontStyle: FontStyle.italic.

Sem o arquivo negrito, o Flutter ainda "engorda" a letra normal para imitar o negrito, mas o resultado fica pior que o desenhado pelo autor da fonte.

3. Usando a fonte: num texto e no app inteiro

import 'package:flutter/material.dart';

void main() => runApp(const ReceitasApp());

class ReceitasApp extends StatelessWidget {
  const ReceitasApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange, fontFamily: 'Lato'),
      home: Scaffold(
        appBar: AppBar(
          title: const Text(
            'Receitas da Ana',
            style: TextStyle(fontFamily: 'Caderno', fontSize: 26),
          ),
        ),
        body: const Padding(
          padding: EdgeInsets.all(16),
          child: Text('Rale as cenouras e bata no liquidificador com os ovos e o óleo.'),
        ),
      ),
    );
  }
}
TextStyle(fontFamily: 'Caderno')
Só este texto usa a família Caderno (a Pacifico). O nome tem de ser igual ao do family: do pubspec.yaml, com as mesmas maiúsculas.
ThemeData(fontFamily: 'Lato')
A fonte padrão do app inteiro: todos os textos, botões e barras que não pedirem outra. É a forma de trocar a "letra da casa" (a ideia de tema da aula Temas).

Este código não roda no editor do guia: o DartPad não tem os arquivos .ttf do seu projeto. Lá, os textos sairiam na fonte padrão, sem erro (veja Quando dá errado). Para ver a fonte de verdade, rode no seu projeto, ou use o pacote da próxima seção.

4. O pacote google_fonts

O pacote google_fonts, mantido pela equipe do Flutter, dá acesso às fontes do Google Fonts sem baixar arquivo nenhum à mão. Instale no projeto com:

$ flutter pub add google_fonts
« a saída (a lista dos pacotes baixados) não foi colhida no laboratório do guia, que ainda não tem terminal com o pub.dev

Cada fonte vira um método que devolve um TextStyle pronto:

import 'package:flutter/material.dart';
import 'package:google_fonts/google_fonts.dart';

void main() => runApp(const ReceitasApp());

class ReceitasApp extends StatelessWidget {
  const ReceitasApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange),
      home: Scaffold(
        appBar: AppBar(
          title: Text(
            'Receitas da Ana',
            style: GoogleFonts.pacifico(fontSize: 26),
          ),
        ),
        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Text(
            'Rale as cenouras e bata no liquidificador com os ovos e o óleo.',
            style: GoogleFonts.lato(fontSize: 18),
          ),
        ),
      ),
    );
  }
}
import 'package:google_fonts/google_fonts.dart';
Traz o pacote para o arquivo.
GoogleFonts.pacifico(fontSize: 26)
Um TextStyle com a fonte Pacifico. Ele aceita os mesmos parâmetros do TextStyle (fontSize, color, fontWeight…). O nome do método é o nome da fonte em minúsculas e sem espaços, no formato do Dart: "Open Sans" vira GoogleFonts.openSans().
Text(..., style: GoogleFonts.lato(...))
Repare que o Text perdeu o const: o estilo agora vem de uma função, que só roda com o app no ar.

Missão: troque a fonte do título por outra do Google Fonts, por exemplo GoogleFonts.lobster(), GoogleFonts.caveat() ou GoogleFonts.dancingScript(). Rode e compare.

A fonte do app inteiro

Para trocar a fonte de todos os textos, junte o pacote com o fontFamily do tema (seção 3): cada estilo do google_fonts sabe o nome da família que ele registrou, e é esse nome que o tema precisa:

theme: ThemeData(
  colorSchemeSeed: Colors.orange,
  fontFamily: GoogleFonts.lato().fontFamily,
),
GoogleFonts.lato()
Um TextStyle com a Lato (e, por trás, o pedido para baixar a fonte).
.fontFamily
Só o nome da família, um String, que o ThemeData(fontFamily: …) aceita. Todos os textos, botões e barras do app passam a usar a Lato.
E o GoogleFonts.latoTextTheme()?

Tutoriais e a própria página do pacote mostram outro jeito: textTheme: GoogleFonts.latoTextTheme(), que gera os 15 estilos de texto do tema (aula Temas) na fonte escolhida. Com o google_fonts 9.0.0 e o Flutter 3.47, essa linha não compila num app que importa o package:flutter/material.dart. O analisador do Dart, rodado no laboratório do guia, responde:

The argument type 'TextTheme' can't be assigned to the parameter type 'TextTheme?'. [argument_type_not_assignable]

"O tipo TextTheme não pode ser passado para o parâmetro do tipo TextTheme?". Parece absurdo (TextTheme no lugar de TextTheme?), mas são duas classes diferentes com o mesmo nome: a versão 9.0.0 do pacote passou a usar o Material de um pacote separado, o material_ui (está no registro de mudanças do pacote, "Migrates to material_ui"), e o TextTheme dele não é o do ThemeData do seu app. Até isso se acertar, use o fontFamily acima, que só passa um texto e funciona nos dois mundos.

A fonte pelo nome

Quando o nome da fonte vem de uma variável (uma configuração que a pessoa escolhe), use o getFont:

final fonteEscolhida = 'Caveat';
Text('Bolo de cenoura', style: GoogleFonts.getFont(fonteEscolhida, fontSize: 24));

Formas diferentes de fazer

Baixar na hora ou embutir no app?

Por padrão, o google_fonts baixa o arquivo da fonte da internet na primeira vez que o app a usa, e guarda no aparelho para as próximas. É prático, mas tem dois efeitos: na primeira abertura, o texto pode aparecer por um instante na fonte padrão e depois "pular" para a nova; e sem internet na primeira vez, a fonte não vem.

Para um app publicado, o pacote recomenda embutir os arquivos: baixe os .ttf do Google Fonts, ponha numa pasta listada nos assets do pubspec.yaml (aula Assets) e desligue o download:

void main() {
  GoogleFonts.config.allowRuntimeFetching = false;
  runApp(const ReceitasApp());
}

Arquivo .ttf + fonts: no pubspec.yamlFontes que não estão no Google Fonts (a fonte da marca), ou quando você quer controle total e nenhuma dependência

Duas fontes bastam

Um app bonito raramente usa mais que duas fontes: uma para títulos (com personalidade, como a Pacifico) e uma para o texto corrido (bem legível, como a Lato). Fontes cursivas são lindas em títulos curtos e cansativas num parágrafo inteiro.

Quando dá errado

Ilustrativo

Os casos abaixo não foram rodados no laboratório (ele não tem pacotes nem arquivos de fonte). A mensagem do google_fonts foi tirada do código do pacote, versão 9.0.0.

O nome da família errado: não dá erro, a fonte não muda 
Text('Receitas da Ana', style: TextStyle(fontFamily: 'caderno'))

No pubspec.yaml a família se chama Caderno, com C maiúsculo. O Flutter procura caderno, não acha e, sem avisar, usa a fonte padrão. O mesmo acontece quando o pubspec.yaml não foi salvo, quando o app não foi reiniciado depois da mudança (a recarga a quente não basta), ou quando o código roda num lugar que não tem o arquivo (como o DartPad). Como consertar: confira o nome letra por letra com o family:, salve o pubspec.yaml e rode o app de novo do zero.

O pubspec.yaml mal indentado 
flutter:
  fonts:
    - family: Caderno
    fonts:
        - asset: assets/fonts/Pacifico-Regular.ttf

O segundo fonts: devia estar alinhado com o family: (dois espaços a mais). Do jeito que está, o YAML o lê como outra chave no mesmo nível do primeiro fonts:, e o flutter pub get (que roda sozinho quando você salva o arquivo no VS Code) recusa o arquivo com uma mensagem apontando a linha. Como consertar: alinhe pelos exemplos desta aula; muitos editores mostram linhas-guia do recuo.

O arquivo que não está onde o pubspec.yaml diz

Se o caminho do asset: não bate com o arquivo (pasta errada, Pacifico-regular.ttf com r minúsculo), a compilação do app para com um erro dizendo que não achou o arquivo listado no pubspec.yaml. Como consertar: o caminho é relativo à raiz do projeto e diferencia maiúsculas de minúsculas: copie o nome do arquivo direto da pasta.

Um nome que não existe no Google Fonts 
GoogleFonts.getFont('Pacifco')

Com o nome escrito errado, o getFont lança a exceção No font family by name 'Pacifco' was found. ("nenhuma família de fonte com o nome 'Pacifco' foi encontrada"). Com os métodos com nome (GoogleFonts.pacifico()), esse erro não acontece: um método que não existe é pego pelo editor antes de rodar. Como consertar: copie o nome exato do site do Google Fonts, com espaços e maiúsculas ('Dancing Script').

Resumo

  • Sem dizer nada, o Flutter usa a Roboto (Android e web) ou a fonte da Apple (iPhone).
  • Fonte em arquivo: copie o .ttf para assets/fonts/, declare a família em flutter: fonts: no pubspec.yaml (com weight e style para negrito e itálico) e rode o app de novo.
  • Use com TextStyle(fontFamily: 'Nome') num texto, ou ThemeData(fontFamily: 'Nome') no app inteiro.
  • O google_fonts traz as fontes do Google: GoogleFonts.pacifico(), ThemeData(fontFamily: GoogleFonts.lato().fontFamily), GoogleFonts.getFont('Nome'). Por padrão baixa na hora; num app publicado, embuta os arquivos e use allowRuntimeFetching = false.
  • Nome de família errado não dá erro: a fonte simplesmente não muda. Confira maiúsculas, o recuo do YAML e reinicie o app.
