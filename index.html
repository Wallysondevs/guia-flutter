Tutorial Flutter

Aprenda a criar apps do zero com Flutter, como numa escola: cada widget é explicado pedaço por pedaço, você vê a tela de verdade que o código desenha e pratica aqui mesmo na página, com o app rodando logo abaixo do código. Com um código só, o mesmo app roda no Android, no iPhone, na web e no computador. Para começar, basta saber o básico de Dart (variáveis, funções e classes); se ainda não sabe, passe antes pelo Guia Dart.

Experimente agora

A caixa abaixo é o editor Experimente do guia. Em cima fica o código de um app completo, a lista de compras da Ana. Clique em ▶ Rodar: o código vai para o DartPad, a ferramenta oficial do Flutter feita pelo Google, que compila o app nos servidores dele e mostra a tela logo abaixo, em alguns segundos (precisa de internet). Pode mexer à vontade: nada que você fizer aqui estraga o guia.

Missão: rode o app como está e veja a lista. Depois, a Ana lembrou que acabou a manteiga: acrescente 'manteiga' na lista compras (depois de 'café', com uma vírgula antes) e rode de novo.

import 'package:flutter/material.dart';

void main() => runApp(const ListaDaAna());

class ListaDaAna extends StatelessWidget {
  const ListaDaAna({super.key});

  @override
  Widget build(BuildContext context) {
    const compras = ['pão', 'leite', 'café'];
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Compras da Ana')),
        body: ListView(
          children: [
            for (final item in compras)
              ListTile(
                leading: const Icon(Icons.shopping_cart),
                title: Text(item),
              ),
          ],
        ),
      ),
    );
  }
}

O que aconteceu: você escreveu a descrição de uma tela. Lido em voz alta, o código diz: "o app é um MaterialApp; a tela tem uma barra no topo com o título 'Compras da Ana' e, no corpo, uma lista; para cada item de compras, uma linha com um carrinho e o nome do item". Você não desenhou a linha nova: acrescentou um item na lista, e o Flutter montou a tela de novo, com uma linha a mais. Cada peça da tela (a barra, a lista, cada linha, o ícone, o texto) é um widget, e montar telas encaixando widgets é o que este guia ensina.

E se você esqueceu a vírgula? O app rodou, mas a última linha virou cafémanteiga: no Dart, dois textos escritos lado a lado, sem nada entre eles, viram um texto só. Por isso a missão pede a vírgula. Já se você esqueceu de fechar as aspas de 'manteiga, o DartPad não mostrou o app: mostrou mensagens em inglês, como Unterminated string literal. ("texto não terminado"), com a linha e a coluna, e no console Error: String starting with ' must end with '. ("um texto que começa com ' precisa terminar com '"). O compilador não adivinha: ele diz onde não entendeu. Errar e ler a mensagem é metade do aprendizado, e todas as aulas mostram os erros mais comuns, com a mensagem real e o jeito de consertar.

Um app que responde ao toque

Telas também mudam. Rode a caixa e clique no botão + do canto: o número sobe a cada toque. Esse é o famoso contador, o app que o Flutter cria quando você começa um projeto novo; o segredo dele, o setState, tem uma aula só para ele.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Contador()));

class Contador extends StatefulWidget {
  const Contador({super.key});

  @override
  State<Contador> createState() => _ContadorState();
}

class _ContadorState extends State<Contador> {
  int _cafes = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Cafés de hoje')),
      body: Center(
        child: Text('$_cafes', style: const TextStyle(fontSize: 64)),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => _cafes++),
        child: const Icon(Icons.add),
      ),
    );
  }
}

O que é este guia

Um app é um programa com telas: botões, listas, campos para digitar, imagens. O Flutter é o kit do Google para construir essas telas com a linguagem Dart. Em vez de desenhar a tela arrastando peças, você descreve a tela em código, encaixando widgets uns dentro dos outros, como blocos de montar: uma coluna com um título, uma foto e um botão; dentro do botão, um texto. A aula O que é Flutter conta essa história.

Quem aprende Flutter consegue:

  • montar telas bonitas e organizadas, que se ajustam ao celular, ao tablet e ao computador;
  • fazer a tela reagir: contar toques, marcar tarefas como feitas, validar um formulário;
  • criar apps com várias telas, menu lateral, abas e barra de navegação;
  • buscar dados na internet, guardar informações no aparelho e organizar o estado de um app maior (Provider, Riverpod);
  • testar, gerar o APK e publicar o app nas lojas.

O guia é para quem já fez o básico de Dart mas nunca fez um app. Cada aula ensina um assunto só (um widget ou uma ideia), com calma. O Flutter das aulas é o 3.47, com o Material 3, o visual padrão dos apps Android de hoje.

Como as aulas funcionam

Nenhum código aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do código, uma comparação do dia a dia: blocos de montar, caixas dentro de caixas, a vitrine de uma loja.
  2. Anatomia. Cada parte de um widget novo é separada e explicada: o widget, os parâmetros, o child (filho) e os children (filhos).
  3. A tela real. Depois de cada exemplo, a foto da tela que o código desenha, tirada de um Flutter de verdade. Nenhuma tela foi inventada.
  4. Experimente. Caixas para você mudar o código e ver o app rodando, muitas com uma missão que confere se você acertou.
  5. Várias formas de fazer. Quase sempre há mais de um widget para o mesmo resultado, e uma tabela "qual usar" mostra quando escolher cada um.
  6. Quando dá errado. O código com erro e o que acontece de verdade: as listras amarelas e pretas do overflow, a tela vermelha de erro, a mensagem do console, traduzida e explicada.
  7. Exercícios e resumo. Perguntas com a resposta na hora e uma lista curta do que levar da aula.

Exemplo: a anatomia de um app

Veja como as aulas desmontam um código. Este é o app da lista de compras, o da primeira caixa:

import 'package:flutter/material.dart';
Traz para o arquivo os widgets do Material, o conjunto de peças visuais do Google (barras, botões, listas, ícones). Todo app das aulas começa assim.
void main() => runApp(const ListaDaAna());
O ponto de partida, como em todo programa Dart. O runApp recebe o widget principal e o coloca na tela (aula Seu Primeiro App).
class ListaDaAna extends StatelessWidget
O seu próprio widget. Stateless quer dizer "sem estado": a tela não muda sozinha depois de desenhada (aula StatelessWidget).
Widget build(BuildContext context)
O método que descreve a tela. O Flutter chama o build e desenha o que ele devolve.
MaterialApp → Scaffold → AppBar e ListView
Widgets dentro de widgets: o app (MaterialApp) tem uma tela (Scaffold) com uma barra no topo e, no corpo, uma lista (ListView) de linhas (ListTile).
for (final item in compras) ListTile(…)
O for do Dart dentro da lista de filhos: uma linha para cada item. Mudou a lista, mudou a tela.

A árvore de widgets, a "planta" da tela, fica assim:

MaterialApp
└── Scaffold
    ├── AppBar
    │   └── Text('Compras da Ana')
    └── ListView
        ├── ListTile (pão)
        ├── ListTile (leite)
        └── ListTile (café)

Além do editor, as aulas mostram o terminal da máquina das aulas: um computador chamado notebook, da usuária ana, onde ela cria projetos com flutter create e roda os apps com flutter run (aulas Criando um Projeto e Rodando o App). A aula O Editor do Guia mostra como as caixas Experimente funcionam, e Instalar o Flutter ensina a pôr o Flutter no seu computador.

Como estudar

Fazer apps se aprende fazendo apps. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e olhe a foto da tela. Não pule a parte "Quando dá errado": quem reconhece as listras do overflow conserta o layout em segundos.
  2. Mexa nos exemplos. Em toda caixa Experimente, mude uma cor, troque um texto, tire um widget de propósito e veja o que acontece. Não tem como estragar nada: o ↺ Restaurar volta tudo ao começo.
  3. Faça as missões. As caixas com Missão conferem se o seu código tem o que foi pedido. Tente de verdade antes de abrir a solução; se abrir, digite a solução você mesmo em vez de só olhar.
  4. Repita no seu computador. Quando chegar à aula Instalar o Flutter, instale-o e refaça os apps num projeto de verdade, rodando no celular ou no emulador. Algumas coisas (vários arquivos, pacotes do pub.dev, câmera, gerar o APK) só existem lá.
A regra de ouro

Ler não basta: digite cada app. Copiar e colar ensina pouco; digitar faz você reparar em cada vírgula, cada parêntese e cada const. Comece pela aula O que é Flutter e, antes de ir longe, dê uma olhada em O Editor do Guia.

Versão de referência: Flutter 3.47 (Dart 3.13)

O guia ensina o Flutter 3.47 (a versão estável em outubro de 2026), com o Material 3. O DartPad das caixas Experimente roda a mesma versão (ele acompanha a versão estável do Flutter e pode, um dia, estar um pouco à frente). As mensagens do Flutter saem em inglês, exatamente como ele as escreve, e as aulas as explicam em português. Se o seu Flutter for mais novo, quase tudo funciona igual; as mudanças importantes aparecem em notas e na aula Novidades do Flutter.
