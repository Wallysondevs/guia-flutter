Flutter Slider e Dropdown

Mais duas formas de a pessoa responder sem digitar. O Slider ("controle deslizante") serve para escolher um número arrastando uma bolinha numa trilha: o volume, o brilho, quantas porções da receita. O dropdown ("lista suspensa") serve para escolher uma opção numa lista que só abre quando se toca: o sabor da pizza, o estado, a categoria.

Você vai aprender
  • Como usar o Slider: value (um double), min, max, divisions e label.
  • Como escolher uma faixa (de R$ 20 a R$ 50) com o RangeSlider.
  • A lista suspensa do Material 3: DropdownMenu com DropdownMenuEntry.
  • O DropdownButton clássico, que você vai encontrar em muito código por aí.
  • O erro real mais comum: o valor escolhido que não existe na lista de itens.

Os dois funcionam como os controles da aula Checkbox, Switch e Radio: o valor mora no seu estado, e o widget só avisa (pelo onChanged ou onSelected) quando a pessoa quer trocá-lo.

A ideia: o botão de volume e o cardápio

O Slider é o botão de volume do rádio: você não digita "37", você gira até achar. Serve quando o número exato importa menos do que "mais ou menos isso", e quando o intervalo é conhecido (de 0 a 100, de 1 a 12).

O dropdown é o cardápio que o garçom traz só quando você pede: fechado, ele mostra apenas o prato escolhido e ocupa pouco espaço; aberto, mostra todas as opções. Serve quando há opções demais para mostrar todas na tela (com 3 ou 4, os botões de opção da aula anterior são mais rápidos).

1. O Slider

A Ana quer que a receita de bolo se ajuste ao número de porções:

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Receita()));

class Receita extends StatefulWidget {
  const Receita({super.key});

  @override
  State<Receita> createState() => _ReceitaState();
}

class _ReceitaState extends State<Receita> {
  double porcoes = 4;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Bolo de cenoura')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            Text('Porções: ${porcoes.round()}', style: const TextStyle(fontSize: 20)),
            Slider(
              value: porcoes,
              min: 1,
              max: 12,
              divisions: 11,
              label: '${porcoes.round()}',
              onChanged: (novo) {
                setState(() {
                  porcoes = novo;
                });
              },
            ),
            Text('Farinha: ${(porcoes * 60).round()} g'),
            Text('Ovos: ${(porcoes * 0.75).ceil()}'),
          ],
        ),
      ),
    );
  }
}
double porcoes = 4;
O valor, no estado. É double (número com vírgula), mesmo que você só queira inteiros: o Slider trabalha sempre com double. O 4 vira 4.0 sozinho.
value: porcoes
Onde a bolinha está. Tem de ficar entre min e max.
min: 1, max: 12
As pontas da trilha. O padrão é de 0.0 a 1.0: sem eles, o 4 estaria fora da trilha (veja Quando dá errado).
divisions: 11
Divide a trilha em 11 pedaços iguais: a bolinha só para em 1, 2, 3… 12 (12 pontos, 11 espaços entre eles). Sem divisions, ela anda livre e o valor pode ser 4.3728….
label: '${porcoes.round()}'
O balãozinho com o número que aparece em cima da bolinha enquanto ela é arrastada. Por padrão, só aparece quando há divisions.
onChanged: (novo) { … }
Chamado muitas vezes durante o arrasto, a cada posição nova, com um double. Se você só quer saber o valor final (para salvar, por exemplo), existe também o onChangeEnd, chamado uma vez quando o dedo solta.
porcoes.round()
Arredonda para inteiro, para mostrar "4" e não "4.0".

Uma faixa: RangeSlider

Na busca da lojinha, a Ana quer filtrar "de R$ 20 a R$ 50". São duas bolinhas na mesma trilha. O RangeSlider funciona igual, mas o valor é um RangeValues (um par: começo e fim):

RangeValues faixa = const RangeValues(20, 50);

// no build:
RangeSlider(
  values: faixa,
  min: 0,
  max: 100,
  divisions: 20,
  labels: RangeLabels('R\$ ${faixa.start.round()}', 'R\$ ${faixa.end.round()}'),
  onChanged: (nova) {
    setState(() {
      faixa = nova;
    });
  },
)

faixa.start é o começo e faixa.end, o fim. Repare no \$: dentro de um texto do Dart, o $ sozinho começa uma interpolação; para escrever o cifrão de verdade, use \$.

2. A lista suspensa do Material 3: DropdownMenu

O sabor da pizza, numa lista que abre quando a pessoa toca:

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Pedido()));

class Pedido extends StatefulWidget {
  const Pedido({super.key});

  @override
  State<Pedido> createState() => _PedidoState();
}

class _PedidoState extends State<Pedido> {
  String? sabor;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pizzaria da Ana')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            DropdownMenu<String>(
              label: const Text('Sabor'),
              width: 300,
              onSelected: (escolhido) {
                setState(() {
                  sabor = escolhido;
                });
              },
              dropdownMenuEntries: const [
                DropdownMenuEntry(value: 'mussarela', label: 'Mussarela'),
                DropdownMenuEntry(value: 'calabresa', label: 'Calabresa'),
                DropdownMenuEntry(value: 'margherita', label: 'Margherita'),
                DropdownMenuEntry(value: 'portuguesa', label: 'Portuguesa'),
              ],
            ),
            const SizedBox(height: 24),
            Text(sabor == null ? 'Escolha um sabor' : 'Sabor: $sabor'),
          ],
        ),
      ),
    );
  }
}
String? sabor;
O escolhido, no estado. Começa null: nada escolhido.
DropdownMenu<String>(…)
A lista suspensa. O <String> diz o tipo dos valores das opções (podia ser um enum, um int…).
label: const Text('Sabor')
O rótulo, que se comporta como o do TextField: dentro da caixa quando vazia, na borda quando tem valor.
width: 300
A largura da caixa, em pixels lógicos. Sem ela, a caixa fica da largura da opção mais comprida.
onSelected: (escolhido) { … }
Chamado quando a pessoa escolhe uma opção, com o value dela ('calabresa', não 'Calabresa'). O tipo é String?.
dropdownMenuEntries: [DropdownMenuEntry(value: …, label: …)]
As opções. Cada uma tem um value (o que o código usa, e que tem de ser único na lista) e um label (o texto que a pessoa vê).

Fechado, o menu é só uma caixa com o rótulo e uma setinha. A Ana tocou na caixa, e a lista abriu logo abaixo; ela tocou em Calabresa:

Repare na última foto: a caixa mostra o label (Calabresa), mas o texto de baixo mostra o value (calabresa), que é o que chega no onSelected.

Para o menu já abrir com uma opção escolhida, passe initialSelection: 'mussarela'. E com enableFilter: true, a pessoa pode digitar na caixa para filtrar as opções: ótimo para listas longas, como os 27 estados do Brasil.

3. O clássico: DropdownButton

Antes do DropdownMenu, o jeito era o DropdownButton. Ele continua no Flutter e aparece em muito tutorial, então vale reconhecer:

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Pedido()));

class Pedido extends StatefulWidget {
  const Pedido({super.key});

  @override
  State<Pedido> createState() => _PedidoState();
}

class _PedidoState extends State<Pedido> {
  String sabor = 'mussarela';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Pizzaria da Ana')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: DropdownButton<String>(
          value: sabor,
          onChanged: (escolhido) {
            setState(() {
              sabor = escolhido!;
            });
          },
          items: const [
            DropdownMenuItem(value: 'mussarela', child: Text('Mussarela')),
            DropdownMenuItem(value: 'calabresa', child: Text('Calabresa')),
            DropdownMenuItem(value: 'margherita', child: Text('Margherita')),
          ],
        ),
      ),
    );
  }
}
value: sabor
A opção mostrada. Diferente do DropdownMenu, aqui você diz qual está escolhida a cada build (é um controle controlado, como o Checkbox).
onChanged: (escolhido) { … }
Recebe o value da opção tocada (String?; daí o !). Com onChanged: null, o botão fica desativado.
items: [DropdownMenuItem(value: …, child: …)]
As opções. O child é um widget (pode ter ícone, cor…), não só um texto.

O DropdownButton é mais simples: sem borda nem rótulo, só o texto escolhido com uma setinha e uma linha embaixo. Tocado, ele abre a lista por cima do botão, com a opção atual destacada:

Qual usar

SituaçãoO que usar
Um número num intervalo, sem precisar ser exatoSlider (com divisions para inteiros)
Um intervalo (de… até…)RangeSlider
Um número exato (CPF, quantidade de 1 a 999)TextField com keyboardType: TextInputType.number (aula TextField)
Uma opção entre muitas (mais de 5)DropdownMenu (com enableFilter se a lista for longa)
Uma opção entre poucas, todas à vistaRadioGroup (aula Checkbox, Switch e Radio)
Código antigo, ou dentro de um FormDropdownButton / DropdownButtonFormField

Quando dá errado

O valor do DropdownButton não está nos itens

A Ana escreveu o valor inicial com letra maiúscula: String sabor = 'Mussarela';, mas os value dos itens estão em minúsculas ('mussarela'). A tela não abre, e o console mostra (de um teste da Ana que só abre a tela):

The following assertion was thrown building Pedido(dirty, state: _PedidoState#aee88):
There should be exactly one item with [DropdownButton]'s value: Mussarela.
Either zero or 2 or more [DropdownMenuItem]s were detected with the same value
'package:flutter/src/material/dropdown.dart':
Failed assertion: line 1028 pos 10: 'items == null ||
             items.isEmpty ||
             value == null ||
             items.where((DropdownMenuItem<T> item) {
                   return item.value == value;
                 }).length ==
                 1'
There should be exactly one item with [DropdownButton]'s value: Mussarela.
"Deveria haver exatamente um item com o valor do DropdownButton: Mussarela."
Either zero or 2 or more [DropdownMenuItem]s were detected…
"Foram encontrados zero, ou dois ou mais, itens com esse valor." Aqui foram zero: 'Mussarela' ≠ 'mussarela' (o Dart diferencia maiúsculas). O outro caso é ter dois itens com o mesmo value.
Failed assertion: … .length == 1
A conferência que o Flutter fez: conta os itens com aquele valor e exige que seja exatamente 1.

Como consertar: o value tem de ser igual ao de um dos itens, ou null. Usar um enum em vez de String evita o erro de digitação: o Dart nem compila se a opção não existir.

O Slider com o valor fora da trilha

O app da seção 1 sem as linhas min: 1,, max: 12, e divisions: 11,. O valor inicial continua 4, mas a trilha agora vai do padrão, 0 a 1:

══╡ EXCEPTION CAUGHT BY WIDGETS LIBRARY ╞═══════════════════════════════════════════════════════════
The following assertion was thrown building Receita(dirty, state: _ReceitaState#f2df1):
Value 4.0 is not between minimum 0.0 and maximum 1.0
'package:flutter/src/material/slider.dart':
Failed assertion: line 202 pos 10: 'value >= min && value <= max'

"O valor 4.0 não está entre o mínimo 0.0 e o máximo 1.0." Repare que o Flutter mostra 4.0: o 4 virou double. Como consertar: dê o min e o max certos, e garanta que o valor inicial (e qualquer valor que você puser no estado pelo código) fique dentro deles; se precisar, use valor.clamp(min, max), que "prende" o número no intervalo.

A bolinha não anda

Sem erro nenhum: a pessoa arrasta e a bolinha volta. É o mesmo caso da caixa que não marca: faltou o setState no onChanged, ou o value é fixo (value: 4) em vez de vir do estado. Como consertar: guarde o valor no State e troque com setState.

Missão final: a gorjeta

Missão: a conta do restaurante deu R$ 120. Acrescente um Slider de gorjeta de 0 a 20 (por cento), de 5 em 5 (divisions: 4), ligado à variável gorjeta, e veja o total mudar.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Conta()));

class Conta extends StatefulWidget {
  const Conta({super.key});

  @override
  State<Conta> createState() => _ContaState();
}

class _ContaState extends State<Conta> {
  double gorjeta = 10;

  @override
  Widget build(BuildContext context) {
    final total = 120 * (1 + gorjeta / 100);
    return Scaffold(
      appBar: AppBar(title: const Text('Conta')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            Text('Gorjeta: ${gorjeta.round()}%'),
            // o Slider vai aqui
            Text('Total: R\$ ${total.toStringAsFixed(2)}',
                style: const TextStyle(fontSize: 24)),
          ],
        ),
      ),
    );
  }
}

Resumo

  • Slider: value é double, entre min e max; divisions faz a bolinha parar em pontos certos e liga o label.
  • RangeSlider escolhe uma faixa, com RangeValues(começo, fim).
  • DropdownMenu é a lista suspensa do Material 3: opções em DropdownMenuEntry(value, label) e a escolha no onSelected.
  • DropdownButton é o jeito clássico: o value tem de existir em exatamente um item, senão o Flutter acusa o erro.
  • Como em todo controle, o valor mora no estado e muda com setState.
