Flutter TextStyle: estilos de texto

Na aula Text, todo texto saiu igual: mesmo tamanho, mesma cor. Mas o nome de uma receita precisa ser grande, o preço precisa chamar atenção, e o preço antigo de uma promoção aparece riscado. Quem decide a aparência das letras é o TextStyle, que vai no parâmetro style do Text.

Você vai aprender
  • A mudar o tamanho (fontSize), o peso (fontWeight) e a cor (color).
  • Itálico, espaçamento entre letras e entre linhas.
  • Sublinhado e riscado (decoration).
  • A usar os estilos prontos do tema (Theme.of(context).textTheme) e a ajustar um deles com copyWith.
  • Os erros reais: uma cor que não pode ser const e um FontWeight escrito errado.

Todos os apps desta aula foram compilados com o Flutter 3.47.7 do laboratório e fotografados numa tela do tamanho de um celular.

A ideia: a ficha de formatação

Num editor de textos, você seleciona uma palavra e escolhe: tamanho 20, negrito, vermelho. O TextStyle é essa ficha de formatação, escrita em código. O Text carrega o conteúdo; o TextStyle carrega a aparência. Tudo o que você não preencher na ficha continua com o valor do tema.

1. Tamanho, peso e cor

import 'package:flutter/material.dart';

void main() {
  runApp(const MeuApp());
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const Column(
          children: [
            Text('Bolo de cenoura'),
            Text(
              'Bolo de cenoura',
              style: TextStyle(fontSize: 28),
            ),
            Text(
              'Bolo de cenoura',
              style: TextStyle(fontSize: 28, fontWeight: FontWeight.bold),
            ),
            Text(
              'Bolo de cenoura',
              style: TextStyle(
                fontSize: 28,
                fontWeight: FontWeight.bold,
                color: Colors.deepOrange,
              ),
            ),
          ],
        ),
      ),
    );
  }
}
style:
O parâmetro do Text que recebe o estilo.
TextStyle( ... )
A ficha de formatação. Todos os parâmetros são opcionais.
fontSize: 28
O tamanho da letra, em pontos lógicos (a medida do Flutter, que é a mesma em telas de densidades diferentes). O padrão do corpo do texto no Material 3 é 14.
fontWeight: FontWeight.bold
O peso (a "grossura") da letra. FontWeight.bold é o negrito; também existem FontWeight.w100 (bem fininha) até FontWeight.w900 (bem grossa), com .normal = w400 e .bold = w700.
color: Colors.deepOrange
A cor da letra. Colors traz as cores do Material com nome (Colors.red, Colors.teal...).

2. Itálico, espaçamento e altura da linha

        body: const Column(
          children: [
            Text(
              'Receita da vó Lurdes',
              style: TextStyle(fontSize: 20, fontStyle: FontStyle.italic),
            ),
            Text(
              'SOBREMESAS',
              style: TextStyle(fontSize: 20, letterSpacing: 6),
            ),
            Text(
              'Bata tudo no liquidificador e leve ao forno. '
              'Espere esfriar antes de cobrir.',
              style: TextStyle(fontSize: 16, height: 2),
            ),
          ],
        ),
fontStyle: FontStyle.italic
Itálico, a letra inclinada. O contrário é FontStyle.normal.
letterSpacing: 6
Espaço extra entre as letras, em pontos. Fica bonito em títulos curtos em maiúsculas. Valores negativos apertam as letras.
height: 2
A altura da linha, como múltiplo do tamanho da letra: 2 = linhas com o dobro da altura da letra, um texto mais "arejado".

3. Sublinhado e riscado: decoration

A lojinha da Ana está em promoção: o preço antigo aparece riscado, e o novo, em destaque.

          children: [

                color: Colors.grey,
                decoration: TextDecoration.lineThrough,
              ),
            ),
            Text(
              'R\$ 39,90',
              style: TextStyle(
                fontSize: 28,
                fontWeight: FontWeight.bold,
                color: Colors.green,
              ),

            Text(
              'Ver condições',
              style: TextStyle(
                color: Colors.blue,
                decoration: TextDecoration.underline,

'R\$ 45,00'
O $ é especial nas strings do Dart (é a interpolação, aula Text). Para escrever um cifrão de verdade, use \$.

Uma linha atravessando o texto: o riscado.
decoration: TextDecoration.underline
Uma linha embaixo do texto: o sublinhado. Há ainda TextDecoration.overline (linha em cima).

4. Os estilos prontos do tema

Escrever fontSize: 28, fontWeight: FontWeight.bold em cada título do app é repetitivo, e cada tela acaba com um tamanho diferente. O Material 3 já traz uma escala de estilos prontos, com nomes: display (enorme), headline, title, body (o texto comum) e label (botões e rótulos), cada um em Large, Medium e Small. Você os pega do tema com Theme.of(context).textTheme:

import 'package:flutter/material.dart';

void main() {
  runApp(const MeuApp());
}

class MeuApp extends StatelessWidget {
  const MeuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: const Text('Receitas da Ana')),
        body: const TelaReceita(),
      ),
    );
  }
}

class TelaReceita extends StatelessWidget {
  const TelaReceita({super.key});

  @override
  Widget build(BuildContext context) {
    final estilos = Theme.of(context).textTheme;

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text('Bolo de cenoura', style: estilos.headlineMedium),
        Text('Sobremesas', style: estilos.titleMedium),
        Text('Rende 8 porções. Pronto em 50 minutos.', style: estilos.bodyMedium),
        Text(
          'Receita favorita',
          style: estilos.labelLarge?.copyWith(color: Colors.deepOrange),
        ),
      ],
    );
  }
}
Theme.of(context)
"O tema deste lugar da árvore": pega o tema que o MaterialApp lá de cima definiu. Precisa do context, e é por isso que a tela virou um widget separado (TelaReceita), cujo context fica abaixo do MaterialApp.
.textTheme
A escala de estilos de texto do tema.
estilos.headlineMedium
O estilo "manchete média", bom para o nome de uma tela ou de um item importante.
?.copyWith(color: ...)
copyWith = "uma cópia com": copia o estilo pronto e troca só o que você disser (aqui, a cor). O ?. está ali porque, para o Dart, os estilos do tema podem ser null.
crossAxisAlignment: CrossAxisAlignment.start
Alinha os textos da coluna à esquerda (aula Alinhamento).

Formas diferentes: estilo na mão, estilo do tema

FormaQuando usar
TextStyle(fontSize: 24, ...)Um detalhe único (o preço riscado, uma etiqueta colorida). Rápido, mas não acompanha o tema.
Theme.of(context).textTheme.titleLargeO recomendado para títulos e textos comuns: o app inteiro fica coerente, e muda junto se você mudar o tema (ou o tema escuro).
...titleLarge?.copyWith(color: ...)O estilo do tema com um ajuste pequeno.
ThemeData(textTheme: ...)Para mudar a escala do app inteiro (aula Temas); fontes de fora estão em Fontes Personalizadas.

Quando dá errado

Os erros abaixo são de compilação: o compilador do flutter run recusa o código e o app não abre.

Uma cor que não é const dentro de um Text const

A Ana quis um laranja mais escuro, o shade700 (o arquivo é o da seção 1; o Text está na linha 15):

        body: const Text(
          'Bolo de cenoura',
          style: TextStyle(color: Colors.orange.shade700),
        ),

lib/main.dart:17:42: Error: Not a constant expression.
          style: TextStyle(color: Colors.orange.shade700),
                                         ^^^^^^
lib/main.dart:15:21: Error: Constant evaluation error:
        body: const Text(
                    ^
lib/main.dart:17:49: Context: The property 'shade700' can't be accessed on 'MaterialColor {}' in a constant expression.
 - 'MaterialColor' is from 'package:flutter/src/material/colors.dart'.   « caminho do arquivo cortado
          style: TextStyle(color: Colors.orange.shade700),
                                                ^
Not a constant expression.
"Não é uma expressão constante": o const do Text exige que tudo dentro dele seja conhecido antes de o app rodar.
Constant evaluation error: (linha 15)
Aponta o const que exigiu isso: o do Text.
The property 'shade700' can't be accessed on 'MaterialColor {}' in a constant expression.
A explicação: "não dá para ler a propriedade shade700 de uma MaterialColor numa expressão constante". Colors.orange é const; o .shade700 é calculado na hora.

Como consertar: tire o const de antes do Text (e de qualquer widget acima dele que o contenha). Ou use uma cor const, como Colors.deepOrange ou Color(0xFFF57C00) (o código hexadecimal da cor).

bold sem o FontWeight. 
        body: const Text(
          'Bolo de cenoura',
          style: TextStyle(fontWeight: bold),
        ),

lib/main.dart:17:40: Error: Not a constant expression.
          style: TextStyle(fontWeight: bold),
                                       ^^^^

A mensagem engana: ela fala de "expressão constante", mas o problema é que não existe nada chamado bold sozinho. O Dart procurou esse nome, não achou, e, como ele está dentro de um const, reclamou do const. Como consertar: FontWeight.bold. O mesmo vale para FontStyle.italic, TextDecoration.underline e TextAlign.center: o valor sempre vem com o nome da classe na frente.

Resumo

  • O TextStyle vai no style do Text e define a aparência: fontSize, fontWeight, color, fontStyle, letterSpacing, height, decoration.
  • O que você não preencher continua com o valor do tema.
  • Prefira os estilos do tema: Theme.of(context).textTheme.titleLarge, e ajuste com copyWith.
  • Num Text const, só cabem cores const: Colors.orange sim, Colors.orange.shade700 não.
  • Cifrão dentro de string: \$.
