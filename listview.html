Flutter ListView

Quase todo app tem uma lista: as conversas do WhatsApp, os produtos da loja, as músicas de um álbum. No Flutter, a peça para isso é a ListView ("visão de lista"): ela põe os filhos um embaixo do outro, como a Column, mas com uma diferença essencial: ela rola. Se os itens não cabem na tela, o usuário arrasta o dedo e vê o resto, sem as listras de overflow.

Você vai aprender
  • Como montar uma lista que rola com ListView(children: [...]).
  • A diferença entre ListView e Column.
  • Os parâmetros mais usados: padding e scrollDirection (lista horizontal).
  • O erro real Vertical viewport was given unbounded height, de quem põe uma ListView dentro de uma Column, e como resolver.

As telas e o console desta aula vieram de um Flutter de verdade, no laboratório da Ana, em tamanho de celular.

A ideia: o rolo de papel da lista de compras

A Column é uma folha de papel do tamanho da tela: o que não cabe fica para fora (o erro de overflow). A ListView é um rolo de papel atrás de uma janela: a janela tem o tamanho da tela, o papel é tão comprido quanto a lista, e você puxa o papel para ver o resto.

2. ListView ou Column?

ColumnListView
Rola?Não (só dentro de um SingleChildScrollView)Sim
AlturaDo tamanho dos filhos (ou da tela)Ocupa todo o espaço que recebe na direção da rolagem
Muitos itensOverflowRola
Centralizar e distribuir (mainAxisAlignment)SimNão
Use paraPoucos itens que cabem na tela: um formulário curto, um cartãoListas: compras, produtos, mensagens
E se a lista tiver mil itens?

A ListView(children: [...]) monta todos os filhos de uma vez, mesmo os que estão fora da tela. Para 14 itens, tudo bem. Para centenas, ou para uma lista que vem de um banco de dados ou da internet, use a ListView.builder, que só monta os itens que aparecem.

3. Lista horizontal: scrollDirection

A tela de receitas da Ana tem uma faixa de categorias que rola para o lado, como as "prateleiras" dos apps de streaming:

        body: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            const Padding(
              padding: EdgeInsets.all(16),
              child: Text('Categorias', style: TextStyle(fontSize: 22)),
            ),
            SizedBox(
              height: 100,
              child: ListView(
                scrollDirection: Axis.horizontal,
                padding: const EdgeInsets.symmetric(horizontal: 8),
                children: [
                  for (final c in ['Bolos', 'Pães', 'Doces', 'Massas', 'Sopas', 'Saladas'])
                    Card(
                      child: SizedBox(
                        width: 110,
                        child: Center(child: Text(c, style: const TextStyle(fontSize: 18))),
                      ),
                    ),
                ],
              ),
            ),
          ],
        ),
SizedBox(height: 100, child: ListView(…))
Uma lista horizontal precisa de uma altura definida: ela ocupa a largura toda e rola de lado, mas não sabe quão alta ser. O SizedBox (veja SizedBox) dá 100 pixels.
scrollDirection: Axis.horizontal
"Direção da rolagem: horizontal." O padrão é Axis.vertical.
padding: const EdgeInsets.symmetric(horizontal: 8)
Um respiro nas pontas da lista, dentro da área que rola: some quando você rola, ao contrário de um Padding por fora.
for (final c in [...]) Card(…)
Um cartão para cada categoria, com o collection for do Dart.

Três cartões inteiros (Bolos, Pães, Doces) e a beirada do quarto na borda direita, sem listras. Esse pedaço cortado é de propósito no design: é o convite para o usuário arrastar para o lado e ver Massas, Sopas e Saladas.

Vertical viewport was given unbounded height.
"Uma janela de rolagem vertical recebeu uma altura ilimitada." A viewport é a "janela" da ListView.

"Janelas de rolagem crescem na direção da rolagem até encher o espaço." A ListView quer ocupar toda a altura que recebe. Mas a Column deixa cada filho ser tão alto quanto quiser, e "toda a altura do infinito" não é um tamanho.

Como consertar: diga à ListView quanto espaço ela tem. O jeito mais comum é o Expanded (veja Expanded e Flexible): "ocupe o que sobrou da coluna":

        body: Column(
          children: [
            const Padding(
              padding: EdgeInsets.all(16),
              child: Text('Faltam 3 itens', style: TextStyle(fontSize: 22)),
            ),
            Expanded(
              child: ListView(
                children: const [
                  ListTile(title: Text('Ovos')),
                  ListTile(title: Text('Leite')),
                  ListTile(title: Text('Café')),
                ],
              ),
            ),
          ],
        ),

Outra saída é uma altura fixa (SizedBox(height: 300, child: ListView(…))), como na lista horizontal da seção 3.

3. O console mostra Vertical viewport was given unbounded height. O que fazer?

Resumo

  • ListView(children: [...]) põe os filhos um embaixo do outro e rola quando eles não cabem: sem overflow.
  • O ListTile é a linha pronta: leading, title, subtitle, trailing.
  • scrollDirection: Axis.horizontal faz a lista rolar de lado; dê a ela uma altura com SizedBox.
  • Dentro de uma Column, a ListView precisa de um Expanded (ou de uma altura fixa); senão, Vertical viewport was given unbounded height e a tela em branco.
  • Para listas grandes ou que vêm de dados, use a ListView.builder.
