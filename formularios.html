Flutter Form e validação

Na aula TextField, a Ana aprendeu a pôr campos na tela. Agora ela quer um cadastro de clientes para a lojinha: nome, e-mail e idade. E não quer que ninguém aperte "Salvar" com o nome em branco ou um e-mail sem @. Conferir se o que foi digitado presta se chama validar, e o Flutter tem uma dupla pronta para isso: o Form ("formulário") e o TextFormField ("campo de formulário").

Você vai aprender
  • Como agrupar campos num Form e trocar o TextField pelo TextFormField.
  • O que é o validator: uma função que devolve a mensagem de erro ou null se está tudo certo.
  • Como conferir todos os campos de uma vez com uma GlobalKey<FormState> e validate().
  • Como guardar os valores com onSaved e save(), e limpar tudo com reset().
  • Como validar enquanto a pessoa digita (autovalidateMode).
  • Validações comuns: obrigatório, e-mail, número, tamanho mínimo, senha repetida.
  • O erro real mais comum: esquecer a key do Form.

A ideia: a recepcionista que confere a ficha

Lembra da ficha de papel na recepção? Quando você a entrega, a recepcionista passa os olhos em cada linha e devolve: "faltou o telefone", "esse CPF está com um número a menos". Ela confere tudo de uma vez e marca cada linha que está errada.

  • Cada linha da ficha sabe a sua regra ("o telefone tem de ter 11 números"). No Flutter, essa regra é o validator do TextFormField.
  • A ficha inteira é o Form. Ele junta as linhas.
  • A recepcionista que confere tudo é você, chamando validate() no botão "Salvar". Para alcançar o Form lá do botão, você usa uma chave (GlobalKey), como o crachá que diz "esta é a ficha do cliente 42".

1. Um campo obrigatório

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Cadastro()));

class Cadastro extends StatefulWidget {
  const Cadastro({super.key});

  @override
  State<Cadastro> createState() => _CadastroState();
}

class _CadastroState extends State<Cadastro> {
  final _formKey = GlobalKey<FormState>();

  void salvar() {
    if (_formKey.currentState!.validate()) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Cliente salvo!')),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Novo cliente')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                decoration: const InputDecoration(
                  labelText: 'Nome',
                  border: OutlineInputBorder(),
                ),
                validator: (valor) {
                  if (valor == null || valor.trim().isEmpty) {
                    return 'Digite o nome do cliente';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 16),
              FilledButton(onPressed: salvar, child: const Text('Salvar')),
            ],
          ),
        ),
      ),
    );
  }
}
final _formKey = GlobalKey<FormState>();
A chave do formulário, criada uma vez no State. Ela dá acesso ao FormState, o "estado" do formulário, de qualquer lugar da tela. O _ no começo do nome a deixa privada ao arquivo (convenção do Dart).
Form(key: _formKey, child: …)
O formulário. Ele não desenha nada: só junta os TextFormField que estão dentro dele, em qualquer profundidade (aqui, dentro de uma Column).
TextFormField(…)
Um TextField que sabe participar de um Form. Aceita os mesmos parâmetros (decoration, keyboardType, obscureText, controller…) e mais alguns: validator, onSaved, initialValue.
validator: (valor) { … }
A regra do campo. Recebe o texto (um String?) e devolve: um texto, que é a mensagem de erro, se o valor não presta; ou null, que quer dizer "está certo". Parece ao contrário, mas pense assim: a função responde "qual é o problema?"; null = "nenhum".
_formKey.currentState!.validate()
Chama o validator de todos os campos do formulário, mostra as mensagens de erro embaixo de cada campo errado e devolve true só se todos responderam null. O ! diz ao Dart "eu garanto que o formulário existe" (o currentState pode ser null se a chave não estiver em nenhum Form; veja Quando dá errado).

Ao abrir, o campo está vazio e sem erro nenhum: o validator só roda quando alguém chama validate().

2. Vários campos, cada um com a sua regra

O cadastro completo da Ana: nome, e-mail e idade. Cada campo tem o seu validator, e o validate() confere os três de uma vez:

TextFormField(
  decoration: const InputDecoration(labelText: 'Nome', border: OutlineInputBorder()),
  validator: (valor) {
    if (valor == null || valor.trim().isEmpty) return 'Digite o nome do cliente';
    if (valor.trim().length < 3) return 'O nome precisa de pelo menos 3 letras';
    return null;
  },
),
const SizedBox(height: 16),
TextFormField(
  keyboardType: TextInputType.emailAddress,
  decoration: const InputDecoration(labelText: 'E-mail', border: OutlineInputBorder()),
  validator: (valor) {
    if (valor == null || valor.isEmpty) return 'Digite o e-mail';
    if (!valor.contains('@') || !valor.contains('.')) return 'E-mail inválido';
    return null;
  },
),
const SizedBox(height: 16),
TextFormField(
  keyboardType: TextInputType.number,
  decoration: const InputDecoration(labelText: 'Idade', border: OutlineInputBorder()),
  validator: (valor) {
    final idade = int.tryParse(valor ?? '');
    if (idade == null) return 'Digite a idade em números';
    if (idade < 18) return 'O cliente precisa ter 18 anos ou mais';
    return null;
  },
),
if (…) return '…';
As regras vão da mais básica para a mais detalhada. A primeira que falhar devolve a sua mensagem, e as outras nem são testadas: a pessoa vê um problema de cada vez, o mais importante primeiro.
valor.contains('@')
Uma conferência simples de e-mail: tem @ e tem ponto. Não garante que o e-mail existe (só mandando uma mensagem para ele dá para saber), mas pega os erros de digitação mais comuns.
int.tryParse(valor ?? '')
Tenta transformar o texto em número inteiro; se não der ('vinte', ''), devolve null, sem erro. O ?? '' troca um valor nulo por texto vazio. Lembre: o keyboardType: TextInputType.number só escolhe o teclado, não impede a pessoa de colar letras, então a conferência é necessária.

3. Guardando os valores: onSaved e save()

Validou, deu certo. E agora, como pegar o que foi digitado? Uma forma é dar um TextEditingController a cada campo (como na aula TextField). Outra, mais limpa num formulário grande, é o par onSaved + save():

String nome = '';
String email = '';
int idade = 0;

void salvar() {
  final form = _formKey.currentState!;
  if (form.validate()) {
    form.save();
    debugPrint('Salvo: $nome, $email, $idade anos');
  }
}

// nos campos:
TextFormField(
  decoration: const InputDecoration(labelText: 'Nome'),
  validator: …,
  onSaved: (valor) => nome = valor!.trim(),
),
TextFormField(
  decoration: const InputDecoration(labelText: 'E-mail'),
  validator: …,
  onSaved: (valor) => email = valor!,
),
TextFormField(
  decoration: const InputDecoration(labelText: 'Idade'),
  validator: …,
  onSaved: (valor) => idade = int.parse(valor!),
),
form.save()
Chama o onSaved de todos os campos. Só chame depois que o validate() deu true: assim você sabe que os valores prestam.
onSaved: (valor) => nome = valor!.trim()
Recebe o texto do campo e guarda numa variável do State. O ! é seguro aqui porque o validator já garantiu que não é nulo.
int.parse(valor!)
Agora pode ser parse (que dá erro se não for número) em vez de tryParse, porque o validator já conferiu.

O cadastro completo, juntando os validadores da seção 2, o onSaved e o reset() (que você vai ver logo abaixo):

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Cadastro()));

class Cadastro extends StatefulWidget {
  const Cadastro({super.key});

  @override
  State<Cadastro> createState() => _CadastroState();
}

class _CadastroState extends State<Cadastro> {
  final _formKey = GlobalKey<FormState>();
  String nome = '';
  String email = '';
  int idade = 0;

  void salvar() {
    final form = _formKey.currentState!;
    if (form.validate()) {
      form.save();
      debugPrint('Salvo: $nome, $email, $idade anos');
      form.reset();
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Novo cliente')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                decoration: const InputDecoration(
                  labelText: 'Nome',
                  border: OutlineInputBorder(),
                ),
                validator: (valor) {
                  if (valor == null || valor.trim().isEmpty) {
                    return 'Digite o nome do cliente';
                  }
                  if (valor.trim().length < 3) {
                    return 'O nome precisa de pelo menos 3 letras';
                  }
                  return null;
                },
                onSaved: (valor) => nome = valor!.trim(),
              ),
              const SizedBox(height: 16),
              TextFormField(
                keyboardType: TextInputType.emailAddress,
                decoration: const InputDecoration(
                  labelText: 'E-mail',
                  border: OutlineInputBorder(),
                ),
                validator: (valor) {
                  if (valor == null || valor.isEmpty) return 'Digite o e-mail';
                  if (!valor.contains('@') || !valor.contains('.')) {
                    return 'E-mail inválido';
                  }
                  return null;
                },
                onSaved: (valor) => email = valor!,
              ),
              const SizedBox(height: 16),
              TextFormField(
                keyboardType: TextInputType.number,
                decoration: const InputDecoration(
                  labelText: 'Idade',
                  border: OutlineInputBorder(),
                ),
                validator: (valor) {
                  final idade = int.tryParse(valor ?? '');
                  if (idade == null) return 'Digite a idade em números';
                  if (idade < 18) return 'O cliente precisa ter 18 anos ou mais';
                  return null;
                },
                onSaved: (valor) => idade = int.parse(valor!),
              ),
              const SizedBox(height: 16),
              FilledButton(onPressed: salvar, child: const Text('Salvar')),
            ],
          ),
        ),
      ),
    );
  }
}

4. Validar enquanto a pessoa digita: autovalidateMode

Do jeito que está, o erro só aparece quando a pessoa toca em Salvar. Às vezes é melhor avisar na hora: errou uma letra do e-mail, a mensagem já aparece. O autovalidateMode escolhe quando o validator roda sozinho:

Form(
  key: _formKey,
  autovalidateMode: AutovalidateMode.onUserInteraction,
  child: …,
)
AutovalidateMode.O validator roda sozinho…
disabled (padrão)nunca: só quando você chama validate()
onUserInteractiona cada mudança, mas só nos campos que a pessoa já mexeu (os outros continuam limpos)
alwayssempre, desde o começo: o formulário já abre cheio de erros vermelhos, o que assusta

Dá para pôr o autovalidateMode no Form (vale para todos) ou num TextFormField só. Um padrão bom e comum: começar com disabled e, depois da primeira tentativa de salvar que falhou, trocar para onUserInteraction, para a mensagem sumir assim que a pessoa conserta:

AutovalidateMode modo = AutovalidateMode.disabled;

void salvar() {
  if (_formKey.currentState!.validate()) {
    // … salvar
  } else {
    setState(() {
      modo = AutovalidateMode.onUserInteraction;
    });
  }
}

// no build:
Form(key: _formKey, autovalidateMode: modo, child: …)

5. Um campo que depende de outro: "repita a senha"

O validator é uma função comum: pode olhar outras variáveis. Para conferir a senha repetida, dê um controlador ao primeiro campo e compare no segundo:

final senha = TextEditingController();

// no build:
TextFormField(
  controller: senha,
  obscureText: true,
  decoration: const InputDecoration(labelText: 'Senha'),
  validator: (valor) {
    if (valor == null || valor.length < 6) return 'A senha precisa de 6 caracteres ou mais';
    return null;
  },
),
TextFormField(
  obscureText: true,
  decoration: const InputDecoration(labelText: 'Repita a senha'),
  validator: (valor) {
    if (valor != senha.text) return 'As senhas não são iguais';
    return null;
  },
),

Não esqueça o senha.dispose() no dispose() do State.

Missão: o segundo campo aceita qualquer coisa. Escreva o validator dele para devolver 'As senhas não são iguais' quando o valor for diferente de senha.text. Teste com senhas diferentes e depois iguais.

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: CriarConta()));

class CriarConta extends StatefulWidget {
  const CriarConta({super.key});

  @override
  State<CriarConta> createState() => _CriarContaState();
}

class _CriarContaState extends State<CriarConta> {
  final _formKey = GlobalKey<FormState>();
  final senha = TextEditingController();

  @override
  void dispose() {
    senha.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Criar conta')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                controller: senha,
                obscureText: true,
                decoration: const InputDecoration(labelText: 'Senha'),
                validator: (valor) {
                  if (valor == null || valor.length < 6) {
                    return 'A senha precisa de 6 caracteres ou mais';
                  }
                  return null;
                },
              ),
              TextFormField(
                obscureText: true,
                decoration: const InputDecoration(labelText: 'Repita a senha'),
              ),
              const SizedBox(height: 16),
              FilledButton(
                onPressed: () => _formKey.currentState!.validate(),
                child: const Text('Criar conta'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Quando dá errado

Esqueceu o key: _formKey no Form

"O operador de checagem de nulo (o !) foi usado num valor nulo." Você prometeu ao Dart, com o ! de currentState!, que o formulário existia; mas a chave não estava presa a nenhum Form, então currentState era null.

Como consertar: Form(key: _formKey, child: …). Sempre que aparecer Null check operator used on a null value junto de um currentState!, desconfie da chave.

O validator que nunca devolve null 
validator: (valor) {
  if (valor == null || valor.isEmpty) {
    return 'Digite o nome';
  }
  return '';
},

Parece inofensivo, mas o texto vazio '' não é null: para o Form, é uma mensagem de erro (vazia). O validate() devolve sempre false e o botão Salvar nunca funciona. Como consertar: no fim do validator, return null;.

Usou TextField em vez de TextFormField

O TextField não tem validator: se você tentar passar um, o app nem compila. Trocando o TextFormField do app da seção 1 por TextField, o flutter analyze mostra:

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Cadastro()));

class Cadastro extends StatefulWidget {
  const Cadastro({super.key});

  @override
  State<Cadastro> createState() => _CadastroState();
}

class _CadastroState extends State<Cadastro> {
  final _formKey = GlobalKey<FormState>();

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Novo cliente')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              TextFormField(
                decoration: const InputDecoration(labelText: 'Nome'),
                validator: (valor) {
                  if (valor == null || valor.trim().isEmpty) {
                    return 'Digite o nome do cliente';
                  }
                  return null;
                },
              ),
              TextFormField(
                keyboardType: TextInputType.phone,
                decoration: const InputDecoration(labelText: 'Celular'),
                validator: (valor) {
                  if (valor == null || valor.length != 11) {
                    return 'O celular tem 11 números (com DDD)';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 16),
              FilledButton(
                onPressed: () => _formKey.currentState!.validate(),
                child: const Text('Salvar'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

Resumo

  • O Form junta os campos; cada TextFormField tem o seu validator.
  • O validator devolve a mensagem de erro ou null (= "está certo"). Texto vazio '' também conta como erro.
  • A GlobalKey<FormState> no key do Form deixa o botão chamar validate(), save() e reset().
  • validate() confere tudo e mostra os erros; save() chama os onSaved; reset() limpa.
  • autovalidateMode: AutovalidateMode.onUserInteraction confere enquanto a pessoa digita.
