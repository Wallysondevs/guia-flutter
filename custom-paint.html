Flutter CustomPaint

Até aqui, toda tela foi montada com peças prontas: Text, Icon, Container. Mas e um gráfico de pizza das vendas, uma assinatura feita com o dedo, um velocímetro? Para isso, o Flutter dá um papel em branco e um pincel: o CustomPaint. Você escreve, em código, "um círculo amarelo aqui, uma linha laranja ali", e ele desenha. É o mesmo mecanismo que os próprios widgets do Flutter usam por dentro.

Você vai aprender
  • As três peças: o widget CustomPaint, a sua classe CustomPainter e o método paint(Canvas canvas, Size size).
  • A usar o Paint (o pincel: cor, espessura, preenchido ou só contorno).
  • As coordenadas: Offset (um ponto) e Size (o tamanho do papel), com o (0, 0) no canto de cima, à esquerda.
  • Os desenhos básicos: drawRect, drawCircle, drawLine e drawArc.
  • Para que serve o shouldRepaint.
  • O erro mais comum: o CustomPaint sem tamanho, e o que ele faz com o desenho.

A ideia: o papel quadriculado

Imagine uma folha de papel quadriculado. Para dizer onde desenhar, você conta quadradinhos a partir do canto de cima, à esquerda: "3 para a direita, 5 para baixo". No Flutter é igual, só que em pixels:

(0,0) ───────── x cresce para a direita ─────────▶ (300,0)
  │
  │        • (150,150) = o centro de um papel 300 × 300
  │
  ▼ y cresce para BAIXO
(0,300)                                           (300,300)

Repare: o y cresce para baixo, ao contrário do gráfico da escola. Um ponto é um Offset(x, y); o tamanho do papel é um Size(largura, altura).

1. O sol da Ana: o primeiro desenho

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: TelaDesenho(),
    ));

class TelaDesenho extends StatelessWidget {
  const TelaDesenho({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('O sol da Ana')),
      body: Center(
        child: CustomPaint(
          size: const Size(300, 300),
          painter: SolPainter(),
        ),
      ),
    );
  }
}

class SolPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final fundo = Paint()..color = Colors.lightBlue.shade100;
    canvas.drawRect(Offset.zero & size, fundo);

    final centro = Offset(size.width / 2, size.height / 2);
    final amarelo = Paint()..color = Colors.amber;
    canvas.drawCircle(centro, 60, amarelo);

    final raio = Paint()
      ..color = Colors.orange
      ..strokeWidth = 6
      ..strokeCap = StrokeCap.round;
    canvas.drawLine(centro + const Offset(0, -80), centro + const Offset(0, -120), raio);
    canvas.drawLine(centro + const Offset(0, 80), centro + const Offset(0, 120), raio);
    canvas.drawLine(centro + const Offset(-80, 0), centro + const Offset(-120, 0), raio);
    canvas.drawLine(centro + const Offset(80, 0), centro + const Offset(120, 0), raio);
  }

  @override
  bool shouldRepaint(SolPainter oldDelegate) => false;
}
CustomPaint(size: …, painter: …)
O widget que reserva um pedaço da tela para desenhar. O size é o tamanho do papel (300 × 300); o painter, quem desenha.
class SolPainter extends CustomPainter
A sua classe de desenho. Ela tem dois métodos obrigatórios: paint e shouldRepaint.
void paint(Canvas canvas, Size size)
Onde o desenho acontece. O canvas ("tela de pintura") tem os métodos draw…; o size é o tamanho do papel, para você desenhar proporcional a ele.
Paint()..color = Colors.lightBlue.shade100
O pincel. O .. (cascata) configura o objeto recém-criado. Sem mais nada, o pincel preenche a forma.
canvas.drawRect(Offset.zero & size, fundo)
Um retângulo. Offset.zero & size é um atalho para "o retângulo que começa em (0, 0) e tem o tamanho do papel": o fundo inteiro.
Offset(size.width / 2, size.height / 2)
O centro do papel (150, 150), calculado a partir do tamanho.
canvas.drawCircle(centro, 60, amarelo)
Um círculo: o centro, o raio (60 pixels) e o pincel.
..strokeWidth = 6 / ..strokeCap = StrokeCap.round
Para linhas: a espessura do traço e a ponta arredondada.
canvas.drawLine(p1, p2, raio)
Uma linha do ponto p1 ao p2. centro + const Offset(0, -80) é "80 pixels acima do centro" (y negativo = para cima).
bool shouldRepaint(…) => false
"Precisa redesenhar quando o widget for reconstruído?" Este desenho nunca muda, então false. (Mais na seção 3.)

2. O pincel e os desenhos básicos

Do PaintO que faz
..color = Colors.redA cor
..style = PaintingStyle.fillPreenche a forma (o padrão)
..style = PaintingStyle.strokeSó o contorno
..strokeWidth = 4Espessura do contorno e das linhas
..strokeCap = StrokeCap.roundPonta das linhas arredondada
Do CanvasDesenha
drawRect(Rect, paint)Retângulo (Rect.fromLTWH(x, y, largura, altura))
drawRRect(RRect, paint)Retângulo de cantos redondos
drawCircle(centro, raio, paint)Círculo
drawOval(Rect, paint)Elipse dentro do retângulo
drawLine(p1, p2, paint)Linha
drawArc(Rect, inicio, angulo, useCenter, paint)Arco ou fatia (ângulos em radianos)
drawPath(Path, paint)Qualquer forma, ponto a ponto (moveTo, lineTo, quadraticBezierTo…)

3. O gráfico de pizza das vendas

A lojinha da Ana vendeu, na semana, 50 cafés, 30 bolos e 20 pães de queijo. Um gráfico de pizza com drawArc:

import 'dart:math';

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: TelaVendas(),
    ));

class TelaVendas extends StatelessWidget {
  const TelaVendas({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Vendas da semana')),
      body: Center(
        child: CustomPaint(
          size: const Size(260, 260),
          painter: PizzaPainter(const [50, 30, 20]),
        ),
      ),
    );
  }
}

class PizzaPainter extends CustomPainter {
  PizzaPainter(this.valores);

  final List<double> valores;
  static const cores = [Colors.orange, Colors.brown, Colors.teal];

  @override
  void paint(Canvas canvas, Size size) {
    final total = valores.reduce((a, b) => a + b);
    final area = Offset.zero & size;
    var inicio = -pi / 2;
    for (var i = 0; i < valores.length; i++) {
      final angulo = valores[i] / total * 2 * pi;
      canvas.drawArc(area, inicio, angulo, true, Paint()..color = cores[i]);
      inicio += angulo;
    }
    final borda = Paint()
      ..color = Colors.white
      ..style = PaintingStyle.stroke
      ..strokeWidth = 4;
    canvas.drawCircle(area.center, size.width / 2, borda);
  }

  @override
  bool shouldRepaint(PizzaPainter oldDelegate) => oldDelegate.valores != valores;
}
import 'dart:math'
Traz o pi (3,14159…). Os ângulos do Canvas são em radianos: uma volta inteira é 2 * pi.
PizzaPainter(this.valores)
O painter pode receber dados, como qualquer classe. Aqui, a lista de vendas.
var inicio = -pi / 2
O ângulo 0 aponta para a direita (3 horas no relógio). -pi / 2 é um quarto de volta para trás: começa no topo (12 horas).
valores[i] / total * 2 * pi
O tamanho da fatia: a fração do total (50/100 = metade) vezes a volta inteira.
drawArc(area, inicio, angulo, true, …)
A fatia. O true (useCenter) liga as pontas do arco ao centro: vira fatia de pizza. Com false, seria só a "casca".
PaintingStyle.stroke
O círculo branco por cima é só contorno, para dar acabamento.
shouldRepaint: oldDelegate.valores != valores
Redesenha só se os dados mudaram. Quando a tela é reconstruída com os mesmos valores, o Flutter reaproveita o desenho anterior.

Quando dá errado

O CustomPaint sem tamanho

A Ana apagou a linha size: const Size(300, 300), do sol. Não dá erro nenhum, nem no console. O resultado:

O que aconteceu, peça por peça:

  • Sem size e sem child, o CustomPaint tem 0 × 0. O Center o coloca no meio da tela, e o paint recebe size = 0 × 0.
  • O fundo era Offset.zero & size: um retângulo de 0 × 0. Sumiu.
  • O centro, size.width / 2, virou (0, 0): o ponto onde está o papel de tamanho zero, que é o meio da tela.
  • O círculo (raio 60) e os raios (até 120 pixels) não dependem do tamanho: foram desenhados em volta desse ponto, por fora do papel. O Canvas não corta o que passa da borda.

Aqui deu a impressão de que "quase funcionou". Num desenho todo proporcional ao size (como o gráfico de pizza, que usa Offset.zero & size para as fatias), nada aparece. Como consertar: dê um size ao CustomPaint, ou um child que tenha tamanho (o papel fica do tamanho do filho), ou ponha o CustomPaint num lugar que o estique (ex.: SizedBox.expand).

Desenhou fora do papel de propósito? Corte com ClipRect

Como o Canvas não corta nada, um desenho que passa da borda invade os widgets vizinhos. Se quiser que o que passar da borda suma, embrulhe o CustomPaint num ClipRect.

Resumo

  • CustomPaint reserva o papel; a sua classe CustomPainter desenha no paint(canvas, size).
  • O Paint é o pincel (cor, preenchido ou contorno, espessura); o Canvas tem os draw….
  • (0, 0) é o canto de cima à esquerda, e o y cresce para baixo. Ângulos em radianos, com o 0 apontando para a direita.
  • shouldRepaint diz se vale redesenhar; devolva true só quando os dados mudarem.
  • Dê um tamanho ao CustomPaint (size ou um child): sem ele, o papel tem 0 × 0, o que depende do tamanho some e o resto é desenhado sem limite em volta de um ponto.
