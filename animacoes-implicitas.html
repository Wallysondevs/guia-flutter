Flutter Animações Implícitas

Um app em que tudo "pula" de um jeito para o outro parece duro. Um botão que cresce suavemente, uma mensagem que aparece aos poucos, uma cor que muda devagar: são detalhes que fazem o app parecer caprichado. No Flutter, o jeito mais fácil de animar é o das animações implícitas: você usa um widget "Animated…" no lugar do comum, diz quanto tempo a mudança leva, e muda o valor com setState. O widget anima sozinho do valor antigo até o novo. Você não controla nenhum quadro da animação: ela está implícita (subentendida) na mudança.

Você vai aprender
  • O AnimatedContainer: um Container que anima tamanho, cor, borda e espaçamento.
  • Os dois parâmetros de toda animação implícita: duration (quanto tempo) e curve (com que ritmo).
  • AnimatedOpacity (aparecer e sumir) e AnimatedAlign (mudar de lugar).
  • AnimatedSwitcher: trocar um widget por outro com transição.
  • TweenAnimationBuilder: animar qualquer valor, mesmo sem um widget "Animated…" pronto.
  • Os erros mais comuns: mudar o valor sem setState e o AnimatedSwitcher que não anima.
Sobre as fotos desta aula

Uma foto não mostra movimento. Por isso, cada exemplo tem duas fotos tiradas no laboratório: o começo e o fim da animação. Para ver o movimento de verdade, rode o exemplo no Experimente.

A ideia: o dimmer da luz da sala

Um interruptor comum liga a luz de uma vez: clac, apagado, aceso. Um dimmer (aquele botão de girar) faz a luz ir acendendo aos poucos. Você só diz aonde quer chegar ("luz forte"); o dimmer cuida do caminho.

Um Container comum é o interruptor: troque a largura de 120 para 280 e ele pula. O AnimatedContainer é o dimmer: troque a largura e ele vai crescendo durante o tempo que você mandou.

1. AnimatedContainer: o cartão que cresce

A Ana quer que o cartão da receita do dia cresça e mude de cor quando ela toca nele:

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: TelaReceita(),
    ));

class TelaReceita extends StatefulWidget {
  const TelaReceita({super.key});

  @override
  State<TelaReceita> createState() => _TelaReceitaState();
}

class _TelaReceitaState extends State<TelaReceita> {
  bool _aberto = false;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Receita do dia')),
      body: Center(
        child: GestureDetector(
          onTap: () => setState(() => _aberto = !_aberto),
          child: AnimatedContainer(
            duration: const Duration(milliseconds: 400),
            curve: Curves.easeInOut,
            width: _aberto ? 280 : 160,
            height: _aberto ? 200 : 100,
            alignment: Alignment.center,
            decoration: BoxDecoration(
              color: _aberto ? Colors.orange : Colors.teal,
              borderRadius: BorderRadius.circular(_aberto ? 32 : 8),
            ),
            child: const Text(
              'Bolo de cenoura',
              style: TextStyle(color: Colors.white, fontSize: 20),
            ),
          ),
        ),
      ),
    );
  }
}
bool _aberto = false
O estado: o cartão está aberto ou fechado? Ele mora num StatefulWidget, porque muda.
GestureDetector(onTap: …)
Detecta o toque (veja Toques e Gestos) e chama setState para inverter o _aberto.
AnimatedContainer
Aceita quase os mesmos parâmetros do Container. A diferença: quando um deles muda de um build para o outro, ele anima a mudança.
duration: const Duration(milliseconds: 400)
Obrigatório. Quanto tempo a animação leva: 400 milissegundos (0,4 s). Entre 200 e 500 ms é o normal para coisas pequenas na tela.
curve: Curves.easeInOut
O ritmo: começa devagar, acelera no meio, freia no fim. Sem curve, o padrão é Curves.linear (velocidade constante, que parece mecânico).
width: _aberto ? 280 : 160
O valor de destino. Você escreve só o fim; o widget lembra o valor anterior e anima entre os dois.
Começo (_aberto = false)Fim (_aberto = true)

Entre as duas fotos, durante 0,4 s, o Flutter desenha os quadros intermediários (cerca de 60 por segundo): larguras entre 160 e 280, cantos cada vez mais redondos e cores misturadas entre o verde-azulado e o laranja. Tudo isso sem uma linha a mais de código.

2. O ritmo: Curves

A curve diz como o valor caminha do começo ao fim. As mais usadas:

CurvaComo parece
Curves.linearVelocidade constante (o padrão). Bom para coisas que giram sem parar.
Curves.easeInOutComeça devagar, acelera, freia. O "natural" para quase tudo.
Curves.easeOutSai rápido e freia no fim. Bom para coisas que entram na tela.
Curves.easeInSai devagar e acelera. Bom para coisas que saem da tela.
Curves.bounceOutChega e "quica", como uma bola.
Curves.elasticOutPassa do ponto e volta, como um elástico.

A documentação do Flutter (api.flutter.dev/flutter/animation/Curves-class.html) tem um pequeno vídeo de cada curva.

3. AnimatedOpacity: aparecer e sumir

A opacidade vai de 0.0 (invisível) a 1.0 (normal). Para o recado "Receita salva!" aparecer aos poucos:

AnimatedOpacity(
  opacity: _salvo ? 1.0 : 0.0,
  duration: const Duration(milliseconds: 500),
  child: const Text('Receita salva!'),
)

Um detalhe: com opacidade 0 o texto fica invisível, mas continua lá, ocupando espaço. Se o espaço também tem de sumir, use o AnimatedSwitcher (seção 5) ou o AnimatedSize.

4. AnimatedAlign: mudar de lugar

Muda o alinhamento do filho dentro do espaço disponível (veja Center e Align), animando o caminho:

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: TelaPrato(),
    ));

class TelaPrato extends StatefulWidget {
  const TelaPrato({super.key});

  @override
  State<TelaPrato> createState() => _TelaPratoState();
}

class _TelaPratoState extends State<TelaPrato> {
  bool _servido = false;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Servindo a mesa')),
      body: AnimatedAlign(
        alignment: _servido ? Alignment.bottomRight : Alignment.topLeft,
        duration: const Duration(seconds: 1),
        curve: Curves.easeInOut,
        child: const Padding(
          padding: EdgeInsets.all(24),
          child: Icon(Icons.lunch_dining, size: 64),
        ),
      ),
      floatingActionButtonLocation: FloatingActionButtonLocation.centerFloat,
      floatingActionButton: FloatingActionButton.extended(
        onPressed: () => setState(() => _servido = !_servido),
        label: const Text('Servir'),
      ),
    );
  }
}
Começo (Alignment.topLeft)Fim (Alignment.bottomRight)

5. AnimatedSwitcher: trocar um widget por outro

Os widgets acima animam um valor do mesmo widget. O AnimatedSwitcher anima a troca de um widget por outro: o velho some aos poucos enquanto o novo aparece (por padrão, um "esmaecer cruzado").

AnimatedSwitcher(
  duration: const Duration(milliseconds: 300),
  child: Text(
    '$_porcoes porções',
    key: ValueKey(_porcoes),
    style: const TextStyle(fontSize: 32),
  ),
)
child
O widget atual. Quando ele é trocado por outro, o switcher anima a troca.
key: ValueKey(_porcoes)
O pulo do gato. Um Text trocado por outro Text é, para o Flutter, o mesmo widget com outro texto, e não há troca para animar. A key diferente a cada número diz "este é outro widget".

6. TweenAnimationBuilder: animar qualquer valor

E quando não existe um "Animated…" pronto para o que você quer? O TweenAnimationBuilder anima um número (ou cor, ou tamanho) e chama um builder a cada quadro com o valor do momento. Uma barra de progresso do preparo da receita:

TweenAnimationBuilder<double>(
  tween: Tween(begin: 0, end: _progresso),
  duration: const Duration(seconds: 1),
  builder: (context, valor, child) {
    return LinearProgressIndicator(value: valor);
  },
)
tween: Tween(begin: 0, end: _progresso)
Tween vem de in-between, "entre": a faixa de valores. O begin só vale na primeira vez; depois, quando o end muda, ele anima do valor atual até o novo end.
builder: (context, valor, child)
Chamado a cada quadro, com o valor do momento (0.0, 0.03, 0.1… até o end).

Implícita ou explícita?

Tudo o que esta aula mostrou anima de A até B, uma vez, quando um valor muda. Para animações que se repetem sem parar, que vão e voltam, que você quer pausar no meio ou controlar com o dedo, o caminho são as Animações Explícitas, com AnimationController.

Você quer…Use
Que uma mudança de tamanho/cor/posição fique suaveUm widget Animated…
Trocar um widget por outro com transiçãoAnimatedSwitcher
Animar um valor qualquer, uma vezTweenAnimationBuilder
Repetir, ir e voltar, pausar, controlarAnimationController (explícitas)
Um elemento "voar" de uma tela para outraHero

Quando dá errado

Mudou o valor sem setState: nada acontece 
          onTap: () => _aberto = !_aberto,

Compila e roda sem erro, mas o toque não faz nada: depois do toque (e de esperar 1 segundo), a tela é idêntica à do começo:

O _aberto mudou, sim, mas ninguém pediu ao Flutter para rodar o build de novo. O AnimatedContainer só anima quando recebe valores novos num build novo (veja setState). Como consertar: onTap: () => setState(() => _aberto = !_aberto).

"O parâmetro nomeado obrigatório duration tem de ser passado." Sem saber quanto tempo, não há animação.

"Achei este construtor, mas os argumentos não batem": a linha do código do próprio Flutter onde o AnimatedContainer é definido. É só uma pista; o erro está no seu arquivo.

Como consertar: duration: const Duration(milliseconds: 400),. Todos os widgets Animated… exigem a duration.

O AnimatedSwitcher troca sem animar

Com child: Text('$_porcoes porções') e sem key, o número muda de uma vez, sem transição. Não há erro: para o Flutter, um Text no lugar de outro Text é o mesmo widget com outro texto, então não há "troca" para animar. Como consertar: key: ValueKey(_porcoes) no filho (seção 5).

Resumo

  • Animação implícita: troque o widget pelo seu "Animated…", dê uma duration, e mude o valor com setState. O widget anima do valor velho até o novo.
  • curve dá o ritmo; Curves.easeInOut é o mais natural, linear é o padrão.
  • AnimatedContainer, AnimatedOpacity, AnimatedAlign, AnimatedPadding, AnimatedPositioned… há uma versão animada para os widgets mais comuns.
  • AnimatedSwitcher anima a troca de um widget por outro, desde que eles tenham keys diferentes.
  • TweenAnimationBuilder anima qualquer valor. Para repetir ou controlar, vá para as animações explícitas.
