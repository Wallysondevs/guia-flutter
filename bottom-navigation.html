Flutter Barra de Navegação Inferior

Abra o app do banco, o de música ou o de mensagens do seu celular: quase todos têm, lá embaixo, uma fileira de 3 a 5 ícones que levam às partes principais do app. É a barra de navegação inferior. Ela fica sempre à vista e ao alcance do polegar, ao contrário da gaveta, que fica escondida. No app da Ana, ela vai levar às três partes que ela usa toda hora: Receitas, Favoritas e Compras. No Flutter com Material 3, essa barra é o NavigationBar.

Você vai aprender
  • A pôr um NavigationBar no parâmetro bottomNavigationBar do Scaffold.
  • O que são os destinos (NavigationDestination): ícone, ícone escolhido e rótulo.
  • A fazer a barra funcionar com selectedIndex, onDestinationSelected e setState.
  • A trocar o conteúdo da tela conforme o destino.
  • A pôr um selo com número no ícone (Badge) e a esconder os rótulos (labelBehavior).
  • Por que o estado de uma aba some quando você troca de aba, e como o IndexedStack resolve.
  • O BottomNavigationBar, a barra do Material 2, que você vai encontrar em código mais antigo.
  • Os erros reais: a barra que não muda, a barra com um item só e o índice fora da lista.

Tudo nesta aula foi compilado com o Flutter 3.47 no laboratório do guia. Você precisa conhecer o Scaffold, os ícones e o setState.

A ideia: o controle remoto da TV

O controle remoto tem um botão para cada canal favorito. Você aperta "3", a TV mostra o canal 3, e o controle não muda de lugar: continua na sua mão, pronto para o próximo canal. A TV só mostra um canal por vez, e você sempre sabe qual é porque o número aparece no canto.

Na TVNo Flutter
O controle remotoO NavigationBar, no bottomNavigationBar do Scaffold
Um botão de canalUm NavigationDestination (ícone + rótulo)
O número do canal atual no cantoO selectedIndex: a barra destaca o destino atual
Apertar um botãoO onDestinationSelected, que recebe o índice tocado
A imagem na telaO body, escolhido a partir do índice

1. A barra parada

Primeiro, só a barra, sem funcionar. Ela vai no parâmetro bottomNavigationBar do Scaffold ("barra de navegação de baixo"):

import 'package:flutter/material.dart';

void main() => runApp(const ReceitasApp());

class ReceitasApp extends StatelessWidget {
  const ReceitasApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange),
      home: const InicioPage(),
    );
  }
}

class InicioPage extends StatelessWidget {
  const InicioPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Receitas da Ana')),
      body: const Center(child: Text('Bolo de cenoura')),
      bottomNavigationBar: NavigationBar(
        destinations: const [
          NavigationDestination(icon: Icon(Icons.menu_book), label: 'Receitas'),
          NavigationDestination(icon: Icon(Icons.favorite), label: 'Favoritas'),
          NavigationDestination(icon: Icon(Icons.shopping_cart), label: 'Compras'),
        ],
      ),
    );
  }
}
bottomNavigationBar:
O lugar da barra no Scaffold: colada no rodapé da tela, abaixo do body. O Scaffold encolhe o body para a barra não cobrir nada.
NavigationBar(destinations: [...])
A barra do Material 3. O único parâmetro obrigatório é a lista de destinos, com pelo menos dois (com um só, dá erro; veja Quando dá errado).
NavigationDestination(icon:, label:)
Um destino: o ícone e o rótulo que aparece embaixo dele. Repare que o label aqui é uma String, não um Text.
const [...]
Os destinos não mudam nunca, então a lista inteira é const. O NavigationBar em si não pode ser const (o construtor dele não é const).

Toque em "Favoritas": nada acontece. A barra não sabe qual destino está escolhido; ela só mostra o valor do selectedIndex, que, sem você dizer nada, vale 0. Quem guarda e muda esse número é você.

2. A barra funcionando

O número do destino atual é estado da página: muda com o toque e precisa redesenhar a tela. Então a página vira um StatefulWidget, e o trio de sempre entra em cena: uma variável, o setState e a barra lendo a variável:

import 'package:flutter/material.dart';

void main() => runApp(const ReceitasApp());

class ReceitasApp extends StatelessWidget {
  const ReceitasApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange),
      home: const InicioPage(),
    );
  }
}

class InicioPage extends StatefulWidget {
  const InicioPage({super.key});

  @override
  State<InicioPage> createState() => _InicioPageState();
}

class _InicioPageState extends State<InicioPage> {
  int _atual = 0;

  static const _telas = [
    Center(child: Text('Todas as receitas', style: TextStyle(fontSize: 22))),
    Center(child: Text('Suas favoritas', style: TextStyle(fontSize: 22))),
    Center(child: Text('Lista de compras', style: TextStyle(fontSize: 22))),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Receitas da Ana')),
      body: _telas[_atual],
      bottomNavigationBar: NavigationBar(
        selectedIndex: _atual,
        onDestinationSelected: (indice) {
          setState(() => _atual = indice);
        },
        destinations: const [
          NavigationDestination(
            icon: Icon(Icons.menu_book_outlined),
            selectedIcon: Icon(Icons.menu_book),
            label: 'Receitas',
          ),
          NavigationDestination(
            icon: Icon(Icons.favorite_border),
            selectedIcon: Icon(Icons.favorite),
            label: 'Favoritas',
          ),
          NavigationDestination(
            icon: Icon(Icons.shopping_cart_outlined),
            selectedIcon: Icon(Icons.shopping_cart),
            label: 'Compras',
          ),
        ],
      ),
    );
  }
}
int _atual = 0;
O índice do destino atual. Começa em 0: o app abre em "Receitas".
_telas
Uma lista com o conteúdo de cada destino, na mesma ordem dos destinos da barra. Aqui são só textos; num app de verdade, cada item seria um widget seu (ReceitasTela(), FavoritasTela()…).
body: _telas[_atual]
O corpo é escolhido pelo índice. Mudou o _atual, mudou a tela.
selectedIndex: _atual
Diz à barra qual destino destacar.
onDestinationSelected: (indice) { ... }
Chamado no toque, com o índice do destino tocado (0, 1 ou 2). O setState guarda o novo índice e pede ao Flutter para chamar o build de novo: a barra destaca o novo destino e o body troca.
icon / selectedIcon
O ícone normal e o ícone quando o destino está escolhido. O costume do Material 3: vazado (_outlined, _border) no normal, cheio no escolhido. Sem selectedIcon, a barra usa o mesmo ícone nos dois casos.

Tocando em "Favoritas":

A etiqueta cinza "Receitas" sobre a barra é a dica (tooltip) do destino: o NavigationBar mostra o rótulo numa etiqueta quando o ponteiro do mouse para em cima de um destino. Ela aparece nas fotos porque o laboratório roda o app num navegador, com mouse; num celular, só aparece ao segurar o dedo no destino.

A "pílula" colorida atrás do ícone escolhido é o indicador do Material 3; a cor dele vem do tema do app (aula Material 3 e ColorScheme).

Missão: acrescente um quarto destino, Perfil, com o ícone Icons.person, e uma quarta tela na lista _telas (por exemplo, Center(child: Text('Olá, Ana'))). Toque nele e confira que a tela troca.

3. Selos e rótulos

Dois ajustes que aparecem em muitos apps. O selo (Badge, "crachá") é a bolinha com um número sobre o ícone: "3 itens na lista de compras". E o labelBehavior ("comportamento do rótulo") decide quando os textos aparecem:

bottomNavigationBar: NavigationBar(
  selectedIndex: _atual,
  onDestinationSelected: (indice) => setState(() => _atual = indice),
  labelBehavior: NavigationDestinationLabelBehavior.onlyShowSelected,
  destinations: const [
    NavigationDestination(icon: Icon(Icons.menu_book), label: 'Receitas'),
    NavigationDestination(icon: Icon(Icons.favorite), label: 'Favoritas'),
    NavigationDestination(
      icon: Badge(label: Text('3'), child: Icon(Icons.shopping_cart)),
      label: 'Compras',
    ),
  ],
),
Badge(label: Text('3'), child: Icon(...))
Envolve o ícone e desenha o selo no canto. Sem label, vira só uma bolinha (bom para "tem novidade"). O Badge funciona em qualquer ícone, não só na barra.
labelBehavior:
Três valores de NavigationDestinationLabelBehavior: alwaysShow (sempre mostra; é o padrão), onlyShowSelected (só o do destino escolhido) e alwaysHide (nunca mostra). Esconder os rótulos economiza espaço, mas a Ana precisa adivinhar o que cada ícone faz; na dúvida, deixe o padrão.

4. A aba que esquece: o IndexedStack

A Ana montou uma tela de compras com um contador de itens. Ela soma 3 itens, vai às "Receitas" e volta: o contador está em zero de novo. Por quê?

import 'package:flutter/material.dart';

void main() => runApp(const ReceitasApp());

class ReceitasApp extends StatelessWidget {
  const ReceitasApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.orange),
      home: const InicioPage(),
    );
  }
}

class ComprasTela extends StatefulWidget {
  const ComprasTela({super.key});

  @override
  State<ComprasTela> createState() => _ComprasTelaState();
}

class _ComprasTelaState extends State<ComprasTela> {
  int _itens = 0;

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Text('$_itens itens na lista', style: const TextStyle(fontSize: 22)),
          const SizedBox(height: 12),
          FilledButton(
            onPressed: () => setState(() => _itens++),
            child: const Text('Adicionar item'),
          ),
        ],
      ),
    );
  }
}

  const InicioPage({super.key});

  @override
  State<InicioPage> createState() => _InicioPageState();
}

    );
  }
}

Com body: _telas[_atual], o body tem uma tela por vez. Quando a Ana vai para "Receitas", a ComprasTela sai da árvore de widgets, e o estado dela (o _itens) vai junto para o lixo. Ao voltar, o Flutter cria uma ComprasTela nova, com _itens = 0. O ciclo de vida do widget explica esse "nasce e morre" em detalhe.

No laboratório, a Ana tocou em "Compras", três vezes em "Adicionar item" (a tela mostrou "3 itens na lista"), depois em "Receitas" e de novo em "Compras":

A troca é uma linha só: o IndexedStack ("pilha com índice") mantém todas as telas na árvore, uma em cima da outra, e mostra só a do índice:

      body: IndexedStack(index: _atual, children: _telas),
IndexedStack
Parecido com o Stack, que empilha os filhos, mas desenha só um: o da posição index. Os outros continuam vivos, escondidos, com o estado intacto.
index: _atual
Qual filho mostrar.
children: _telas
Todas as telas, criadas uma vez só.

Agora a Ana soma 3 itens, vai às receitas, volta, e o contador ainda mostra 3:

O preço do IndexedStack

Todas as telas ficam na memória e são montadas logo no começo, mesmo as que a Ana nunca abre. Com 3 a 5 abas simples, isso não pesa. Se uma aba carrega coisas pesadas (uma lista enorme, imagens da internet), considere guardar o estado fora da tela, na página de cima (aula Elevando o Estado), e continuar com o _telas[_atual].

Formas diferentes de fazer

O BottomNavigationBar do Material 2

Antes do Material 3, a barra de baixo era o BottomNavigationBar. Ele ainda existe e você vai encontrá-lo em muitos tutoriais e projetos antigos. A lógica é a mesma; mudam os nomes:

bottomNavigationBar: BottomNavigationBar(
  currentIndex: _atual,
  onTap: (indice) => setState(() => _atual = indice),
  items: const [
    BottomNavigationBarItem(icon: Icon(Icons.menu_book), label: 'Receitas'),
    BottomNavigationBarItem(icon: Icon(Icons.favorite), label: 'Favoritas'),
    BottomNavigationBarItem(icon: Icon(Icons.shopping_cart), label: 'Compras'),
  ],
),
NavigationBar (Material 3)BottomNavigationBar (Material 2)
destinations:items:
NavigationDestinationBottomNavigationBarItem
selectedIndex:currentIndex:
onDestinationSelected:onTap:
selectedIcon:activeIcon:
Indicador em forma de pílula; mais altoSó a cor muda; mais baixo

Qual usar

CasoEscolha
App novo, de 3 a 5 partes principaisNavigationBar
Projeto antigo que já usa o Material 2BottomNavigationBar, para manter o visual
Mais de 5 partes, ou partes que a Ana visita poucoA gaveta (ou as duas juntas: barra para as principais, gaveta para o resto)
Partes "irmãs" dentro de uma mesma tela (Doces / Salgados)As abas no topo
Tela larga (tablet, computador)O NavigationRail, a mesma ideia na lateral (aula Telas de Vários Tamanhos)

Quando dá errado

A barra não muda quando eu toco 
NavigationBar(
  selectedIndex: _atual,
  onDestinationSelected: (indice) {
    _atual = indice;
  },
  destinations: const [ ... ],
),

Nenhuma mensagem de erro, e nada muda na tela. A variável _atual até recebe o número novo, mas ninguém avisou o Flutter de que a tela precisa ser redesenhada. Como consertar: mude a variável dentro do setState: setState(() => _atual = indice);. Se ainda assim não mudar, confira se o selectedIndex lê a variável (selectedIndex: _atual) e não um número fixo (selectedIndex: 0).

O índice fora da lista

A regra agora é a da linha 123: "o selectedIndex tem de ser pelo menos 0 e menor que a quantidade de destinos". Com dois destinos, os índices válidos são 0 e 1; o 2 aponta para um destino que não existe. O _InicioPageState#199eb é só um "número de série" do estado, para diferenciar um objeto do outro; pode ignorar.

Como consertar: o selectedIndex precisa estar entre 0 e o número de destinos menos 1. Quando tirar um destino, confira o valor inicial do índice e a lista _telas: as duas listas (destinos e telas) andam juntas, com o mesmo tamanho e a mesma ordem.

class ReceitasApp extends StatelessWidget {

  Widget build(BuildContext context) {

  }

class InicioPage extends StatefulWidget {
  const InicioPage({super.key});

  @override
  State<InicioPage> createState() => _InicioPageState();
}

class _InicioPageState extends State<InicioPage> {
  int _atual = 0;

  static const _telas = [
    Center(child: Text('Todas as receitas')),
    Center(child: Text('Suas favoritas')),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Receitas da Ana')),
      body: _telas[_atual],
      bottomNavigationBar: NavigationBar(
        selectedIndex: _atual,
        onDestinationSelected: (indice) => setState(() => _atual = indice),
        destinations: const [
          NavigationDestination(icon: Icon(Icons.menu_book), label: 'Receitas'),
          NavigationDestination(icon: Icon(Icons.favorite), label: 'Favoritas'),
        ],
      ),
    );
  }
}

Resumo

  • A barra de navegação inferior vai no bottomNavigationBar do Scaffold. No Material 3, é o NavigationBar, com 2 ou mais NavigationDestination (o ideal: de 3 a 5).
  • A barra só mostra o selectedIndex; quem guarda e muda o índice é você, com onDestinationSelected + setState.
  • O body escolhe a tela pelo índice: _telas[_atual]. Destinos e telas na mesma ordem.
  • icon vazado e selectedIcon cheio; Badge para selos; labelBehavior para os rótulos.
  • Com _telas[_atual], a aba que sai perde o estado. Com IndexedStack(index: _atual, children: _telas), todas ficam vivas.
  • O BottomNavigationBar é a versão Material 2: items, currentIndex, onTap.
  • Barra que não muda: faltou setState. Um destino só ou índice fora da lista: o Flutter reclama (seção Quando dá errado).
